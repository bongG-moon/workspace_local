    줄 이동과 임시 보관 자세히

    임시 보관은 업무별로 한 개입니다. 다른 글·첨부가 있는 상태에서 Ctrl+S를 누르면 기존 보관 내용을 교체합니다. 다른 요청의 전송이 확인되고 입력창이 비어 있으면 자동 복원하며, 새로 쓰는 내용은 덮어쓰지 않습니다.

    입력·편집의 기본 키는 맞췄지만, 모든 동작이 같은 것은 아니에요. Ctrl+O는 앱의 도구 기록을 펼치며, Ctrl+R과 ↑·↓의 기록 탐색은 현재 대화·업무 안에서만 동작합니다. 검색 결과는 입력창으로 가져오며 자동 전송하지 않습니다.

    작업 중 Ctrl+Enter의 즉시 반영은 현재 연결에서 지원하지 않습니다. Enter로 대기열에 넣거나 ‘지금 반영’의 중지·재개 방식을 선택할 수 있어요. 중지 후에는 대기열을 자동 실행하지 않습니다.

    Ctrl+C를 반복해도 앱은 종료되지 않습니다. Ctrl+D 종료, Ctrl+B 백그라운드 전환, Esc 두 번의 되감기, 원본 터미널의 편집기·작업 목록 키는 설정 → 고급 기능 → 원본 Claude Code 열기에서 사용하세요.

    사용 상태·저장 범위 도움말
    
    
    공통·기존 설정 따르기는 이 범위의 별도 지정만 지워요. 사용 안 함은 끄는 값을 저장해요.
    
    
    스킬 사용 상태
    
    
    공통·기존 설정 따르기
    이 프로젝트에서 별도로 지정한 값만 지우고 공통 설정과 기존 프로젝트 설정, 스킬 원래 규칙을 따릅니다. 스킬을 삭제하거나 반드시 켜는 기능은 아니에요.
    사용
    Claude에 이름과 설명을 제공하고, /스킬이름으로 직접 호출할 수 있게 설정해요.
    이름만 제공
    Claude에는 설명 없이 이름만 제공해요. /스킬이름으로 직접 호출할 수도 있어요.
    직접 호출만
    Claude가 스스로 고르는 목록에는 숨기고, 내가 /스킬이름으로 호출할 때 사용해요.
    사용 안 함
    Claude와 / 목록에서 숨기고, 이름을 직접 입력해도 실행하지 않도록 설정해요. 파일은 지우지 않습니다.
    
    
    예: 사용자 공통에서 끈 스킬은 프로젝트에서 ‘공통·기존 설정 따르기’를 선택해도 꺼진 상태를 따릅니다. 이 프로젝트에서만 켜려면 ‘사용’을 선택하세요.
    
    
    저장 범위와 플러그인
    
    
    이 프로젝트에서만
    현재 업무 폴더에 저장해요. 같은 폴더를 사용하는 다른 업무와 Claude 터미널에도 적용됩니다.
    사용자 공통
    같은 Claude 사용자 설정을 사용하는 여러 프로젝트에 적용해요. 프로젝트에 별도 설정이 있으면 그 설정이 우선할 수 있습니다.
    플러그인 사용 / 사용 안 함
    설치된 플러그인을 켜거나 꺼요. 플러그인이 제공하는 스킬도 함께 관리하며, 삭제하거나 새로 설치하지 않습니다.
    
    
    저장 후 ‘지금 적용’을 선택하면 이 관리창에 표시된 업무의 Claude Code를 재연결해요. 작업 중이면 중지할 내용을 먼저 안내합니다. ‘나중에’를 선택하면 현재 연결을 유지하며, ‘저장한 설정 적용’이나 상단 재시작 버튼으로 적용할 수 있어요. 다른 업무와 터미널은 각각 재시작해야 합니다. ‘다시 확인’은 목록만 새로 읽어요. 회사 정책이나 스킬 원래 규칙이 변경을 제한할 수 있습니다.
    
    
    표시된 상태는 저장된 설정입니다. 사용자 공통 값보다 이 프로젝트의 별도 설정이 우선하면 변경이 잠기며 이유를 표시합니다. 해당 프로젝트 설정을 먼저 확인하세요.
    
    
    스킬의 ‘사용 안 함’은 스킬 호출과 목록 제공을 끄는 설정입니다. 원본 파일을 삭제하거나 일반 파일 읽기 권한을 차단하지 않습니다.
    
    
    재연결해도 대화는 유지됩니다. 꺼진 플러그인의 이전 지침이 답변에 계속 영향을 준다면 같은 폴더에서 ‘새 업무’로 시작해 확인해 주세요. 별도로 등록된 후크·스킬·프로젝트 지침은 해당 플러그인을 끄는 것만으로 삭제되지 않습니다.
