    3. 필요한 선택만 확인해요추가 질문에 답하고, 실행 전에 작업 대상과 영향을 확인해 주세요.
    4. 결과를 열고 이어가세요‘이번 결과’에서 파일을 확인하세요. 같은 대화에서 수정도 부탁할 수 있어요.

    직접 해보며 익히고 싶다면
    자료 선택부터 차근차근 따라 해보세요.

    기존 Claude Code의 로그인·스킬·후크·MCP·모델 설정을 사용해요. 승인은 이번 요청에만 적용하며, 기존 설정에서 허용한 동작은 다시 묻지 않을 수 있어요.

    대화는 이 PC의 앱 기록과 Claude 기록에 저장돼요. 자료 처리는 기존 회사 연결과 정책을 따릅니다. 인증 갱신과 일부 터미널 전용 기능은 현재 원본 Claude Code에서 진행해야 해요.
