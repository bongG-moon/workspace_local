임시 보관은 업무별로 한 개입니다. 다른 글·첨부가 있는 상태에서 Ctrl+S를 누르면 기존 보관 내용을 교체합니다. 다른 요청의 전송이 확인되고 입력창이 비어 있으면 자동 복원하며, 새로 쓰는 내용은 덮어쓰지 않습니다.

원본 Claude Code와 다른 부분

터미널 전용 기능은 설정 → 고급 기능 → 원본 Claude Code 열기에서 사용하세요. Ctrl+B·Ctrl+T·Ctrl+G·Ctrl+D·Ctrl+L·Alt+T·Alt+O와 Esc 두 번의 되감기는 앱의 다른 기능에 연결하지 않습니다.
