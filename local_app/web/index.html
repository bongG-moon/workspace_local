    / 스킬·명령, @ 파일, Tab 자동완성
    Shift+Tab 승인 모드, Ctrl+Enter 보내기

    기존 Claude Code의 로그인·스킬·후크·MCP·모델 설정을 사용해요. 승인의 기본 선택은 ‘이번만 허용’이에요. Claude가 제안한 경우 ‘항상 허용’도 선택할 수 있어요. 현재 연결, 프로젝트 개인 설정, 프로젝트 공유 설정, 내 모든 프로젝트 중 적용 범위와 규칙을 확인해 주세요. 지속 허용은 해당 옵션을 선택하고 승인할 때만 저장돼요. 공유 설정은 파일을 공유하면 다른 사용자에게도 적용될 수 있어요. 기존 설정에서 허용한 동작은 다시 묻지 않을 수 있어요.

    대화는 이 PC의 앱 기록과 Claude 기록에 저장돼요. 자료 처리는 기존 Claude Code 연결과 정책을 따릅니다. 인증 갱신과 일부 터미널 전용 기능은 현재 원본 Claude Code에서 진행해야 해요.

    HTML은 안전한 정적 미리보기를 제공해요. ‘기본 앱에서 열기’를 누르면 원본의 스크립트와 외부 연결이 동작할 수 있어요. Office·PDF·텍스트도 기본 앱에서 확인할 수 있어요. 앱을 종료하려면 ‘설정 → 완전히 종료’를 눌러 주세요.
