- 입력창·대기 요청·중지/재개·화면 상태·릴리즈 이력 회귀 테스트 171개 통과.
- 실제 HTML과 JavaScript를 사용한 Edge UI 검증: 대기 요청 행 32px, 드래그 순서 변경·삭제 요청 전달, 작성 중 입력 유지, 실행 예약과 전체 예약 접근 가능, 브라우저 오류 없음.
- 작업 중 빈 입력/공백에는 지금 반영 숨김, 추가 입력 시 표시, 보내기는 enqueue 처리, 전송 성공 후 다시 숨김 확인.
- EXE에 포함된 171개 파일 압축 해제 검증 및 VBS ZIP과 내용 동일 확인.
- NSIS 설치파일 빌드 완료. 기존 개인 환경에 설치하거나 제거하는 검증은 수행하지 않음.
- 배포 ZIP: 원본 164개 파일과 빌드 자산 7개 검증, 상태/인증정보 포함 없음.
- 격리 데모에서 새 압축 해제본 시작, 버전 0.23.29, 인증 API 경계, 업무 생성·파일 조회·목록 API, 정상 종료 검증.
- 실제 Claude 모델 요청이나 사내 GitLab 배포는 이 검증에서 실행하지 않음.
