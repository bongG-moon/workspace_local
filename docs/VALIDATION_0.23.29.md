# AX Workspace 0.23.29 통합 검증

- 이어 할 일 UI, Ctrl+A 전체 선택, 클릭 누락 수정을 0.23.29에 통합했습니다.
- 대기 요청·HTTP 처리·중지/재개·입력 단축키·릴리즈 이력 회귀 테스트 207개 통과.
- 동일한 브라우저 조건에서 상태 갱신과 겹친 휴지통 클릭: 수정 전 취소 요청 0회, 수정 후 1회.
- 실제 HTML/JavaScript로 삭제 후 목록 제거, 저장된 요청 지금 반영, 입력창 지금 반영, Shift+Enter 줄바꿈 전송, 드래그 순서 변경, 작성 중 초안 보존을 검증했습니다.
- 일반 대화·업무의 여러 줄 한글·이모지 Ctrl+A 전체 선택, 삭제·되돌리기 확인.
- 개인 Claude 환경을 호출하지 않는 회귀 및 격리 데모 검증입니다. 사내 GitLab 실제 배포와 사용자 PC 설치/제거는 실행하지 않았습니다.
- 이미 이전 0.23.29 또는 0.23.30을 설치한 PC에는 버전 비교상 자동 업데이트가 제공되지 않습니다. 수정 설치본을 수동 적용해야 하며, 더 높은 버전이 실행 중이면 먼저 완전히 종료해야 합니다.
