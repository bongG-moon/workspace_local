# AX Workspace 0.23.30 — 응답성·승인 설정·좁은 화면 개선

2026-10-22 저녁 변경 사항입니다.

- **작업 중 화면 응답성:** 닫힌 이어 할 일·예약 관리창의 상세 목록을 반복 생성하지 않고, 긴 답변을 출력할 때 기존 글과 대화 기록을 매번 복제하는 작업을 줄였습니다.
- **도구 활동 중 조작 반응:** 화면용 활동 기록 저장을 짧게 모아 앱 공용 잠금 밖에서 처리합니다. 대기 요청의 변경·전송과 최종 대화 저장은 기존의 즉시 저장을 유지합니다.
- **스킬 화면과 목록 갱신:** 답변 조각마다 스킬 화면의 업무 폴더를 다시 계산하지 않고, 관련 정보가 바뀔 때 갱신합니다. 닫힌 전체 업무 팝업도 열 때만 목록을 생성합니다.
- **업무 전환 후 조회:** 관리자 연결에서 이전 업무의 진행 조회를 정리해 새 업무의 조회가 기다리는 상황을 줄였습니다. 이전 화면의 이미지 요청도 취소합니다.
- **버전 관리:** 버전 원본 한 곳에서 실행기와 진단 값을 생성하고, 빌드 전에 일치 여부를 검사합니다. 과거 릴리즈 설명은 유지합니다.
- **실행 중인 앱 확인:** 같은 버전의 다른 빌드가 실행 중이면 이전 프로세스를 그대로 사용하는 대신 완전 종료 후 새 앱 실행을 안내합니다. 설정에서 실행 중인 빌드 식별값을 확인할 수 있습니다.
- **업무 폴더 승인 유지:** 한 번 명시적으로 승인한 폴더는 앱을 완전히 종료한 뒤에도 같은 폴더인지 확인해 승인을 재사용합니다. 다른 폴더나 교체된 폴더에 승인을 넘기지 않습니다.
- **기본 승인 모드:** 지원되는 업무 연결은 Auto를 기본으로 적용하고, 사용자가 직접 고른 일반 승인 모드는 복원합니다. 적용이 거절되거나 지원되지 않으면 실제 상태를 안내합니다. Bypass 승인은 재시작 때 자동 복원하지 않습니다.
- **일반 대화·업무 버튼:** 한 자리 진행 숫자 공간을 확보해 숫자가 표시되어도 이름이 줄바꿈되거나 아이콘이 밀리지 않도록 했습니다.
- **자료·이번 결과 탭:** 세 자리 숫자 공간을 확보하고 두 탭의 너비를 같게 유지합니다. 실제 개수를 그대로 표시합니다.
- **좁은 채팅 영역:** 창을 줄이거나 우측 패널을 넓히면 입력창 위 이어 할 일·예약 버튼이 다음 줄로 이동해 진행 상태의 표시 공간을 확보합니다. 숨겨진 버튼 때문에 빈 줄이 생기지 않도록 했습니다.
- **개발 소스 안내:** 앱을 개조할 때 참고할 사용 기술과 화면·서버·Windows 창의 소스 위치를 정리했습니다.

기존 대화·대기 요청·예약·작성 중인 입력과 첨부를 유지합니다. 개인 Claude 설정과 회사 정책은 변경하지 않습니다. 별도 상시 진단 수집이나 추가 폴더 감시를 넣지 않았습니다.
