# Workspace 0.15.0 — 일반 Claude Code 앱 사용 범위

0.15.0은 기존 Claude Code를 화면에서 쓰는 기능에 집중합니다. 앱의 실행 이름과 업무 기록 호환성을 유지하며, 특정 하네스의 관리 화면 없이도 질문·첨부·승인·결과·대기 요청·예약을 사용하도록 정리합니다. 기본 사용법은 [로컬 업무 안내](LOCAL_WORKSPACE.md), 실행 준비는 [EXE 안내](WORKSPACE_STANDALONE_EXE.md)를 참고하세요.

## 제거한 전용 기능과 보존하는 설정

Company Agent 전용 학습·기억 관리·설치 등록 기능 및 그 기능을 위한 런타임·배포 의존성을 제외합니다. 사용자의 Company Agent 설치를 제거하거나 해당 플러그인의 설정·기억 데이터를 삭제하는 작업은 아닙니다.

기존 Claude 설정에서 활성화된 Company Agent가 있다면 다른 플러그인과 같은 설치 후보로 조회합니다. 그 플러그인을 실행할지, 어떤 후크와 도구를 적용할지는 기존 Claude 실행 환경이 결정합니다. Workspace가 플러그인의 코어를 설치·업데이트하거나 설정을 대신 작성하지 않습니다.

기존 인증, `CLAUDE_CONFIG_DIR`, 모델·MCP·스킬·플러그인·메모리 설정을 보존합니다. 모델·Effort·승인 선택은 같은 앱 실행 중 해당 업무의 임시 선택입니다. 사용자가 승인 카드의 **항상 허용**을 선택한 규칙은 CLI가 제공한 저장 범위로 전달되며 이 임시 선택과 구분합니다.

## 공통 스킬과 연결 목록

이전 공통 범위에서는 연결 업무 식별자를 제거하면서 도구·연결 서버·명령도 **연결 전**으로 표시했습니다. 공통 설치 범위와 업무 연결의 보고 목록을 분리했습니다.

| 화면 | 표시하는 근거 |
| --- | --- |
| 공통 스킬 | 사용자 공통 Claude 설정에서 발견한 설치 메타데이터 |
| 공통 화면의 연결 기준 업무 | 선택한 업무의 실제 Claude 연결이 보고한 도구·서버·명령 |
| 폴더별 스킬 | 선택 폴더의 설치 후보와 같은 폴더에 속한 업무 연결의 보고 |

현재 연결과 마지막 연결 기록을 구분하고, 서로 다른 폴더나 세션의 목록을 하나로 합치지 않습니다. 같은 폴더의 다른 업무도 공통 화면에서 각각 선택할 수 있습니다. 출처가 다른 동명 스킬은 유지합니다. 설치 후보를 발견했다는 사실만으로 실행 가능하거나 권한이 허용됐다고 표시하지 않습니다.

목록 조회는 업무 전환·실행·폴더 신뢰 승인이 아닙니다. 현재 대화·입력 초안·첨부는 유지합니다. 연결 보고가 나중에 도착하면 선택한 연결의 숫자를 갱신하고, 선택 변경 뒤 도착한 이전 응답은 새 목록에 섞지 않습니다. 미제공 목록은 **미확인**, 실제 빈 목록은 **0**입니다.

## 최근 업무 순서

최근 업무의 이동 손잡이를 끌어 앞뒤 순서를 바꿉니다. 키보드는 손잡이에 초점을 둔 상태에서 **Alt+↑ / Alt+↓**를 사용합니다. 현재 화면에 보이는 같은 고정 그룹 안에서 이동하며, 고정 그룹을 바꾸려면 핀 버튼을 사용합니다.

순서 변경은 앱 상태에 저장합니다. 대화 내용·파일·업무 폴더를 옮기거나 업무를 실행하지 않습니다. 저장하지 못하면 이전 화면 순서로 돌아가고 오류를 안내합니다.

## 자동완성과 승인 모드의 연결 준비

`/` 자동완성과 모델·Effort·승인 목록은 기존 Claude 연결을 준비해 실제 제공 목록을 확인할 수 있습니다. 신뢰 확인이 필요한 폴더에서는 기존 폴더 확인 절차를 따릅니다.

자동완성의 연결 준비와 Shift+Tab이 겹치면 같은 업무의 진행 중인 연결 준비를 공유합니다. 중복 준비가 새 연결을 만들거나 승인 모드를 다시 기본값으로 표시하는 흐름을 막습니다. 준비만으로 작성 중인 질문을 AI에 보내지 않으며, 업무를 바꾸거나 선택창을 닫은 뒤 도착한 이전 응답을 새 화면에 적용하지 않습니다.

Shift+Tab은 현재 연결이 제공하는 일반 모드만 순환합니다. Bypass 진입은 목록에서 명시적인 위험 확인을 거쳐야 하며, 이미 Bypass이면 단축키로 지원되는 일반 모드로 돌아올 수 있습니다. 실제 CLI 적용 응답과 회사 정책을 따르고 개인 기본값을 임의로 바꾸지 않습니다.

## 실행 환경과 호환성

EXE와 VBS 모두 **기존 Python 3.11 이상**을 사용합니다. Python 실행 환경·설치 프로그램을 동봉하거나 다운로드·자동 설치하지 않습니다. AI는 기존 Claude Code 인증을 사용하며 앱 전용 로그인은 없습니다.

**Company-Workspace** 실행 이름, `%LOCALAPPDATA%\CompanyAgent\local-ui` 앱 상태 경로, `%LOCALAPPDATA%\CompanyAgent\workspace-runtime` EXE 캐시는 이전 기록 호환성을 위해 유지합니다. 경로에 남은 이름이 Company Agent의 필수 설치나 전용 기능을 의미하지 않습니다.

다른 버전으로 바꾸기 전에 **완전히 종료**한 뒤 새 묶음을 실행합니다. 창의 X는 화면만 닫으며 대기 요청·예약·업무 연결이 백그라운드에 남을 수 있습니다. 기존 설치 폴더나 개인 설정을 자동 삭제하지 않습니다.

## 검증 상태

이 문서는 0.15.0의 구현 범위와 사용 절차입니다. 빌드·실제 CLI·Windows 화면·회사 PC 실행·공개 다운로드 검증은 이 문서만으로 완료 처리하지 않습니다. 확인 결과는 별도 검증 기록에 남기며, 이전 버전의 성공 기록을 0.15.0의 결과로 옮겨 적지 않습니다.
