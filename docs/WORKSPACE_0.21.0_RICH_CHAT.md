# 0.21.0 대화의 이미지·표·코드와 실행 결과

## 설계 방향

결과를 대화 안에서 먼저 확인하고, 필요한 세부 내용만 펼치는 방식입니다. 기존 밝은 회색·연보라 색상과 Noto Sans KR을 유지하며 코드 영역만 고정폭 글꼴로 구별합니다. 앱의 Claude 인증·승인·모델·스킬 설정은 변경하지 않습니다.

2026-09-30에 확인한 실제 서비스 공식 문서의 다음 흐름을 참고했습니다. 화면을 그대로 복제하거나 같은 실행 환경을 제공한다는 의미는 아닙니다.

| 참고 서비스 | 확인한 흐름 | 이번 앱에 적용 |
| --- | --- | --- |
| [ChatGPT 이미지](https://learn.chatgpt.com/docs/image-generation) | 이미지를 선택해 확대 뷰어에서 확인 | 대화 안의 로컬 이미지와 클릭 확대 |
| [Claude Code Desktop](https://code.claude.com/docs/en/desktop) / [Artifacts](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them) | 대화와 파일·미리보기를 오가며 결과 확인 | 대화의 파일 카드에서 기존 미리보기 열기 |
| [Cursor Agent](https://prod.cursor.com/help/ai-features/agent) | 도구 실행·파일 변경을 확인하고 이어서 요청 | 실제 CLI 명령·결과를 연결한 접이식 실행 카드 |
| [OpenAI Code Interpreter](https://developers.openai.com/api/docs/guides/tools-code-interpreter) | 실행 결과와 생성 파일을 응답에 연결 | 코드 표시와 실제 실행 증거를 분리하고 요청 중 바뀐 파일을 함께 제시 |

OpenAI API나 별도 클라우드 인터프리터를 추가하지 않습니다. 실행은 설치된 Claude Code가 담당하며 기존 승인 경로를 그대로 사용합니다.

## 사용법

- **이미지:** 첨부 이미지, 로컬 Markdown 이미지, 요청 중 바뀐 이미지가 대화 안에 표시됩니다. 누르면 크게 볼 수 있습니다. 외부 이미지 주소는 자동으로 읽지 않고 링크로 표시합니다.
- **표:** Markdown 표와 CSV·TSV 파일을 행·열로 확인합니다. `표 복사`는 화면에 표시된 범위를 탭 구분 텍스트로 복사합니다.
- **코드:** 언어 표시, 기본 문법 색상, 복사, 접기를 제공합니다. Python·JavaScript·TypeScript·JSON·셸·PowerShell·SQL은 기본 색상 구분을 지원하고, 그 외 언어도 고정폭 코드로 표시합니다. 소스 파일은 읽기 전용 미리보기입니다.
- **실행 카드:** Bash·PowerShell 호출 ID에 연결된 명령과 결과를 표시합니다. 기본은 접힌 상태이며 펼칠 때 내용을 만듭니다. 출력은 CLI가 보낸 원문 텍스트이며 별도 stdout/stderr로 추정 분리하지 않습니다.
- **결과 파일:** 요청 전후 관찰된 파일을 해당 대화 아래에서도 확인합니다. 다른 프로그램의 변경이 포함될 수 있으므로 모두 Claude가 작성했다고 표시하지 않습니다.

`실행 요청`은 도구 호출이 보고된 상태입니다. 성공 결과를 받은 경우만 `실행 완료`, 오류 결과는 `실행 오류`, 완료 결과 없이 중단·종료되면 `결과 미확인`입니다. 코드 상자를 보여주거나 복사하는 동작만으로 코드를 실행하지 않습니다.

## 기록과 부하 관리

- 이미지: PNG·JPEG·WebP, 원본 8 MiB 이하, 1,600만 화소 이하. 화면 근처에서만 읽고 동시에 두 파일까지 요청합니다. 이미지 데이터는 최대 네 개만 화면 메모리에 유지하며 대화를 바꾸면 해제합니다. 애니메이션·손상 이미지·한도 초과 파일은 외부 확인 안내로 전환합니다.
- 표: 입력 파일은 1 MiB까지 읽으며 최대 100행·30열을 표시합니다. CSV의 따옴표·필드 안 줄바꿈, UTF-8/BOM·UTF-16·CP949를 처리합니다. 잘림 여부와 복사 범위를 표시합니다.
- 코드: 최대 10만 자. 색상 토큰·Markdown 구조의 복잡도를 제한하고 큰 내용은 일반 텍스트로 표시합니다.
- 실행 기록: 업무별 최근 40개, 합계 30만 자. 명령 8천 자, 설명 240자, 결과 1만2천 자. 바이너리·인라인 이미지 데이터는 기록에 보관하지 않습니다.
- 재시작: 실행 카드와 요청의 연결은 복원하지만, 결과가 없던 요청을 성공 처리하거나 자동 재실행하지 않습니다. 오래된 업무의 본문은 기존 지연 로딩 정책을 따릅니다.

## 지원 범위

실행 카드는 이번 버전부터 앱이 직접 관찰한 최상위 Bash·PowerShell 호출을 대상으로 합니다. 다른 도구·하위 에이전트의 모든 출력, 과거 가져온 Claude 세션의 실행 기록을 재구성하는 기능은 포함하지 않습니다. 원본 이미지 파일은 미리보기를 열 때의 현재 내용이며 과거 시점의 이미지 사본을 저장하지 않습니다. 이미지 자체를 생성하는 도구나 Office 편집기는 이번 변경에 추가하지 않습니다.

파일 접근은 기존 업무 폴더·명시적 첨부 범위의 권한 검사를 사용합니다. HTML 미리보기의 스크립트·외부 연결 차단을 유지하고, 추가된 소스 파일을 외부 앱 실행으로 넘기지 않습니다. 별도 패키지 설치·CDN·인증 없이 동작하는 기본 모듈과 로컬 UI로 구성했습니다.
