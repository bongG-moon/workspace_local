# Company Workspace 0.12.2 입력 사용법과 호환 범위

## 입력창에서 바로 찾기

ChatGPT 데스크톱 앱의 입력창 안에서 명령을 찾고 선택하는 흐름을 참고했습니다. 명령 문법과 실행 주체는 기존 Claude Code를 유지합니다. OpenAI 계정이나 API를 추가하지 않습니다.

| 입력/조작 | 동작 |
| --- | --- |
| `/` 또는 **스킬·명령** | 현재 업무의 Claude가 보고한 호출 목록 |
| `/rep` | `/report`, `/company:report`처럼 이름 앞부분이 맞는 후보를 먼저 표시 |
| 문장 중간의 `/rep` | 선택한 전체 호출명을 문장에 삽입. 시작 위치와 원래 인자를 그대로 Claude에 전달 |
| `@rep` 또는 **파일** | 현재 업무 폴더의 문서·이미지·일반 소스/텍스트 파일을 이름과 경로로 검색 |
| ↑/↓ 또는 Ctrl+N/P | 후보 이동 |
| Tab 또는 Enter | 현재 후보를 입력. 이 조작만으로 질문을 전송하지 않음 |
| Esc | 후보 목록 닫기 |
| Shift+Enter | 줄바꿈 |
| Ctrl+Enter | 작성한 요청 전송 |
| **모델·승인** | 현재 연결의 기존 모델·승인 설정 화면 열기 |

정확히 일치하는 이름, 파일명·호출명 앞부분, 경로·단어 앞부분, 부분 일치 순으로 찾습니다. 명령 설명도 마지막 순위로 검색합니다. 플러그인 명령은 네임스페이스를 생략해 검색해도 전체 호출명을 삽입합니다. 한글 조합형/완성형은 검색에서 정규화하되 실제 파일 경로와 명령은 원문을 보존합니다.

`@`로 파일을 고르면 `@src/report.py`, `@"월간 실적.csv"`처럼 참조가 입력에 남고 첨부 칩도 표시됩니다. 외부 위치의 직접 선택 파일은 전체 경로를 표시합니다. 실제 선택 파일의 전체 경로는 기존 첨부 프로토콜로 함께 전달하므로 공백·한글 파일도 특정할 수 있습니다. 첨부 취소는 해당 자동완성 참조와 칩을 함께 지웁니다. 참조 문구를 직접 편집하는 것과 첨부 취소는 구별됩니다.

## 첫 질문 전에 명령 불러오기

새 업무에서 `/`를 입력한 뒤 **Claude 명령 불러오기**를 누르면, 기존 계정·설정·작업 폴더로 Claude CLI를 초기화합니다. AI 질문을 대신 보내지 않으며 기존 시작 후크와 MCP 초기화는 실행될 수 있습니다. 다시 연 업무의 폴더 신뢰 확인이 필요하면 기존 확인 화면으로 이어집니다. 이 확인을 마쳐도 초안을 자동 전송하지 않습니다.

초기화에서 명령·모델 후보만 제공했다면 실제 선택 모델이나 도구 목록을 추정하지 않습니다. 이후 첫 실제 요청도 같은 연결을 사용합니다. 앱은 최대 세 개의 CLI 연결을 유지하며, 다른 연결을 중지하면 추가로 준비할 수 있습니다.

## CLI와의 경계

- 현재 CLI가 보고한 스킬·사용자 명령·플러그인 명령·MCP 명령과 비대화형 기본 명령을 그대로 전달합니다. 앱이 다른 도구나 자연어 지시로 치환하지 않습니다. `/model` 등의 인자가 필요한 명령은 기존 Claude 문법을 사용합니다.
- `/login`, `/theme`, `/terminal-setup` 등 터미널 UI가 필요한 명령은 앱에서 완전히 동일하게 동작하지 않습니다. 목록에 보고된 경우 터미널 전용임을 표시합니다. 보고되지 않은 명령은 임의로 추가하지 않습니다.
- `!` 셸 모드는 앱에서 AI 요청으로 잘못 전송하지 않고 원본 Claude Code로 안내합니다. 원본 CLI를 열면 작성 중인 앱 입력은 보존되고 자동 실행되지 않습니다. 진행 중인 요청은 먼저 마치거나 중지해야 합니다.
- 폴더 자체·다른 Claude 세션·임의 바이너리·숨김 파일의 `@` 후보까지 CLI와 전부 같지는 않습니다. 추천은 현재 업무 및 직접 선택한 파일에 한정하고, 깊이·개수·시간 제한과 링크 제외 규칙을 유지합니다. 사용자가 직접 입력한 참조와 명령은 CLI가 처리합니다.
- 자동완성에 소스 파일을 추가한 것이 스크립트를 실행하거나 외부 앱에서 여는 허용으로 이어지지 않습니다. Office·HTML 등 기존 외부 앱 열기 범위는 유지합니다.
- 설치 후보만으로 호출 가능하다고 가정하지 않으며, 스킬 탭에서 조회 중인 다른 폴더의 목록을 현재 입력에 섞지 않습니다.

앱 시작·기존 인증·Windows 조건은 [0.12.1 호환성 안내](WORKSPACE_0.12.1_COMPATIBILITY.md)를 유지합니다. 이 변경은 Claude 인증, 개인 모델·MCP·스킬 설정, UAC 및 영구 PowerShell 정책을 변경하지 않습니다.
