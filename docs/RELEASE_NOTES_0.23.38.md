# AX Workspace 0.23.38 — 오류 확인 안내 개선

- **오류 확인 안내:** Claude 연결 및 인증, 모델 사용 권한과 요청 처리 오류가 발생하면 오류 안내의 **확인할 사항**에서 가능한 원인과 순서대로 확인할 방법을 볼 수 있습니다. 표시된 오류만으로 원인을 확정하기 어려운 경우에는 그 점도 안내합니다.
- **사용 설명서:** 도움이 필요할 때 자주 발생하는 Claude 연결과 요청 처리 오류별로 초보자도 따라 할 수 있는 확인 및 조치 방법을 추가했습니다. KEY나 토큰은 전달하지 않도록 안내합니다.
- **확장 화면:** 확장 기능이 작업을 처리할 때 기존 화면을 밀지 않도록 상태 안내 위치를 정리했습니다.

오류 안내는 문제 확인을 돕는 정보이며, 요청을 자동으로 재실행하거나 인증 및 개인 설정을 변경하지 않습니다. 오류 처리 전에 이미 실행된 작업과 파일 변경을 확인하세요.
