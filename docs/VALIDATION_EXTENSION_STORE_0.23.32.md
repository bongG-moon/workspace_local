# 선택 확장 연결부 추가 검증 — 0.23.32

이번 갱신은 업무 목록 선택·등록 파일 선택·내장 글꼴 공유를 범용 연결부에 추가합니다. 조직별 서버 주소나 KEY는 기본 앱에 포함하지 않습니다.

- 확장·프런트엔드·정적 글꼴 HTTP 경계 검사 54개 통과. 파일 토큰의 확장/작업 제한, 15분 만료, 파일 변경, 다른 경로 접근, 취소, 미설치 확장의 무실행을 확인했습니다.
- 파일 선택은 ZIP·MD·AXEXTENSION·EXE·MSI·PS1 한 개, 64MiB 이하이며 확장이 임의 경로를 지정할 수 없습니다. 파일 본문과 경로는 iframe에 전달하지 않으며 서버의 검증된 작업 문맥에만 넣습니다.
- 기존 글꼴 한 파일만 sandbox iframe에서 읽을 수 있도록 허용합니다. API·다른 정적 파일·임의 경로의 CORS 권한은 확대하지 않았습니다. 실제 브라우저에서 Noto Sans KR 로딩과 등록 요청 UUID 생성을 확인했습니다.
- 실제 앱과 격리 iframe의 카탈로그·상세·좋아요·파일 받기·업무 선택 설치·복구·초안 유지·라이트/다크·좁은 화면 검증을 통과했습니다. 플랫폼 데이터만 합성 자료이며 개인 KEY와 실제 설치 프로필은 쓰지 않았습니다.
- 별도 스토어의 등록·파일 검사·연결·설치·패키징 160개 회귀 검사도 통과했습니다. 등록은 서버 초안→사용자 웹 승인→등록 완료 순서를 따르며 중복 재시도와 만료 승인을 확인했습니다.

새 연결부는 명시적인 사용자 조작 때만 동작합니다. 상주 worker·추가 주기 조회·전체 폴더 탐색을 넣지 않았습니다. 실제 운영 서버·VDI·보안 정책 확인은 운영 환경에서 별도 진행해야 합니다.
