# Company Workspace 0.12.0 검증 기록

검증일: 2026-09-29. R01~R14의 구현과 개발 환경 검증을 기록한다. 실제 회사 PC에서만 확인할 수 있는 실행·알림·문서 연계는 별도로 남긴다. 사용자 경로·실제 업무 내용·인증 정보는 포함하지 않는다.

전체 회귀는 `python -X utf8 scripts/test-lab/test-workspace.py`로 실행했고, `build/qa-workspace-0.12.0-tests.json`의 `success=true`, 실패·오류 빈 목록을 확인했다. 최초 보고서 후처리 오류를 수정한 뒤 재실행하여 보고서까지 생성했다. 보고서 생성 실패를 시험 성공 증거로 사용하지 않았다.

전체 실행의 생략 7건은 심볼릭 링크 생성 권한 3건, 명시적 opt-in이 필요한 Windows 사용자·제한 토큰 시험 3건, 그 실행 환경에서 WSH 기본 실행을 확인하지 못한 VBS 중복 안내 시험 1건이다. 뒤의 4건은 실제 사용자 환경에서 각각 다시 실행하여 모두 통과했다. 따라서 심볼릭 링크 생성 권한 3건은 여전히 생략이며, 합성 reparse/junction 차단 시험은 통과했다. 현재 사용자 실행기 3건은 sandbox 계정과 실제 로그인 사용자를 혼동하지 않도록 전체 실행과 분리했다.

## 브라우저에서 직접 확인한 흐름

임시 업무와 가상 CLI로 다음을 확인했다. 가상 응답을 실제 회사 모델 결과로 취급하지 않았다.

- 업무 생성 없이 공통 스킬 목록 조회, 폴더 미선택 안내, 한글·경로 표시.
- 디자인 카드 10개가 한 번 표시되고, 뉴모피즘을 한 번 클릭하면 사용자 선택과 다음 응답이 각각 한 번 표시됨.
- 승인 모드 변경의 가상 CLI 응답이 화면에 반영됨.
- 전체 대기 배지에서 다른 업무의 질문으로 이동하고 거절 후 배지가 해제됨.
- `/test-skill` 추천 삽입, `@확인`으로 한글 파일을 한 번 첨부하고 입력 토큰 제거.
- HTML 미리보기에서 기본 앱·위치 보기·메모장 버튼 표시. 실제 외부 앱의 문서 열람은 실행하지 않음.

## 설정 보존과 배포 경계

기존 Windows UAC·보안·계정 설정, Claude 인증·개인 모델·MCP·스킬·기억 설정을 변경하지 않았다. 시험은 임시 상태·등록·파일을 사용하고, 기존 사용자 메타데이터는 읽기만 했다. 사용자 검사 실패를 피하려고 실행기 검사를 완화하지 않았다.

Workspace ZIP과 Company Agent 코어는 별도 배포다. R12·R13 및 R14 일부의 코어 변경은 저장소 소스와 격리 시험에만 적용했다. Workspace ZIP이 설치 코어를 자동 갱신하거나, 기존 설치에서 해당 기능이 이미 동작한다고 주장하지 않는다. 상세 조건은 [0.12.0 사용 범위와 호환성](WORKSPACE_0.12.0_COMPATIBILITY.md)을 따른다.

실제 회사 모델 요청, 업무 결과물 품질, 회사 Office·보호 문서, 실제 Edge 점멸·브라우저 알림, UAC-off VBS 전체 실행과 복수 모니터 DPI 수용시험은 남아 있다.

## 실행용 ZIP

파일: `dist/company-workspace-preview-0.12.0-20260929-195240.zip`

SHA-256: `943075298834b03c92a5ad8a3870f2a9a5e8b9c51cb24925bdfc3f16fb8fdbe9`

패키지 검사에서 허용 파일 59개의 현재 소스 일치, 상태 파일 미포함, 진단 helper 해시 4개 일치를 확인했다. 별도 임시 폴더에 압축을 풀고 그 위치에서 실제 로그인 사용자로 `python -m local_app.server --demo`를 실행했다. 원래 소스의 서버를 재사용하지 않고 다음을 확인했다.

- 버전 0.12.0, 실행 앱 루트가 새 추출 경로, 비어 있는 격리 상태.
- 인증 없는 요청의 403 응답과 인증된 API 응답.
- HTML·JavaScript·한글 글꼴·안내서를 포함한 자산 8개 제공.
- 임시 업무와 파일 생성, 파일 목록·attention·catalog API.
- 인증된 API 종료와 runtime 파일 정리.

결과는 `build/qa-workspace-0.12.0-bundle.json`에 기록했다. 이 시험은 추출된 Python 진입점의 demo 실행이며, 회사 PC에서 VBS부터 실제 Claude 요청까지 수행한 시험은 아니다. 최종 독립 검토도 완료했다. 커밋·푸시·공개 업로드·메일 발송은 이 검증에 포함하지 않는다.
