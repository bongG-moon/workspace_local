# AX Workspace 0.23.42 — 불필요한 대화 기록 안내 개선

0.23.41 수정본의 개선 내용을 0.23.42로 배포합니다. 사내에 이미 0.23.41을 배포한 경우에도 새 버전으로 구분해 게시하고, 기존 앱에서 업데이트를 확인할 수 있습니다.

- **자동 확인 안내:** 대화를 선택할 때 추가 Claude 기록을 확인하지 못해도 오류 안내를 표시하지 않습니다. 같은 세션에 추가된 대화가 확인된 경우에만 **대화 내용 불러오기** 버튼을 표시합니다.
- **직접 불러오기:** 사용자가 버튼을 눌렀을 때의 실패 안내는 유지합니다. 기록이 일치하지 않으면 임의로 합치지 않으며 기존 대화, 작성 중인 입력과 첨부를 보존합니다. 주기적인 조회나 자동 재시도는 추가하지 않습니다.
- **사내 배포 검사:** XLS 판독기 파일을 검사 목록에서 누락해 발생하던 `bundle-check` 오류 수정과, 릴리즈 빌드의 필수 검사도 포함합니다.
- **기존 개선 유지:** XLS 첨부와 WS-47의 시스템 DPI 호환성 개선을 포함합니다. 기존 업무 폴더, 대화와 확장 연결을 유지하며 P&T AI Square 확장과 플랫폼은 기존 배포본을 사용합니다.

설치 파일은 `AX-Workspace-0.23.42-Setup.exe`, 사내 반입용 소스는 `workspace-local-0.23.42-source.zip`입니다. 기존 업데이트용 EXE 및 VBS ZIP과 호환 파일명도 제공합니다.
