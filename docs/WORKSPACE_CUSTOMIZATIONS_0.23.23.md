# Claude 설정 명령과 자동 목록 확인

2026-10-13 · AX Workspace 0.23.23

## 사용자 동작

- `/model`, `/model 모델명`, `/permissions`는 기존 연결 설정 UI/API를 사용한다. `/effort`의 기존 동작을 유지한다.
- `/skills`, `/plugin`은 관리 화면을 연다. 스킬·기능 화면의 ‘스킬·플러그인 관리’에서도 접근한다.
- 설정 명령은 AI 질문이나 이어 할 일에 등록하지 않는다. 작업 중 모델 변경은 요청 종료까지 제한하고, 승인 변경은 실제 연결의 지원 여부를 따른다.
- 스킬은 `skillOverrides`의 네 가지 상태와 범위 지정 해제를 제공한다. 원본 SKILL.md를 복사·편집하지 않으며 꺼진 스킬도 관리 목록에 남는다.
- 플러그인은 기존 Claude 실행 경로를 통해 공식 `plugin enable/disable --scope` 명령을 실행한다. 설치·삭제는 수행하지 않는다.
- 기본 범위는 프로젝트 로컬이다. 사용자 공통 변경은 영향 범위를 확인한다. 프로젝트별 플러그인 설정이 있으면 CLI가 공통 범위 변경을 거절할 수 있어 해당 범위의 선택을 잠근다.
- 관리 정책과 원본 제한을 존중한다. 앱의 스킬 설정 쓰기는 검증 대상으로 삼은 CLI 2.1.260 이상에서 제공한다. 조직 정책의 최종 적용 여부는 실제 CLI가 결정한다.
- 저장과 현재 연결 적용을 구분한다. 0.23.24 추가 보완에서는 저장 직후 재연결 여부를 묻는다. ‘지금 적용’은 관리창에 표시된 업무만 재연결하며, 작업 중에는 중지 및 대기열·예약 일시정지를 한 확인창에서 안내한다. ‘나중에’는 저장값과 기존 연결을 유지하고 관리창의 ‘저장한 설정 적용’ 또는 해당 업무 상단의 재시작 버튼으로 나중에 적용한다.
- 조회 기준 업무가 현재 채팅과 달라도 정확한 대상만 재연결한다. 저장 실패는 재연결하지 않고, 재연결 실패는 저장값을 유지하며 다시 시도할 수 있다. 확인 대기 중 업무 전환·창 닫기는 늦은 실행을 막고, 확인 후 새 작업이 시작된 경우에는 별도의 중지 동의를 받는다.
- 같은 폴더나 공통 설정을 사용하는 다른 연결은 그대로 유지한다. 이 연결들도 각각 다시 시작해야 새 설정을 불러온다. 재개 대화의 과거 지침이나 플러그인과 독립적으로 등록된 후크·스킬은 삭제하지 않는다.

## 관리창 표시와 도움말

- 탭과 저장 범위를 두 줄로 나누고, 라이트·다크 및 좁은 창에서 가로 넘침을 확인했다.
- 프로젝트 범위는 ‘공통·기존 설정 따르기’, 사용자 공통은 ‘스킬 기본 설정 따르기’로 표시한다. 별도 지정 해제는 선택한 범위의 값만 제거하며 프로젝트 설정·회사 정책은 계속 우선할 수 있다.
- 옵션 아래 짧은 설명과 접는 도움말을 제공한다. 범위 변경만으로 설정을 저장하지 않으며, 스킬 상태 저장 계약과 플러그인 옵션은 유지한다.

## 자동 조회 및 자원 사용

- 실행 기능·MCP·빠른 요청 탭에서 선택한 업무만 연결한다. 범위·기준 업무 변경 시 다시 조회한다.
- 이미 열린 연결과 준비 중인 연결 요청을 재사용한다. 미확인 폴더는 자동 신뢰하지 않는다.
- 전환 직후 150ms 지연으로 빠른 변경을 합치고, 실패 반복을 30초 동안 억제한다. 시도 기록은 최대 16개다. 상시 폴링은 추가하지 않는다.
- 취소된 화면 및 이전 조회 응답은 현재 화면을 덮어쓰지 않는다. 관리 화면 목록은 최초 100개만 그리며 더 보기를 제공한다.
- 목록 조회를 위한 가상 AI 요청을 보내지 않는다. CLI가 첫 요청 이후에만 제공하는 목록은 ‘CLI 미제공’으로 구분한다.
- 플러그인 관리 보조 프로세스는 숨김·시간 제한·출력 크기 제한을 적용하고 앱 종료 시 취소한다. 프로세스 트리는 기존 소유 프로세스 관리 방식으로 정리한다.

## 검증

- 0.23.23 최종 회귀: 324 통과, 환경 조건 3개 제외. 기능·서버·Windows 시작·실행 권한 표시·브랜드 패키지·배포 이력·소스 ZIP 검사를 포함한다.
- EXE 내장 추출 검증 및 EXE/VBS 공통 149개 파일 일치 확인. ZIP을 새 폴더에 풀어 격리된 체험 상태로 서버 시작·새 정적 모듈·API 인증·업무 생성·정상 종료를 확인했다.
- 관리창 표시 변경 후 기존 프런트엔드 5개 검사와 범위 전환 시 라벨·도움말 동기화, 설정 쓰기 없음, 플러그인 옵션 유지 검사를 확인했다.

- 관련 자동 테스트: 207 통과, 1 환경 조건으로 건너뜀. 설정 보존·충돌·원본 제한·범위·실패 안내·API 인증·신뢰 경계·실행 중 상태·화면 전환 경합·명령 입력을 포함한다.
- 실제 설치 CLI 2.1.296: 별도 임시 프로필에서 검증용 플러그인의 사용자 공통/프로젝트 로컬 enable 및 disable을 확인했다. 개인 프로필을 변경하지 않았고 AI 요청을 보내지 않았다.
- 실제 브라우저: `/skills` 열기, 스킬 끄기 및 다시 켜기, `/model` 선택 및 적용, 실행 기능 탭 자동 연결, 다크 모드 화면을 확인했다.
- 브라우저 검증용 CLI 기록: initialize 1회, user prompt 0회. 연결을 반복 생성하지 않았다.
- 운영 PC의 회사 래퍼·서버 관리 정책·실제 MCP 인증 및 모든 CLI 버전에서의 동작은 이번 격리 검증에 포함하지 않는다.
