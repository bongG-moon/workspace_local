# AX Workspace 0.23.27 — UI 환경 개선·간편 화면·업데이트 이력

2026-10-18

사내 운영 버전 **0.23.26 이후의 개선 사항을 모두 포함한 통합 릴리즈**입니다. UI 개선, 일반 대화, 간편 화면과 릴리즈 노트 이력 확인 기능을 0.23.27의 변경 사항으로 제공합니다.

- **UI 환경 개선:** 채팅창의 라이트·다크 색상을 정리하고 일반 본문을 13px·줄 간격 25px로 맞췄습니다. 상단 버튼은 32px로 통일하고, 사이드바·설정·팝업·결과 파일 목록의 글자 크기·요소 크기·여백과 정렬을 다듬었습니다.
- **간편 화면:** 다크모드 옆 아이콘으로 업무 목록과 채팅 중심 화면을 켜고 끕니다. 현재 업무, 작성 중인 글과 첨부, 모델·승인 설정, 진행 중인 작업과 예약은 유지합니다. 화면 설정은 다음 실행에도 복원합니다.
- **릴리즈 노트 이력:** 설정 → 앱 업데이트 → 업데이트 내역에서 버전별 변경 내용을 확인합니다. 최신 버전에서도 열 수 있으며, 이력을 보는 것만으로 설치하거나 Claude에 연결하지 않습니다. 최근 조회 결과를 재사용하고, 연결이 안 되어도 저장된 이력과 앱에 포함된 내용을 볼 수 있습니다.
- **기존 사내 배포 기록:** 배포 도구가 같은 GitLab 프로젝트에 남아 있는 이전 배포 채널·릴리스·패키지 기록을 가져옵니다. 사내 배포 시 작성하거나 수정한 설명을 우선 반영하고 출처와 날짜를 구분합니다. 파일만 확인되면 ‘당시 배포 설명을 확인할 수 없습니다’라고 표시합니다. 과거 기록 조회는 시간·개수·용량을 제한해 처리합니다.
- **일반 대화 / 업무 전환:** 폴더를 고르지 않고 질문하거나 첨부 자료로 대화할 수 있습니다. 일반 대화의 모델을 선택할 수 있고, 대화를 삭제하면 앱의 기록·첨부 사본·전용 폴더를 정리합니다. 원본 파일과 기존 업무는 유지합니다.
- **자료와 결과:** 우측 패널 너비를 드래그로 조절합니다. 열려 있을 때는 패널 안의 닫기 버튼만, 닫혀 있을 때는 중앙 상단의 열기 버튼만 표시합니다. HTML 미리보기는 창 너비에 맞추고 코드 영역은 남는 높이를 사용합니다.
- **ZIP 자료 표시 보완:** 업무 폴더의 ZIP 파일도 우측 자료 목록과 변경 결과에 표시합니다. 새로고침으로 추가·삭제된 파일을 반영하고, 선택한 ZIP은 기본 앱이나 폴더에서 확인할 수 있습니다. 목록 조회 시 압축 내용을 읽거나 풀지 않습니다. 자료가 없을 때의 안내도 짧은 제목과 설명으로 정리했습니다.
- **입력과 설정:** 확대·축소할 때 현재 비율을 안내합니다. 자동 포커스의 불필요한 테두리를 줄이고 키보드 탐색 표시는 유지합니다. 스킬·기능 조회 대상을 바꾸면 자동 확인하고 연결과 목록을 재사용합니다. 스킬·플러그인 설정 적용 안내도 보완했습니다.
- **업데이트 안내:** 업데이트 준비·앱 종료·새 화면 준비 과정을 표시하고 새 화면이 준비되면 대기창을 닫습니다. 진행창의 글꼴과 크기를 정리하고 사용 도움말을 현재 동작에 맞췄습니다.

기존 Claude Code 인증과 업무 환경을 사용합니다. 일반 대화는 앱이 첨부 내용을 전달하고 파일 탐색·수정·명령 실행 도구를 제한하는 별도 연결입니다. 기존 업무의 도구·승인 정책은 유지합니다.

### 다운로드와 업데이트

[설치 파일](https://github.com/bongG-moon/workspace_local/releases/download/v0.23.27/AX-Workspace-0.23.27-Setup.exe) · [사내 반입용 소스 ZIP](https://github.com/bongG-moon/workspace_local/releases/download/v0.23.27/workspace-local-0.23.27-source.zip)

GitHub의 Setup·직접 EXE는 NSIS 설치 파일입니다. EXE/VBS ZIP은 기존 실행기와 앱 자동 업데이트용으로 함께 제공합니다. 기존 0.23.26 사용자는 앱의 새 버전 확인으로 업데이트할 수 있습니다.

앱 실행에는 기존 Python 3.11 이상과 최신 Claude Code 설치·인증, 기존 Windows 실행 환경이 필요합니다. Python이나 Claude Code를 함께 설치하지 않습니다. 설치 파일로 갱신할 때는 트레이에서 기존 앱을 완전히 종료한 뒤 설치하세요.

사내 GitLab은 이 소스 ZIP으로 **0.23.26 → 0.23.27** 배포를 별도로 진행해야 합니다. 같은 서버·프로젝트에 새 패키지와 채널 정보를 게시하면 기존 사내 최신 설치용 `AX-Workspace-Install.exe`가 새 버전을 확인합니다. 기존 채널과 ZIP 업데이트 방식은 유지합니다. 이전 기록은 서버의 보존 상태와 토큰 권한에 따라 가져오며 삭제된 설명은 복원할 수 없습니다. 실제 사내 GitLab에는 접속하지 않았으며 모의 서버로 검증했습니다.
