# Workspace 0.12.3: 입력하는 즉시 표시되는 자동완성

## 사용 방법

입력창에서 `/` 또는 `/sk`를 입력하면 **입력창 바로 위에 후보 이름과 설명이 표시**됩니다. 별도의 목록 불러오기 버튼을 누르는 과정은 기본 흐름에서 제거했습니다.

- 홈 화면: 현재 PC에 설치된 공통 스킬의 호출명과 설명을 표시합니다. 특정 업무 폴더의 설정을 임의로 가져오지 않습니다.
- 업무 선택 후: 해당 업무 범위의 후보를 표시합니다. 이미 신뢰를 확인한 업무는 처음 `/`를 입력할 때 기존 Claude CLI를 자동 초기화하고, 연결이 보고한 명령으로 목록을 갱신합니다.
- 초기화는 AI 질문을 전송하지 않습니다. 선택한 업무의 기존 시작 후크와 MCP 초기화는 실행될 수 있습니다. 아직 신뢰하지 않은 폴더의 CLI는 자동 시작하지 않습니다.
- `공통 스킬`·`폴더 스킬` 표시는 설치 정보에서 발견한 후보입니다. `Claude` 표시는 현재 연결이 보고한 후보입니다. 설치 정보만으로 현재 연결에서 실행됐다고 단정하지 않습니다.
- ↑/↓로 이동하고 Tab·Enter 또는 마우스 클릭으로 선택합니다. 명령은 입력창에만 삽입되며 Ctrl+Enter 또는 보내기로 요청합니다. 플러그인은 전체 호출명을 삽입합니다.
- `@`는 선택한 업무 폴더의 파일을 추천합니다. 홈에서는 업무 폴더 선택 안내를 표시합니다.
- 후보가 없거나 목록 확인이 실패해도 입력창 위에 이유를 표시합니다. 연결 실패 시 반복 재시도하지 않으며, 불러오기 버튼으로 다시 시도할 수 있습니다.

Claude 연결 중에도 계속 입력할 수 있습니다. 다른 업무로 이동하거나 입력창에서 벗어나거나 Esc로 목록을 닫았다면 늦은 연결 응답이 입력을 덮거나 포커스를 빼앗지 않습니다.

## 이전 구현에서 보완한 부분

0.12.2는 업무를 선택하기 전 자동완성 처리를 중단했고, 새 연결의 명령도 수동으로 불러와야 했습니다. 따라서 홈 입력창에 `/skill`을 적어도 아무 목록이 나타나지 않는 사용 흐름이 있었습니다. 기존 검증은 업무를 이미 선택한 상태에 편중돼 이 경로를 빠뜨렸습니다. 0.12.3은 홈부터 검증합니다.

자동완성 목록의 범위는 CLI 전체 화면과 같지 않을 수 있습니다. 터미널 전용 명령과 `!` 셸 모드의 경계는 [기존 입력 안내](WORKSPACE_0.12.2_INPUT.md)를 참고하세요. 앱은 Claude 개인 인증·모델·MCP·스킬 설정이나 PC 보안 정책을 변경하지 않습니다.
