# AX Workspace 0.23.32 — 응답 복구·화면 개선과 선택 확장 지원

## 2026-10-25 — 확장 ZIP 직접 가져오기

- **앱 안에서 설치:** 설정 → 추가 기능 → 확장 ZIP 가져오기에서 패키지 이름·버전·기본 서버·설치 위치를 확인한 뒤 현재 계정에 설치합니다. 가져오는 동안 확장 코드를 실행하지 않습니다.
- **기존 내용 보존:** 같은 확장을 갱신해도 기존 연결 정보·개인 KEY·대화·작성 중인 내용은 유지합니다. 설치 후 추가 메뉴를 갱신하며, 사용 중인 확장은 종료한 뒤 교체하도록 안내합니다.
- **파일 검증:** ZIP 크기·경로·선언 파일·해시를 검사하며, 잘못된 경로나 수정된 기존 설치를 덮어쓰지 않습니다. Windows 긴 하위 경로를 처리하고 실행이 불가능한 작업 경로는 설치 전에 안내합니다.
- **별도 조직 배포:** P&T AI Square 확장은 별도 설치 EXE 없이 ZIP으로 제공합니다. 운영자가 서버 주소를 지정한 ZIP을 웹에 직접 등록하고, 사용자는 공통 앱으로 가져온 뒤 개인 KEY를 입력합니다. 공개 소스·공통 앱에 사내 주소나 개인 KEY를 넣지 않습니다.

## 2026-10-25 — 선택 확장 지원

- **범용 확장 연결부:** 필요한 기능을 별도 설치 패키지로 추가할 수 있습니다. 설치된 확장의 메뉴를 선택하면 전용 화면을 열며, 기존 업무·대화·작성 중인 요청은 유지됩니다.
- **미설치 사용자 유지:** 확장을 설치하지 않으면 추가 메뉴·확장 화면 자산·worker·플랫폼 요청이 생성되지 않습니다. 확장 작업용 상주 프로세스나 주기 조회도 추가하지 않습니다.
- **별도 조직 기능:** P&T AI Square의 화면·개인 KEY 연결·다운로드·설치 기능은 [ai_square 저장소](https://github.com/bongG-moon/ai_square)의 별도 확장과 웹 배포본으로 제공합니다. 공통 앱에는 조직별 서버 주소나 KEY를 넣지 않습니다.
- **기존 상태 보존:** 확장 화면을 열거나 닫아도 현재 업무와 작성 중인 내용은 유지합니다. 설치 범위는 사용자가 선택하며, 확장 작업이 중단됐을 때 같은 변경 요청을 자동으로 재실행하지 않습니다.

버전은 **0.23.32**를 유지합니다. 이전 0.23.32 설치본에는 확장 연결부가 없을 수 있으므로, 같은 버전을 사용 중인 경우 트레이에서 앱을 **완전 종료**한 뒤 최신 설치 파일로 다시 설치하세요. 기존 업무·대화·초안·예약과 개인 Claude 설정은 유지됩니다.

## 2026-10-24 — 응답 복구와 이어 할 일·안내 화면 개선

- **누락된 응답 화면 복구:** 화면의 이벤트 수신이 밀려 보관 범위를 벗어나면 서버의 현재 대화 상태로 답변과 진행 내용을 복원합니다. 작성 중인 입력·첨부와 승인·질문의 입력 상태를 보존하며, 요청을 자동으로 다시 보내지 않습니다.
- **파일 확인 중 버튼 반응성:** 요청 완료 후 파일 변경을 확인하는 동안 다른 업무의 취소·대기 목록 조작이 함께 기다리던 구간을 줄였습니다. 확인 결과는 원래 요청과 일치할 때 반영하며, 같은 업무의 중복 실행을 방지합니다.
- **결과로 이어서 요청:** ‘이 결과로 요청’으로 추가한 파일도 초안에 저장합니다. 첨부 한도를 확인하고, 추가되지 않은 파일을 성공으로 안내하지 않습니다.
- **이어 할 일 안내와 배치:** 전송 확인이 필요한 요청의 이유와 확인 동작을 입력창 위에서 바로 제공합니다. 이어 할 일 목록 아래에 진행 상태·도구 이름·경과 시간·답변 중지 버튼을 배치했습니다.
- **답변 중지 버튼:** 주변 요소에 맞는 작은 크기를 유지하면서 테두리·배경·중지 아이콘으로 구분합니다.
- **선택 목록 디자인:** 설정, 스킬·플러그인, 실행 예약 등에서 사용하는 선택 목록의 높이·여백·선택 표시를 정리했습니다. 지원 환경에서 앱 색상에 맞는 목록을 표시하고 기존 키보드 선택과 비활성 항목 동작을 유지합니다.
- **설정과 사용 안내:** 창을 숨기는 동작을 ‘최소화하기’로 안내합니다. 사용 안내서 상단에 바로 시작하는 세 단계를 배치하고, 과도한 줄바꿈·그라데이션·카드 배경색을 정리했습니다.
- **안내서 아이콘 통일:** 설정·도움말·소개 페이지의 안내서 링크와 안내 목차를 펼친 책 아이콘으로 통일했습니다.

기존 업무·대화·초안·예약 및 Claude 개인 설정을 사용하는 방식은 유지합니다. 이번 변경은 운영 환경의 모든 연결 오류를 해결했다는 의미는 아닙니다.
