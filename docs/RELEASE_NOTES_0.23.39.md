# AX Workspace 0.23.39 — 결과 확인과 요청 복구 안내 개선

## 2026-11-01 동일 버전 갱신

- **결과 파일 찾기:** 제한된 파일 확인 범위 안에서 하위 폴더의 결과를 확인하고, 보고서 파일을 먼저 표시합니다. 보조 파일은 **전체 변경 파일 보기**에서 확인할 수 있습니다. 확인 범위를 넘긴 경우 화면에 안내합니다.
- **이전 요청 확인:** 완료 기록을 확인하지 못한 요청이 있는 대화에는 **진행 내용 보기**와 **자료에서 파일 확인**을 표시합니다. 좁은 창에서도 자료 패널을 열며, 이전 요청을 자동으로 재전송하지 않습니다.
- **미리보기와 예약 기록:** HTML 미리보기의 동작 범위를 안내하고, 예약의 일시정지와 재개 기록을 실제 실행 결과와 구분합니다.
- **기존 작업 보존:** 작성 중인 입력과 첨부, 기존 대화와 파일은 유지합니다. 파일 확인의 시간과 개수 상한을 유지하며 상시 폴더 감시는 추가하지 않습니다.

버전은 **0.23.39**로 유지한 재빌드입니다. 같은 버전을 사용 중이면 새 버전 알림이 나타나지 않을 수 있으므로 앱을 트레이에서 완전히 종료한 뒤 새 설치 파일로 적용하세요.

관련 회귀시험과 라이트 및 다크 모드, 좁은 창의 실제 화면을 검증했습니다. 사내 운영 서버와 VDI 환경에서는 별도 확인이 필요합니다. P&T AI Square의 설치 목록, 검색 및 등록 초안 개선은 별도 확장과 플랫폼 릴리즈에 포함됩니다.

## 기존 0.23.39 변경 내용

- **인증 오류 확인 방법:** Claude 인증 오류가 표시되면 PowerShell에서 대화형 실행과 CMD를 통한 요청을 확인하고, 앱에서 선택한 모델과 Claude 기본 모델을 살펴볼 수 있도록 안내를 보완했습니다.
- **사용 설명서:** 같은 확인 절차를 사용 설명서의 도움이 필요할 때 항목에도 추가했습니다. 확인 과정에서 KEY나 토큰 값을 전달할 필요는 없습니다.

오류 안내는 확인을 돕는 정보이며, 인증 설정이나 개인 설정을 자동으로 변경하지 않습니다.
