# AX Workspace 0.23.45 — HTML 프로젝트 웹 미리보기

2026-11-15에 HTML과 연결된 파일을 함께 확인하는 **웹** 보기를 추가했습니다. 기존의 빠른 **화면** 보기와 **코드** 보기도 계속 사용할 수 있습니다.

## HTML을 웹페이지처럼 확인하기

- 탐색창에서 HTML을 열고 **웹**을 누르면 허용한 업무 폴더의 CSS, 이미지, 글꼴, JavaScript와 로컬 JSON 데이터를 함께 불러옵니다. JS 모듈과 상대 경로 import도 지원합니다.
- **화면**은 스크립트를 실행하지 않는 정적 미리보기입니다. **웹**에서는 페이지의 메뉴, 탭, 버튼과 그래프 등 연결된 동작을 확인할 수 있습니다. **코드**에서는 선택한 HTML의 현재 원문을 확인합니다.
- 같은 웹 탭을 다시 누르거나 **넓게 보기 / 팝업으로 보기**로 이동할 때 실행 화면과 스크롤을 유지하며 파일을 불필요하게 다시 읽지 않습니다.
- 웹 화면을 열 수 없으면 안내를 표시합니다. 기존 **화면 / 코드 / 기본 앱에서 열기 / 폴더에서 보기**로 파일을 계속 확인할 수 있습니다.

## 필요한 순간에만 불러오기

- 웹 탭을 선택할 때만 관련 파일을 읽습니다. 폴더 전체를 미리 읽거나 상시 감시하지 않으며, 별도의 미리보기 서버나 상주 작업 스레드를 추가하지 않습니다.
- 큰 HTML과 CSS는 나누어 처리하고, 변환 결과가 커지면 임시 파일을 사용합니다. 파일 본문이나 이미지를 별도 메모리 캐시에 계속 쌓지 않습니다.
- 파일 요청 수, 전송량과 이미지 크기에 한도를 두었습니다. 파일이나 업무를 바꾸거나 **화면 / 코드**로 전환하거나 미리보기를 닫으면 실행 화면과 접근 권한을 정리합니다. 진행 중인 파일 변환도 읽기 구간마다 취소 여부를 확인합니다.
- 웹페이지 자체의 복잡한 JavaScript에는 추가 메모리와 처리 시간이 필요할 수 있습니다. 기존의 가벼운 화면 보기를 기본으로 유지합니다.

## 기존 업무 범위 유지

- 기존에 확인한 업무 폴더 안의 파일만 함께 엽니다. 폴더 밖에서 별도로 첨부한 HTML은 주변 파일 접근 권한을 자동으로 넓히지 않으며, 일반 대화의 기존 화면과 코드 보기 범위도 유지합니다.
- 실행 중인 웹 화면은 앱 화면과 분리됩니다. 앱 API, 외부 통신, 새 창, 작업 실행이나 파일 쓰기를 위한 앱 기능을 제공하지 않습니다. 원본 HTML과 관련 파일도 수정하지 않습니다.
- 외부 CDN, 로그인이나 API 서버, 별도 빌드와 개발 서버가 필요한 웹은 완전히 동작하지 않을 수 있습니다. 개발 서버를 자동 실행하거나 의존성을 설치하지 않습니다.
- HTML과 CSS의 `/assets/...` 같은 경로는 연 HTML이 있는 폴더를 기준으로 처리합니다. JavaScript 안의 `fetch('/data.json')`처럼 서버 루트를 전제로 한 요청 경로는 자동으로 바꾸지 않습니다. 로컬 데이터는 프로젝트 파일 기준의 상대 경로를 사용하세요.
- 기존 자료 탐색, CSV와 TSV 원본 표, 줄 번호와 코드 색상, 파일 변경 비교 및 대화 기능은 유지합니다.

## 차이를 확인하는 예시

**AX-Workspace-0.23.45-Web-Preview-Example.zip**에 가상 생산 보고서와 CSS, 이미지, JS, JSON 예시를 제공합니다. 전체를 같은 폴더에 풀고 그 폴더를 업무로 연 다음 HTML의 **화면 / 웹**을 비교하세요.

- 화면 탭에서는 연결 안내와 비활성화된 범위 버튼을 보여 줍니다.
- 웹 탭에서는 공정 그림과 디자인을 불러오고 **전체 105건 / 처음 100건 / 검사 공정**을 눌러 최대값과 그래프를 바꿀 수 있습니다.
- 전체 105건의 최대값은 **2,400개**, 처음 100건과 검사 공정의 최대값은 **1,480개**입니다. 체험용 가상 데이터의 로컬 사본이며, 버튼을 눌러도 원본 CSV와 기존 보고서 수치는 바뀌지 않습니다.

## 설치와 배포

- Windows 설치: **AX-Workspace-0.23.45-Setup.exe**
- 사내 반입과 재빌드: **workspace-local-0.23.45-source.zip**
- 기존 업데이트용 EXE와 VBS ZIP, 호환 파일명, 진단 도구와 **SHA256SUMS.txt**도 함께 제공합니다.

업데이트 전에는 진행 중인 업무가 없는지 확인하고 앱을 완전히 종료하세요. 기존 대화, 업무 자료와 개인 Claude 설정은 유지합니다. 사내 사용량 조회 주소와 업데이트 주소는 해당 조직의 배포 설정을 사용해야 하며 공개 파일에는 운영 주소나 KEY를 넣지 않습니다.
