# AX Workspace 0.23.27 배포 전 검증

검증일: 2026-10-18. Windows 환경에서 Python 3.13.5, Node 24.19.0, NSIS 3.12를 사용했습니다.

## 자동 회귀 검사

표준 `scripts/test-lab/test-workspace.py` 전체 검사: **2843개 실행, 2792개 통과·49개 건너뜀·2개 실패, 오류 0개**. 발견한 두 항목을 아래와 같이 처리한 후 **관련 모듈 12개 검사를 모두 재통과**했습니다. 건너뛴 항목은 별도 환경이나 명시적 실행이 필요한 검사이며 통과 수에 포함하지 않았습니다.

1. 실행기 버전 변경에 맞춰 시작 진단 해시를 UTF-8 BOM 제거·LF 줄바꿈 정규화 기준으로 동기화했습니다. 최종 소스로 번들 검사 모듈 5개를 재검증하고 EXE·ZIP·설치본을 다시 빌드해 실제 배포 파일 검사도 통과했습니다.
2. 종료 중 연결 대기를 검증하는 기존 테스트의 호출 기대값에 명시적인 `_catalog=False`를 반영했습니다. 사용자 연결과 목록 조회 연결을 구분하는 기존 제품 동작은 유지하며, 해당 종료 검사 모듈 7개를 재통과했습니다.

전체 검사의 원본 결과와 보완 후 모듈 재검증 결과를 구분해 보존했습니다. 최종 검증은 영향받은 모듈과 새 배포 파일을 대상으로 수행했습니다.

- HTML 미리보기 보충 검사: 15개 실행, 13개 통과·선택 의존성 검사 2개 건너뜀.
- 현재 사용자 실행기 검사: 3개 모두 통과. 임시 상태 폴더와 가짜 CLI, `-NoBrowser`로 실행했습니다.
- 처음 실행한 격리 환경에서는 테스트용 임시 폴더 접근 권한 오류가 발생했습니다. 해당 테스트 프로세스만 중지하고 동일한 가짜 CLI·개인 상태 미사용 조건으로 정상 사용자 환경에서 다시 검사했습니다. 위 결과는 재실행 결과입니다.

실제 Claude·알림·트레이·네이티브 창 등 별도 opt-in 검사는 이번 전체 검사에서 활성화하지 않았습니다. 회사 인증·MCP·DRM·Office와 실제 AI 응답을 모두 재검증했다는 뜻은 아닙니다.

## 화면 검증

2026-10-17에 최종 기능 소스로 실행한 간편 화면 23개와 우측 패널 12개, 총 **35개 브라우저 시나리오**가 통과했습니다. 페이지 오류는 0개였습니다. 이후 릴리즈 준비에서는 앱 버전·시작 진단 해시·문서와 배포 검증 도구를 갱신했습니다.

- 일반/간편 화면, 라이트/다크, 넓은/좁은 화면에서 넘침 없이 표시.
- 간편 화면 전환 시 업무·입력·첨부·연결·승인·진행 중 응답 유지. 빠른 전환의 저장 요청 병합과 포트 변경 후 복원 확인.
- 자료 패널이 열리면 내부 닫기 버튼만, 닫히면 중앙 상단 열기 버튼만 표시. 키보드 동작과 포커스 이동 확인.
- 패널 드래그·최소/최대 폭·취소·키보드 조절·너비 저장 및 복원 확인.

일반 대화·첨부의 앞선 실제 CLI 검증과 성능 측정은 [2026-10-16 기록](VALIDATION_CHAT_MODES_LOCAL.md)에 날짜와 범위를 구분해 보존했습니다.

## 실제 배포 파일

- 독립 실행 EXE를 새로 빌드하고 `--verify-only`로 내장 파일 **167개**를 검증했습니다.
- EXE 내장 내용과 자동 업데이트용 VBS ZIP의 **167개 파일**이 바이트 단위로 일치합니다.
- ZIP 허용 목록 검사에서 소스 **160개**와 고정된 WebView2 빌드 자산 **7개**를 확인했습니다. 시작 진단이 사용하는 네 파일의 정규화된 해시도 일치합니다.
- 압축을 푼 실제 서버를 빈 임시 상태의 demo/no-browser 모드로 실행했습니다. 버전 0.23.27, 인증 없는 API 거부, 정적 화면·한글 폰트·도움말, 업무 생성·파일 목록·알림·카탈로그 API가 통과했습니다. 정상 종료 코드 0과 runtime 파일 정리까지 확인했습니다.
- NSIS 설치 파일은 정식 제품 ID, 사용자별 설치, 파일 버전 0.23.27.0으로 컴파일했습니다. 테스트용 설치 ID를 사용하지 않았습니다. 이번 검증에서 사용 중인 앱에 실제 설치·제거를 수행하지 않았습니다.
- Python·Claude Code·개인 인증·대화 상태를 배포 파일에 포함하지 않습니다.
