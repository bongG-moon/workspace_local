# 0.19.0 대화 중심 화면 배치

## 변경 내용과 이유

상단 제목 줄과 입력창 주변 높이를 줄여 대화 본문에 더 많은 공간을 줍니다. 기존 밝은 색감과 부드러운 그림자는 유지합니다. 업무 화면에는 제목과 폴더 정보가 남고 홈의 중복 부제만 생략합니다.

- 좌측 최근 업무는 제목 한 줄을 기본으로 표시합니다. 선택한 행은 연보라 음영으로 구분하고 고정한 업무에는 핀을 표시합니다. 상태·날짜·경로는 툴팁, 응답 필요 수는 작은 배지와 접근성 이름으로 제공됩니다. 드래그·Alt+방향키 순서 변경은 유지합니다.
- 좌측 상단 접기 버튼은 탐색 영역을 아이콘 레일로 줄입니다. 새 업무·이전 대화·빠른 실행·홈·스킬·설정·도움말에 계속 접근할 수 있습니다. 우측 상단 버튼은 자료·결과 영역을 펼치고 접습니다.
- 넓은 창에서 선택한 패널 상태는 앱의 `workspace.layout.v1` 화면 저장소에만 저장됩니다. 창 폭 1,100px 이하의 우측 패널과 700px 이하의 좌측 패널은 임시 오버레이로 열립니다. 화면 폭 변경은 넓은 창의 저장된 선택을 덮어쓰지 않습니다.
- 임시 패널은 바깥 클릭·Esc로 닫힙니다. 열린 패널 안에서 키보드 포커스를 유지하고 닫으면 호출 버튼으로 돌아갑니다. 명령 팔레트를 열 때 임시 패널을 닫아 모델 선택 등이 가려지지 않게 합니다. 자동완성·모드 선택 메뉴·기존 대화상자의 Esc 처리를 존중합니다.
- **이어 할 일·실행 예약**은 입력창 위 버튼으로 옮겼습니다. 파일 드래그 안내와 하단의 반복 설명은 제거했습니다. 파일 드래그·첨부 기능과 관련 안내는 기존 동작을 유지합니다.

새 반복 조회, 파일 감시기, 별도 실행 프로세스나 라이브러리는 추가하지 않았습니다. 패널 레이아웃은 CSS와 화면 폭 변경 이벤트로 처리합니다. 숨긴 우측 패널은 키보드 탐색에서도 제외합니다. 업무 기록·Claude 연결과 개인 설정·Windows 설정을 변경하지 않습니다.

## 검증 범위

- 전체 회귀 검사 **1,007개 실행: 975개 통과, 32개 명시적 생략, 실패·오류 0개**. 생략은 선택적 Company Agent 연동, 심볼릭 링크 권한, Windows 네이티브 opt-in 및 샌드박스의 VBS 실행 제한 등에 해당합니다. 별도 현재 사용자 실행을 요구하는 실행기 검사 3개는 이 수치에 포함되지 않습니다.
- 패널 전용 9개와 팔레트 10개 검사에는 저장된 선택, 저장소 차단·손상, 좁은 화면·크기 변경, Esc·Tab 포커스, 모드 선택·자동완성과의 키보드 충돌, 오버레이에서 Ctrl+K로 모델·Effort·스킬 화면에 진입하는 경로를 포함합니다. 이 검사는 위 전체 수치의 일부입니다.
- 실제 Windows WebView2 데모 창에서 최대화·복원, 제목 중심 업무 목록·선택 음영·핀, 좌측 아이콘 레일, 양쪽 패널 접기, 좁은 창의 우측 오버레이, 입력창 위 이어 할 일 버튼의 대화상자, 패널 → Ctrl+K → 스킬 화면의 정상 포커스를 확인했습니다. 데모 메시지만 사용했습니다.
- 0.19.0 단일 EXE를 EXE만 있는 한글·공백 경로에서 시작하여 전용 WebView2 창, 반복 실행의 동일 서버·캐시 재사용, 기존 Python 3.13.5와 Claude Code 2.1.285 탐지를 확인했습니다. 기존 Claude 인증으로 초기화하고 명령 141개를 받았으며 사용자 업무 메시지는 보내지 않았습니다. 검사한 개인 설정 파일 5개는 변경되지 않았습니다.
- EXE와 VBS ZIP의 앱 구성 92개(소스 85개·고정된 네이티브 빌드 파일 7개)가 동일했습니다. `layout.js`의 정적 제공·배포 포함도 확인했습니다. 런타임 기록·인증 파일·Python 실행 파일은 포함하지 않습니다. VBS ZIP을 새 폴더에 해제한 뒤 데모 API의 시작·자료 조회·정상 종료 검사도 통과했습니다.

700px 이하 좌측 오버레이의 실제 마우스 조작과 모든 모니터 배율 조합은 수동 검증 범위 밖이며, 좁은 좌측 패널의 상태·키보드 처리는 자동 검사로 확인했습니다. 저장된 패널 선택은 현재 앱 웹 화면의 origin에 속하므로 앱을 완전히 종료해 새 포트로 시작하면 초기 배치로 돌아갈 수 있습니다. 기존 사용자 작업과 실제 AI 업무 전체를 다시 실행했다는 의미는 아닙니다.

단일 EXE SHA-256: `ae4ad060293becefe49dbc7888af3685b9c61ae84a5c0aa9fec62e8ccc4addb4`.

## 업데이트와 사용

기존 앱을 **설정 → 완전히 종료** 또는 트레이의 **완전 종료**로 닫은 후 `Company-Workspace-0.19.0.exe` 또는 VBS 묶음을 실행합니다. 창의 X는 트레이로 숨기는 동작입니다. 기존 Python·Claude Code·WebView2 실행 조건은 유지하며 자동 설치하지 않습니다.

좌측 위 목록 아이콘으로 업무 목록을 접고 펼칩니다. 우측 위 패널 아이콘으로 자료·결과를 표시합니다. 좁은 창에서는 Esc나 패널 바깥을 눌러 대화 화면으로 돌아옵니다.
