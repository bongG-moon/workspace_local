# AX Workspace 0.23.41 — 대화 확인 안정화, XLS 첨부와 WS-47 호환성 개선

- **자동 이어하기 중 대화 확인:** 이전 요청 완료와 다음 예약 요청의 시작이 겹칠 때 정상적인 상태 변경을 외부 도구 오류로 표시하던 문제를 수정했습니다. 작업 중인 자동 확인은 보류하며, 현재 요청과 맞지 않는 늦은 결과는 적용하지 않습니다. 실제 외부 대화가 추가된 경우의 불러오기 기능은 유지합니다.
- **XLS 첨부:** 일반 대화와 업무에서 이전 Excel 형식인 `.xls` 파일을 선택하거나 끌어다 첨부할 수 있습니다. 일반 대화는 시트 이름과 저장된 셀 값을 읽습니다. 매크로, 수식과 외부 링크를 실행하지 않으며 서식, 차트와 이미지는 추출하지 않습니다. 일반 대화의 XLS 한도는 8 MiB입니다. 손상 파일 처리와 내부 데이터 및 메모리 사용 한도도 추가했습니다.
- **WS-47 화면 초기화:** Windows 10 LTSC 2019 환경에서 보고된 WebView2 DPI 호환성 문제를 개선하기 위해 전용 창의 매니페스트를 시스템 DPI 인식으로 변경했습니다. 실패 단계와 HRESULT를 진단 기록에 남기고, 오류 안내에 화면 표시 호환성을 포함했습니다. 오류 원문이나 인증정보는 기록하지 않습니다.

시스템 DPI 방식은 배율이 서로 다른 모니터 사이로 창을 옮길 때 글자가 덜 선명해질 수 있습니다. 이번 로컬 기동 검증은 Windows 11과 WebView2 156.0.4314.58에서 수행했으며, 문제가 발생한 LTSC PC에서는 새 설치 파일로 확인해야 합니다. 모든 WS-47을 DPI 문제로 단정하지 않습니다.

설치 파일은 `AX-Workspace-0.23.41-Setup.exe`, 사내 반입용 소스는 `workspace-local-0.23.41-source.zip`입니다. 기존 EXE 및 VBS 업데이트 ZIP과 호환 파일명도 제공합니다. 사내 배포 담당자는 새 소스로 사내 서버의 배포 파일을 갱신해 주세요.

기존 대화, 초안, 업무 폴더와 확장 연결은 유지됩니다. P&T AI Square 확장과 플랫폼은 기존 배포본을 사용할 수 있습니다.
