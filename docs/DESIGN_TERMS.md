# 디자인 용어 참고

“깔끔하게”, “세련되게”만으로 원하는 모양을 설명하기 어려울 때 참고하세요. 첨부된 스타일 키워드 이미지 3장의 **30개 용어**를 쉬운 설명과 요청 예문으로 정리했습니다. 용어를 외울 필요 없이 마음에 드는 느낌 하나를 골라 쓰면 됩니다.

이 용어집은 **분위기를 설명하는 참고자료**이며, 30개 디자인 기능이 새로 추가됐다는 뜻은 아닙니다. 표의 예문은 모양을 설명하는 말이지 메뉴 선택 명령이 아닙니다. 메뉴에 없는 스타일은 가까운 선택지와 구현 가능한 범위를 먼저 확인하세요.

## 1. 원하는 디자인을 쉽게 요청하는 법

**용도 + 스타일 하나 + 색·글자·여백 + 결과 형식**을 함께 말하면 좋습니다. 서로 다른 스타일을 많이 섞기보다 기본 분위기 하나에 강조 효과 하나만 더해 보세요.

```text
팀 회의에서 볼 HTML 보고서를 만들고 싶어.
미니멀·스위스 느낌으로, 흰 배경과 짙은 글자, 넓은 여백을 사용해줘.
핵심 숫자만 크게 강조하고 본문은 Noto Sans KR로 읽기 쉽게 해줘.
현재 제공되는 디자인 중 가까운 선택지로 제안해줘. 참고 파일은 없어.
```

회사 자료에는 장식보다 읽기 쉬운 글자, 명확한 숫자·단위, 충분한 대비가 우선입니다. 예쁜 배경 때문에 본문이 희미해지지 않도록 요청하세요. 이 가이드의 본문 글꼴은 외부 다운로드 없이 표시되는 Noto Sans KR입니다.

## 2. 기본 분위기와 정보 강조

| 용어 | 쉽게 말하면 · 어울리는 용도 | 모양을 설명하는 요청 예문 |
| --- | --- | --- |
| **그라디언트 배경** (Gradient background) | 색이 자연스럽게 이어지는 배경입니다. 표지나 구역 구분에 쓰고, 긴 본문 뒤에서는 은은하게 사용합니다. | “표지에 연한 하늘색과 보라색이 이어지는 배경을 넣고 본문은 흰색으로 해줘.” |
| **글래스모피즘** (Glassmorphism) | 반투명 유리처럼 보이는 카드입니다. 배경색이 비치고 얇은 테두리나 흐림 효과가 깊이감을 줍니다. | “유리 같은 카드를 쓰되 글자가 비치지 않게 바탕을 충분히 밝게 해줘.” |
| **미니멀·스위스** (Minimal / Swiss style) | 미니멀은 불필요한 장식을 줄이는 방향, 스위스 스타일은 격자 정렬과 글자 위계를 중시하는 방향입니다. 업무 보고서에 활용하기 좋습니다. | “장식은 줄이고 제목·수치·본문을 격자에 맞춰 정렬해줘. 여백은 넉넉하게 해줘.” |
| **다크 모드** (Dark mode) | 어두운 바탕과 밝은 글자를 쓰는 화면입니다. 여기서는 색 표현을 뜻하며 테마 전환 버튼이 자동으로 생기는 것은 아닙니다. | “검정에 가까운 남색 바탕에 밝은 글자를 쓰고, 표와 보조 설명도 선명하게 해줘.” |
| **그레인 텍스처** (Grain texture) | 종이나 필름처럼 미세한 입자감을 더합니다. 차분한 소개 자료에 어울리며 글자 위에 거친 무늬를 겹치지 않습니다. | “배경에만 아주 약한 종이 입자감을 넣고 표·글자 주변은 깨끗하게 유지해줘.” |
| **빅 타이포** (Big typography) | 핵심 단어나 숫자를 크게 보여주는 방식입니다. 한 장에 메시지 하나를 강조할 때 좋습니다. | “핵심 수치 하나를 크게 보여주고, 단위와 비교 기준은 바로 아래에 붙여줘.” |

## 3. 카드와 입체감

| 용어 | 쉽게 말하면 · 어울리는 용도 | 모양을 설명하는 요청 예문 |
| --- | --- | --- |
| **플랫 디자인** (Flat design) | 그림자와 질감을 줄이고 단순한 색 면·선·아이콘으로 표현합니다. 정보가 많은 화면을 정리하기 좋습니다. | “질감과 그림자를 빼고 색 면과 가는 구분선으로 정보 구역을 나눠줘.” |
| **플랫 2.0** (Flat 2.0) | 평면적인 구성을 유지하면서 필요한 곳에만 약한 그림자나 깊이감을 더합니다. 별도의 프로그램 버전명은 아닙니다. | “전체는 평면적으로 만들고 누를 수 있는 버튼과 중요한 카드에만 약한 그림자를 줘.” |
| **머티리얼 디자인** (Material Design) | 면이 층층이 놓인 것처럼 높이와 그림자로 관계를 표현하는 디자인 체계입니다. 그림자 하나만 넣는 것과는 다릅니다. | “카드·버튼의 간격과 높이감을 일관되게 해줘. 중요한 조작은 구분하기 쉽게 보여줘.” |
| **클레이모피즘** (Claymorphism) | 점토처럼 둥글고 부풀어 보이는 형태입니다. 부드러운 하이라이트와 그림자를 쓰며 친근한 안내에 어울립니다. | “소개 카드에 둥근 점토 느낌을 약하게 적용하고 본문 표는 평평하고 또렷하게 해줘.” |
| **스큐어모피즘** (Skeuomorphism) | 나무·가죽·실제 버튼 같은 사물의 재질과 모양을 닮게 표현합니다. 단순한 그림자 효과와 구분합니다. | “표지에만 종이 노트 같은 재질감을 쓰고, 본문은 실제 노트 그림이 아닌 편집 가능한 글자로 해줘.” |
| **3D 렌더** (3D render) | 입체 물체를 조명·재질·그림자와 함께 그린 이미지입니다. 실제 3D 모델링이나 편집 기능이 있다는 뜻은 아닙니다. | “표지에 부드러운 입체 장식을 원해. 실제 이미지가 필요한지, 현재 도구로 가능한 표현은 무엇인지 먼저 알려줘.” |

## 4. 글자와 그래픽을 강하게 쓰는 표현

| 용어 | 쉽게 말하면 · 어울리는 용도 | 모양을 설명하는 요청 예문 |
| --- | --- | --- |
| **키네틱 타이포그래피** (Kinetic typography) | 글자의 움직임과 시간 차로 메시지를 강조합니다. 정적 HTML·PDF·PPT 이미지에서는 같은 움직임을 전달할 수 없습니다. | “글자로 변화감을 강조하고 싶어. 정적 보고서에서는 움직임 대신 굵기·크기·배치로 표현해줘.” |
| **구성주의** (Constructivism) | 사선, 기하학 도형, 강한 색 대비로 방향성과 힘을 줍니다. 표지나 캠페인 메시지에 어울립니다. | “표지에 빨강·검정·흰색과 사선 도형을 쓰되, 본문 글자와 표는 수평으로 정렬해줘.” |
| **아르데코** (Art Deco) | 대칭, 기하학 무늬, 반복되는 직선으로 정돈된 장식미를 표현합니다. 격식 있는 표지에 활용할 수 있습니다. | “짙은 배경에 얇은 금색 계열 선과 대칭 구성을 쓰고, 본문에는 장식을 줄여줘.” |
| **팝 아트** (Pop Art) | 선명한 색, 굵은 외곽선, 만화 같은 점 무늬를 사용합니다. 짧은 홍보나 주목을 끄는 표지에 어울립니다. | “핵심 문구에 원색과 굵은 선을 쓰고 점 무늬는 제목을 가리지 않는 여백에만 넣어줘.” |
| **멤피스 디자인** (Memphis design) | 낙서 같은 선과 작은 도형, 서로 대비되는 색을 자유롭게 배치합니다. 활기찬 행사·교육 안내에 어울립니다. | “행사 안내 표지에 작은 원·삼각형·물결선을 넣고 일정표 주변은 비워줘.” |
| **브루탈리즘(웹)** (Brutalism) | 구조를 드러내고 거칠거나 덜 꾸민 인상을 주는 표현입니다. 굵은 선과 원색을 쓰는 변형도 있지만 항상 같은 모양은 아닙니다. | “꾸밈을 줄이고 제목·표·버튼의 경계를 확실히 해줘. 굵은 테두리와 대비는 필요한 곳에만 써줘.” |

## 5. 차분하고 자연스러운 표현

| 용어 | 쉽게 말하면 · 어울리는 용도 | 모양을 설명하는 요청 예문 |
| --- | --- | --- |
| **스칸디나비안** (Scandinavian) | 밝은 바탕, 부드러운 중성색, 자연스러운 재료 느낌을 사용합니다. 편안한 소개 자료에 어울립니다. | “흰색·연한 베이지·차분한 초록을 쓰고 여백을 넓게 해줘. 나무 질감은 꼭 필요할 때만 넣어줘.” |
| **저팬디** (Japandi) | 절제된 구성과 따뜻한 자연색을 조합하는 방향입니다. 낮은 색 대비를 쓰더라도 글자는 선명해야 합니다. | “저팬디 느낌의 차분한 베이지와 회색, 넓은 여백을 원해. 글자 대비는 충분히 유지해줘.” |
| **와비사비** (Wabi-sabi) | 불규칙함과 자연스러운 재료의 흔적을 살리는 미적 태도입니다. 자료의 오류나 어긋난 정렬을 허용하라는 뜻은 아닙니다. | “표지의 장식만 자연스럽고 비정형적으로 하고, 수치·표·정렬은 정확하게 유지해줘.” |
| **아르누보** (Art Nouveau) | 식물 줄기 같은 유기적인 곡선과 장식 무늬를 사용합니다. 감성적인 표지나 구역 장식에 어울립니다. | “가느다란 식물 곡선을 모서리에만 넣고 본문 글꼴과 표는 간결하게 해줘.” |

## 6. 복고와 미래적인 표현

| 용어 | 쉽게 말하면 · 어울리는 용도 | 모양을 설명하는 요청 예문 |
| --- | --- | --- |
| **프루티거 에어로** (Frutiger Aero) | 맑은 하늘색·초록, 물방울, 광택 같은 요소로 밝고 깨끗한 기술 이미지를 표현합니다. | “하늘색과 초록을 중심으로 밝은 기술 느낌을 주고, 물방울·광택 장식은 표지에만 작게 써줘.” |
| **레트로 퓨처리즘** (Retrofuturism) | 과거 사람들이 상상한 미래의 모습을 표현합니다. 둥근 기계 모양, 복고 색감 등 참고 방향을 구체적으로 지정하면 좋습니다. | “크림색·주황·청록과 둥근 모서리로 복고적인 미래 분위기를 내고 수치는 현대적인 표로 정리해줘.” |
| **Y2K** | 은빛 금속, 광택, 파스텔 등으로 세기 전환기의 디지털 분위기를 표현하는 이름입니다. 모든 요소를 동시에 쓸 필요는 없습니다. | “은빛과 연보라 포인트로 디지털 느낌을 주고, 본문에는 금속 효과나 반짝임을 넣지 마.” |
| **베이퍼웨이브** (Vaporwave) | 분홍·보라·청록, 해 질 무렵의 색 변화, 복고 디지털 요소를 조합합니다. 표지에 소량 적용하기 좋습니다. | “분홍·보라·청록이 이어지는 복고 디지털 표지를 원해. 본문은 단색 바탕에 정리해줘.” |
| **사이버펑크** (Cyberpunk) | 어두운 배경 위 네온색과 기술적인 요소를 강조합니다. 빛나는 글자를 많이 쓰면 읽기 어려워질 수 있습니다. | “검정에 가까운 배경에 청록 포인트를 쓰고, 네온은 구분선에만 적용해줘. 본문은 빛 번짐 없이 해줘.” |
| **미드센추리 모던** (Mid-century modern) | 단순한 기하학 형태와 머스터드·청록·주황 같은 따뜻한 색 조합을 활용합니다. 친근한 소개 자료에 어울립니다. | “크림색 바탕에 머스터드와 청록을 포인트로 쓰고, 단순한 도형과 넓은 여백으로 구성해줘.” |

## 7. 유리 표현을 더 구체적으로 말하기

글래스모피즘과 아래 두 표현은 비슷한 재료감을 설명하지만 같은 효과를 보장하는 이름은 아닙니다.

| 용어 | 쉽게 말하면 · 어울리는 용도 | 모양을 설명하는 요청 예문 |
| --- | --- | --- |
| **아크릴** (Acrylic) | 배경 흐림에 반투명 색과 미세한 질감을 겹친, 뿌연 유리판 같은 표현입니다. 특정 제품의 효과가 그대로 구현된다는 뜻은 아닙니다. | “뿌연 반투명 패널 느낌을 원해. 흐림 효과를 지원하지 않으면 읽기 좋은 불투명 패널로 바꿔줘.” |
| **리퀴드 글래스** (Liquid Glass) | 곡면 유리처럼 가장자리의 하이라이트와 배경 굴절을 강조하는 표현입니다. 단순한 투명 카드보다 복잡합니다. | “곡면 유리 같은 가장자리 표현을 참고해줘. 굴절을 구현하기 어렵다면 단순한 테두리와 그림자로 표현하고 한계를 알려줘.” |

## 8. 기본 디자인 메뉴와는 어떻게 다른가요?

기본 HTML 제작 스킬에는 **10개 디자인 메뉴**가 있습니다. 아래는 용어집과 가까운 메뉴를 연결한 예이며, 새로운 메뉴나 추가 기능을 등록하는 표가 아닙니다.

| 참고 용어 | 가까운 기본 메뉴 | 구분할 점 |
| --- | --- | --- |
| 미니멀·스위스 | 미니멀리즘 | 간결한 출발점입니다. 스위스 스타일의 모든 규칙을 자동 적용하지 않습니다. |
| 글래스모피즘 | 글래스모피즘 | 배경 흐림은 표시 환경에 따라 달라질 수 있습니다. |
| 그라디언트 배경 | 그라디언트 메시 | 여러 색이 번지는 표현입니다. 모든 그라디언트와 같은 것은 아닙니다. |
| 브루탈리즘(웹) | 브루탈리즘 | 기본 메뉴는 굵은 선과 강한 대비를 쓰는 준비된 양식입니다. |
| 3D 렌더 | 3D·이머시브 | CSS 입체 장식입니다. 실제 3D 모델·렌더링·회전 뷰어 기능이 아닙니다. |
| Y2K | 레트로·Y2K | 준비된 복고 디지털 양식이며 모든 금속·광택 효과를 지원하지는 않습니다. |

나머지 용어는 현재 기본 메뉴에 독립 항목으로 들어 있지 않습니다. 특히 **클레이모피즘·스큐어모피즘·뉴모피즘은 서로 다른 표현**입니다. 이름이 비슷하다는 이유만으로 같은 스타일을 선택하지 마세요. 실제 선택 순서는 [업무별 사용법](USER_GUIDE.md)을 참고하세요.

HTML의 흐림·굴절·움직임은 인쇄/PDF나 편집 가능한 PPT에서 달라지거나 생략될 수 있습니다. 지원하지 않는 효과는 단순화할지 먼저 확인하고, 편집 가능한 PPT를 요청했다면 전체 슬라이드 이미지만 넣는 방식으로 대신하지 않도록 합니다.

## 9. 바로 응용할 요청 예문

**설명 도표:** 흐름도는 순서·의존성, 구성도는 구성 요소의 관계, 스윔레인은 담당별 인계, 상태 전이도는 조건에 따른 상태 변화를 보여줍니다. 숫자 비교용 차트와는 다릅니다. 작업을 마친 뒤 설명을 요청할 때 사용하며, 재생은 설명 강조일 뿐 실제 작업 실행이 아닙니다.

### 차분한 업무 보고서

```text
방금 정리한 내용을 보통 분량의 스크롤 HTML 보고서로 만들어줘.
기본 메뉴의 미니멀리즘을 사용하고 핵심 수치만 빅 타이포로 강조해줘.
Noto Sans KR, 밝은 배경, 짙은 본문 글자, 넓은 여백을 원해.
실제 자료의 수치·단위·출처는 바꾸지 말고 최종 HTML 한 파일로 전달해줘.
```

### 메뉴에 없는 분위기를 참고하고 싶을 때

```text
저팬디의 차분한 색과 넓은 여백을 참고하고 싶어.
현재 제공되는 디자인 중 가까운 선택지와 구현 가능한 범위를 먼저 알려줘.
결과는 편집 가능한 PPT로 원해. 글자와 숫자를 이미지로 바꾸지 마.
아직 파일은 만들지 말고 내 선택을 기다려줘.
```

### 디자인을 고르기 어려울 때

```text
같은 가상 내용으로 미니멀한 느낌과 글래스모피즘 느낌의 차이를 설명해줘.
팀 회의에서 읽기 쉬운 쪽을 추천하고, 이유는 글자 대비·정보량·PPT 변환 기준으로 알려줘.
아직 파일을 생성하거나 양식·기억에 저장하지 마.
```
