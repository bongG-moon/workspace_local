# AX Workspace 0.23.47 — 보관 업무 초안 처리와 사번 안내 개선

## 보관한 업무는 초안 저장을 건너뜁니다

업무를 보관하면 해당 업무의 초안을 저장 대기열과 화면 복구 대상에서 제외합니다. 보관 뒤 늦게 도착한 저장 요청도 정상적으로 건너뛰어 다른 업무의 요청, 앱 종료와 업데이트를 막지 않도록 했습니다.

- 현재 업무와 일반 대화의 초안은 계속 저장합니다. 이 초안의 실제 저장 실패는 기존처럼 안내하고 입력을 보호합니다.
- 기존 대화, 작업 파일과 보관 전에 이미 저장한 초안은 유지합니다. 업무를 복원하면 다시 초안을 저장할 수 있습니다.
- 보관 직전에 완료된 저장의 응답이 늦게 도착해도 최신 저장 번호를 유지해 복원 후 저장 충돌을 방지합니다.
- 업무 보관 확인창에 보관한 업무의 초안은 자동 저장하지 않는다는 안내를 추가했습니다.

이 처리를 위해 상시 감시나 주기적인 API 호출은 추가하지 않았습니다. 기존 초안 조회와 저장 요청 안에서 보관 상태를 확인합니다.

## 사번 안내를 더 분명하게 표시합니다

최초 사번 등록창과 업데이트창에 **사번 (7~8자)**를 표시하고, 글자 수는 **현재 7자**처럼 안내합니다. 8자를 모두 채워야 하는 것처럼 보이던 `0 / 8자` 표시는 사용하지 않습니다. 앞뒤 공백을 제거한 최대 8자 입력 조건은 유지합니다.

저장된 사번이 있으면 다음 업데이트에서는 입력창을 띄우지 않습니다. 안내 문구도 유지합니다.

> 설치 또는 업데이트가 완료되면 결과를 한 번 전송합니다.
>
> 이 집계 기능은 평소 앱 사용 중 사용 정보를 수집하지 않습니다.

## 사내 배포 PY에서 인증키를 입력합니다

0.23.46에 별도 수정 소스로 제공했던 배포 화면 연결을 이번 전체 소스에 포함합니다. `Publish-Workspace.py`에서 **설치 현황 집계 사용**을 켜고 **집계 인증키**에 웹 서버의 `PTAI_AX_REGISTRATION_KEY`와 같은 값을 입력한 뒤 **배포하기**를 누르세요. 빌드만 할 때는 고급 설정의 **빌드만 하기**를 사용합니다.

GitLab 게시용 토큰과 집계 인증키는 별개입니다. 키는 마스킹 표시하고 설정 저장, 소스 게시와 진행 기록에서 원문을 제외합니다. 새 배포 창에서 새 설치 파일을 만들 때는 다시 입력합니다. 기본 웹 주소를 바꿀 때만 **설치 현황 집계 웹 주소**를 수정합니다. 기존 웹의 집계 API와 MongoDB 설정은 그대로 사용합니다.

공개 설치 파일에는 실제 인증키가 없으며 집계 기능은 기본으로 꺼져 있습니다. 실제 키가 포함된 파일은 사내 배포에만 사용합니다.

설치 파일은 `AX-Workspace-0.23.47-Setup.exe`, 사내 반입용 소스는 `workspace-local-0.23.47-source.zip`입니다. 기존 EXE 및 VBS 업데이트 ZIP과 호환 파일명도 제공합니다.
