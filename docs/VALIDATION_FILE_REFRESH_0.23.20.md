# 0.23.20 자료·결과 목록 갱신 보완

검증일: 2026-10-07. 기존 이어 할 일 자동 실행 보완을 포함한 0.23.20 동일 버전 수정본의 검증 기록입니다.

## 변경 내용

- 오른쪽 자료와 결과 상단의 새로고침 버튼으로 두 탭을 함께 갱신합니다. 선택한 탭은 유지합니다.
- 업무 선택과 작업 완료·중지·오류 시에도 두 목록을 갱신합니다. 탐색기에서 파일을 삭제한 경우 상단 새로고침으로 반영할 수 있습니다.
- 실제 파일이 사라졌거나 파일 대신 폴더·링크가 된 결과는 표시에서 제외합니다. 권한·장치 오류나 확인 시간 제한은 삭제로 간주하지 않고 기존 결과와 안내를 유지합니다.
- 대화, 저장된 결과 관찰 기록, 파일 변경 비교 기록과 실제 파일은 변경하지 않습니다. 같은 경로에 파일이 다시 생기면 기존 관찰 기록에 해당하는 항목은 다시 표시할 수 있습니다.
- 파일 내용을 읽거나 폴더를 상시 감시하지 않습니다. 최대 100개 결과의 메타데이터를 앱 잠금 밖에서 확인하고 중복 경로 조회를 공유합니다. 새 메타데이터 조회를 시작하는 데 0.25초 예산을 적용하며 이미 시작한 OS 조회를 강제로 중단하지는 않습니다.
- 목록별 요청은 하나만 유지하고 업무 전환·홈 이동·종료 시 취소합니다. 이전 업무나 오래된 응답이 최신 목록을 덮지 않도록 합니다.

- 파일 존재 확인·HTTP 경로·제품 흐름·파일 변경 비교·실행 카드·프런트엔드 갱신·파일 동작: 85개 실행, 84개 통과, OS 심볼릭 링크 생성 권한이 필요한 기존 테스트 1개 건너뜀. 대체 링크·junction·Cloud Files 판정은 합성 메타데이터 테스트로 확인했습니다.
