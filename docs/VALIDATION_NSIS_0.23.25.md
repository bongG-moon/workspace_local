# 0.23.25 NSIS 설치 배포 검증

2026-10-15. 앱 버전은 0.23.25로 유지하며 설치·배포 방식을 추가했습니다.

## 설치 파일

- NSIS 3.12로 만든 `AX-Workspace-0.23.25-Setup.exe`: 12,717,786바이트.
- SHA256: `c79aabd3fa744e610dff9b4c6fd0b3dd3ee89c6cea71c0f6d844d110d1d4f7c5`.
- 포함한 독립 실행기 SHA256: `863f9c27ef0a5eda7e3a68fe762e8698cfbe525f570e74e5f440d81dcb23eb4e`.
- 실행기 내장 앱과 같은 소스의 VBS 패키지 151개 파일이 일치했습니다. 기존 공개 ZIP에 비해 설치 관련 가이드가 추가된 실행기이며, 앱 동작 코드는 변경하지 않았습니다.
- 현재 사용자 설치, Windows 앱 제거 등록, 시작 메뉴·바탕화면 바로가기와 AppUserModelID를 사용합니다. 설치 전용 서비스나 상주 프로세스는 없습니다.

## 확인한 범위

별도 시험 제품 ID와 격리된 설치·상태 폴더로 설치, 재설치, 바로가기 대상, Windows 등록, 제거 시 관련 없는 파일 보존을 확인했습니다. 다른 파일이 있는 설치 폴더, 동시 설치·제거, 잠긴 제거 프로그램을 정상 완료로 처리하지 않는지도 확인했습니다. 설치한 실행기의 앱 추출, 데모 시작, 업무 생성과 인증된 정상 종료를 확인했습니다. 실제 사용자 업무·Claude 설정은 변경하지 않았습니다.

네이티브 설치 시험의 반복 정리 단계에서 테스트 호스트의 프로세스 생성 지연·WinError 5가 발생했습니다. 각 시험 설치본의 원래 제거 프로그램을 별도로 실행해 모두 exit 0으로 정리하고 시험 등록이 남지 않은 것을 확인했습니다. 따라서 네이티브 unittest 전체 실행을 정상 통과한 것으로 기록하지 않습니다. 설치 화면의 시각적 검수와 사내 운영 PC 설치는 이 기록의 검증 범위에 포함하지 않습니다.

기존 업데이트·패키지·게시 도구 회귀 검사 99개가 통과했습니다. GitHub 다운로드 준비 도구의 별도 8개 검사도 통과했습니다. 이 검사는 기존 ZIP 바이트 보존, 설치 EXE 별칭의 동일 해시, 소스 ZIP 목록 검증, 잘못된 설치 기록·해시·버전 거부와 출력 파일 덮어쓰기 방지를 확인합니다.

## 기존 배포와 호환성

기존 공개 4개 EXE/VBS ZIP은 바이트 그대로 보존합니다. `AX-Workspace-0.23.25.exe`, `Company-Workspace-0.23.25.exe`, `AX-Workspace-0.23.25-Setup.exe`, `AX-Workspace-Setup.exe`는 같은 설치 파일로 제공합니다. 기존 앱의 업데이트 파서는 이 직접 EXE들을 사용하지 않고 원래 ZIP을 선택합니다. 실제 기존 ZIP으로 업데이트 메타데이터·체크섬·독립 실행기 추출·VBS 패키지 검증을 확인했습니다.

이미 저장한 EXE와 메일 첨부 파일은 바뀌지 않습니다. 설치 등록을 원하면 설치 파일을 새로 받아 한 번 실행해야 합니다. 같은 버전이므로 새 버전 알림은 발생하지 않습니다.

원래 v0.23.25 태그는 보존합니다. 설치 배포 소스는 main의 Code Download ZIP과 별도 source ZIP으로 제공합니다. GitHub 게시 이후 공개 URL에서 각 파일을 다시 내려받아 해시와 업데이트 파서 결과를 확인하는 절차를 사용합니다. 사내 GitLab 서버 게시·다운로드는 이 검증에 포함하지 않습니다.
