# Company Workspace 0.23.18 검증 기록

검증일: 2026-10-05. 공개 GitHub의 0.23.7 이후 로컬에서 개선한 0.23.8~0.23.18을 함께 배포한다.

## 이번 배포의 동작

- 작업 중 완전 종료를 선택하면 확인창을 표시한다. 취소하면 진행 중인 작업과 승인 대기를 유지한다. 종료하면 앱이 시작한 모든 CLI와 하위 프로세스를 정리한 뒤 창·트레이를 종료한다. 숨겨진 창에서도 확인한다.
- 일반 작업 중지는 Claude의 중지 응답을 확인한 뒤 같은 연결과 대화에서 후속 요청을 받는다. 모델·Effort·승인 모드, 작성 중인 입력과 첨부를 유지하고 이전 요청을 자동 재전송하지 않는다.
- 현재 업무의 Claude 재시작, 전체 예약 조회, 알림의 요청 요약, EXE·압축파일 첨부, 진행 내용·실행 카드의 정렬과 펼치기, 스킬·기능 화면의 표시 개선을 포함한다.
- Windows에서 작은 거절된 파일 전송의 미처 읽지 않은 본문 때문에 JSON 오류 응답이 끊길 수 있던 경로를 보완한다. 작은 선언된 본문만 제한된 시간에 버리며, 거절된 요청으로 파일을 저장하지 않는다.

## 코드와 실행 검증

- 전체 회귀 검사 2,048개를 실행했다. 조건부 생략 39개를 제외한 2,009개는 실패 원인 확인과 관련 재검증을 포함해 최종 통과했다. 최초 검사에서는 11개가 실패했다. 새 중지·종료 계약에 맞춘 테스트 가정과 모의 프로세스 보완, 작은 첨부 거절 응답 수정 후 관련 78개 검사(1개 조건부 생략)를 재검증했다. 제한 실행 계정의 WS-31로 차단된 실행기 검사 3개는 실제 로그인 사용자 환경에서 모두 통과했다. 반복한 검사 수를 별도 기능 수로 합산하지 않는다.
- Windows Job은 CLI를 실행하기 전에 소유 관계를 확보한다. 부모 실행기가 먼저 종료된 경우, 하위 프로세스, 종료 실패 후 재시도, 동시 종료, 시작 소유 확인 실패를 검사했다. 실제 소유 프로세스가 남아 있으면 종료 완료를 주장하지 않는다.
- 격리된 실제 WebView2 창에서 취소·종료 버튼을 직접 눌렀다. 진행 중 업무와 승인 대기 업무를 동시에 준비했고, 취소 후 두 업무와 4개 소유 프로세스가 유지됐다. 종료 확인 후 두 Job의 활성 프로세스가 모두 0이 되고 창·트레이가 종료됐다. 트레이 진입은 실제 코드의 `_dispatch('exit')`를 호출했으며 물리적인 트레이 메뉴 클릭 시험은 아니다.
- 설치된 Claude Code 2.1.286과 PowerShell 실행기를 사용해 EXE의 연결 준비와 완전 종료를 확인했다. 업무용 모델 요청은 보내지 않았고 테스트 서버·하위 프로세스와 runtime 파일의 정리를 확인했다.
- 기존 실제 앱의 12개 업무 ID가 새 버전에서도 유지되는 것을 확인했다. 전체 대화 파일의 바이트 해시 비교를 완료했다는 의미는 아니다.
- Python 구문, JavaScript 구문, Git 공백 검사와 소스의 인증 정보·실행 파일 미포함을 확인했다.

## 배포와 사내 반입

EXE 내장 앱 ZIP 검증을 통과했고, EXE와 VBS ZIP의 공통 파일 128개가 동일하다. 앱 원본 파일 121개와 고정 빌드 자산 7개를 확인했다. Python은 포함·설치·다운로드하지 않는다.

GitHub **Code → Download ZIP**용 소스 검증 목록도 0.23.18로 갱신한다. 목록은 파일의 누락·변경을 확인하는 용도이며 서명이 아니다. 사내에서는 새 ZIP을 풀고 `python -X utf8 Publish-Workspace.py`를 실행해 기존 GitLab 주소·프로젝트 ID·게시 토큰으로 다시 빌드·게시한다. 공개 GitHub 게시가 사내 GitLab을 직접 변경하지는 않는다.

| 배포 파일 | SHA256 |
| --- | --- |
| Company-Workspace-0.23.18-exe.zip | `3d15623e82950c4223562dafe2c1140034313539a6f7c5aed95acf8811a2f1c4` |
| Company-Workspace-0.23.18-vbs.zip | `ff405e6116242a89f545f6360c9f96664cb2c66289719bd0c61d5b9ac68d03e7` |

사내 GitLab의 실제 게시·익명 다운로드, HCP·DRM·백신 정책과 운영 PC 실행은 외부에서 검증하지 않았다. Windows 소유 관계를 확보할 수 없는 정책 환경에서는 이유를 안내하고 연결을 시작하지 않는다. 이미 저장된 파일과 대화는 보존하지만, 강제 종료 시 진행 중이던 변경의 완료는 보장하지 않는다.
