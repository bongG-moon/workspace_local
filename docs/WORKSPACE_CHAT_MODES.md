# 일반 대화와 업무 사용하기

AX Workspace 왼쪽 위에서 **일반 대화 / 업무**를 선택합니다. 같은 Claude Code 인증과 회사 연결 환경을 사용하며, 선택한 화면에 맞춰 시작 버튼과 목록이 바뀝니다.

| 하고 싶은 일 | 선택할 화면 |
| --- | --- |
| 궁금한 점 질문, 번역, 글 다듬기, 첨부 자료 요약 | **일반 대화** |
| 폴더 안의 파일 작업, 결과 파일 만들기, 스킬·플러그인 사용, 실행 예약 | **업무** |

## 간편 화면으로 채팅에 집중하기

**간편 화면**은 업무 목록과 채팅에 집중하도록 부가 도구를 숨기는 보기입니다. 상단의 **밝기(다크모드)** 버튼 바로 옆 아이콘으로 전환합니다. 켜져 있으면 아이콘 배경이 보라색이며, ON/OFF 글자는 표시하지 않습니다. 아이콘에 마우스를 올리면 전환 설명을 볼 수 있습니다. 자료·결과 패널, 모델·승인 선택 버튼, 스킬·예약 등 부가 메뉴를 숨기며, 밝기 버튼은 간편 화면에서도 사용할 수 있습니다. 다시 누르면 기존 화면과 패널 너비·접힘 상태로 돌아갑니다. 선택은 이 PC의 앱 화면 설정에 저장되며 다음 실행에도 유지됩니다.

간편 화면은 화면만 바꿉니다. 현재 업무와 대화, 작성 중인 입력, 첨부, 선택한 모델·승인 방식, 진행 중인 작업과 실행 예약은 그대로입니다. 승인·확인 요청과 답변 중지, 다른 업무의 알림은 계속 표시합니다. 업무가 일반 대화로 바뀌거나 승인 없이 실행되도록 설정되는 기능이 아닙니다.

파일 끌어 놓기와 붙여넣기, `/스킬이름`과 `@파일` 입력도 사용할 수 있습니다. 첨부한 자료는 계속 표시하며 제거할 수 있습니다. 모델 선택처럼 숨겨진 도구를 단축키나 `/model`로 직접 열면 기존 화면으로 전환해 해당 도구를 보여줍니다. 작은 창에서는 왼쪽 목록을 아이콘으로 펼칠 수 있고, 상단의 간편 화면 아이콘으로 언제든 끌 수 있습니다.

## 일반 대화 시작하기

1. 왼쪽 위의 **일반 대화**를 선택하고 **새 대화**를 누릅니다.
2. 질문을 입력합니다. 폴더를 고르거나 새 프로젝트를 만들 필요가 없습니다. 첫 화면의 질문 예시를 누르면 입력창에 초안이 들어가며, 원하는 내용으로 고쳐 보낼 수 있습니다. 예시만 눌러서는 전송되지 않고 작성 중인 글과 첨부는 유지됩니다.
3. 자료가 있으면 **자료 추가**로 선택하거나 입력창에 끌어 놓습니다.
4. **Enter** 또는 **보내기**를 누릅니다. 줄바꿈은 **Shift+Enter**입니다.

왼쪽에는 일반 대화 목록만 보이며, 오른쪽 업무 파일 영역은 표시하지 않습니다. 앱이 대화별 저장공간을 만들고 사용자가 선택한 파일의 사본만 읽어 전달합니다. “내 문서 폴더에서 찾아줘”, “이 프로그램을 실행해줘”와 같은 파일 탐색·수정·실행은 일반 대화에서 수행하지 않습니다. 필요한 경우 **업무**를 선택해 별도 업무를 시작하세요. 화면을 바꾼다고 기존 대화가 다른 종류로 바뀌지는 않습니다.

## 일반 대화에서 모델 고르기

처음에는 **기존 Claude Code 실행 환경의 기본 모델**을 사용합니다. 회사 연결에서 지정한 모델이 있으면 그 설정을 따르며, 앱이 특정 모델을 임의로 지정하지 않습니다.

- 입력창 아래의 **모델** 버튼을 누르면 현재 연결이 제공하는 모델을 선택할 수 있습니다. 새 대화에서는 대화 공간과 연결을 먼저 준비하지만 질문을 자동으로 보내지는 않습니다.
- 목록에 없는 회사 모델은 **모델 이름 직접 입력**으로 지정할 수 있습니다. 실제 연결에서 적용을 확인한 경우에만 선택이 반영되며, 해당 회사 연결에서 사용할 수 있는 이름이어야 합니다.
- 선택은 **현재 앱 실행 중 해당 대화에만** 적용됩니다. 다른 대화·업무와 개인 Claude Code 기본 설정은 바꾸지 않습니다. 새 대화는 기존 기본 모델로 시작합니다.
- **기존 설정 사용**을 선택하면 이번 연결에서 처음 확인한 기본 모델로 돌아갑니다. 답변 중에는 변경할 수 없으며, 답변이 끝난 뒤 고르면 다음 질문부터 적용됩니다.
- 앱을 켜 둔 상태에서 대화를 다시 연결할 때는 선택을 복원합니다. 앱을 완전히 종료한 뒤에는 Claude Code의 현재 설정을 다시 확인합니다. 복원에 실패하면 요청을 보내기 전에 사용할 모델을 다시 확인합니다. CLI가 모델 변경을 지원하지 않으면 이유를 표시하고 기존 모델을 사용합니다.

일반 대화에는 모델 선택만 표시합니다. Effort·승인 모드·스킬·도구 설정은 기존 업무 화면에서 사용하며, 일반 대화의 파일·도구 제한은 모델을 바꿔도 유지됩니다.

## 자료를 읽을 때마다 승인해야 하나요?

**일반 대화와 첨부 자료 읽기는 별도 승인 없이 바로 진행됩니다.** 앱이 대화별 공간을 만들고 선택한 파일의 사본을 읽어 전달하므로, 대화를 시작하거나 파일을 읽을 때마다 Claude의 도구 승인창을 확인할 필요가 없습니다.

이는 PC 폴더 권한을 모두 개방하는 설정이 아닙니다. Windows 파일 권한과 회사 정책은 그대로이며, 일반 대화에서 원본 파일 수정이나 프로그램 실행은 하지 않습니다. 이런 작업은 **업무**에서 기존 승인 방식을 사용합니다.

## 첨부할 수 있는 자료와 읽는 범위

| 형식 | 전달하는 내용 | 파일당 한도 |
| --- | --- | --- |
| TXT·MD·CSV·TSV·JSON·소스 코드 등 | 텍스트. 코드 파일도 실행하지 않고 글로 읽음 | 2 MiB |
| PNG·JPG/JPEG·WebP | 정지 이미지 | 4 MiB, 가로·세로 각각 8,000픽셀 이내, 총 2,000만 픽셀 이내 |
| PDF | PDF 원문을 Claude에 전달 | 5 MiB |
| DOCX | 본문 문단과 표 텍스트 | 16 MiB |
| PPTX | 슬라이드 텍스트 | 16 MiB |
| XLSX | 시트 이름과 셀 값, 파일에 저장된 수식 결과 | 16 MiB |

한 번에 최대 **12개**를 첨부합니다. 이미지·PDF 합계는 **5 MiB**, 추출 텍스트는 파일당 **48,000자**, 요청 전체 **120,000자**까지 전달합니다. 일부만 읽었거나 읽지 못했으면 자료별 안내에 표시합니다. 큰 자료는 필요한 부분으로 나누어 보내세요.

- **PDF는 파일 전달과 실제 내용 확인이 다릅니다.** 연결된 Claude 모델·사내 서버가 PDF 입력을 지원해야 합니다. 앱이 “원문 전달”로 표시해도 전체 페이지를 확인했다는 뜻은 아닙니다. 응답의 읽은 범위와 실패 안내를 확인하세요. 암호화된 PDF는 첨부하지 않고, 읽지 못하면 텍스트나 필요한 페이지 이미지로 직접 준비하세요.
- DOCX의 머리말·도형·이미지, PPTX의 이미지·차트·발표 노트, XLSX의 서식·차트·이미지는 텍스트 추출에 포함하지 않습니다. 매크로·수식·외부 링크는 실행하지 않습니다. 도형이나 차트 모양을 묻고 싶으면 해당 부분을 이미지로 첨부하세요.
- EXE·ZIP·7z 등 실행·압축 파일, HWP와 이전 Office 형식은 일반 대화에서 읽지 않습니다. 기존 **업무**의 파일 첨부 지원은 유지됩니다.
- 암호·DRM·손상·지원하지 않는 압축 구조 등으로 읽을 수 없으면 이유를 표시합니다. 보호를 해제하거나 우회하지 않습니다.

첨부 사본과 추출 캐시는 이 PC에 저장됩니다. 질문과 선택한 자료 내용은 기존 Claude 연결의 모델·서버로 전달되므로 사용 가능한 자료 범위를 확인하세요.

## 화면을 오갈 때

- **일반 대화**는 최근 대화 목록, **업무**는 기존 폴더별 업무 목록을 표시합니다. 검색도 현재 화면의 목록에 적용합니다.
- 각 화면의 마지막 선택과 작성 중인 입력을 구분합니다. 화면을 오가도 다른 대화의 초안과 섞지 않습니다.
- 일반 대화로 이동해도 진행 중인 업무는 계속됩니다. 선택 버튼의 진행·응답 필요 표시나 알림을 통해 돌아갈 수 있습니다.
- 화면 전환만으로 Claude 연결을 추가하지 않습니다. 기존의 동시 작업 최대 5개와 완료된 연결을 정리하는 정책을 함께 사용합니다.
- 좌우 패널은 기존 색상을 유지하고 중앙은 뉴트럴 색상을 사용하는 **A2** 구성을 적용했습니다. 사이드바는 작은 글자·아이콘과 한 줄 제목으로 정리하며, 폴더는 아이콘과 들여쓰기로 구분합니다. 라이트·다크 모드 모두 같은 구조입니다. 긴 업무 이름은 상단과 목록의 정해진 너비에서 한 줄로 생략하며, 마우스를 올리면 전체 이름을 확인할 수 있습니다.
- 맨 위 **AX Workspace 로고**를 누르면 현재 화면의 홈으로 돌아갑니다. 작성 중인 글과 진행 중인 작업은 유지됩니다. **빠른 실행**은 `Ctrl+Shift+P`로 열 수 있습니다.
- **업무**에서는 목록 위에 **스킬·기능**과 검색창을 두고, 아래의 **설정·전체 예약·단축키·사용 도움말**은 2×2로 모았습니다. 일반 대화에서는 스킬·예약 메뉴를 숨깁니다. 사이드바를 접어도 홈과 하단 메뉴를 아이콘으로 사용할 수 있습니다.
- 폴더 아이콘은 열고 닫은 상태에 따라 달라집니다. 폴더 안에는 처음 5개 업무를 표시하고, 6개 이상이면 **더 보기**로 나머지를 펼칩니다. 검색할 때는 일치하는 업무를 모두 표시합니다.
- 목록의 이름에 마우스를 올리면 **이름 변경·고정·삭제** 버튼이 나타납니다. 키보드의 Tab으로 선택해도 같은 버튼을 사용할 수 있고, 터치 화면에서는 버튼이 계속 보입니다. 평소에는 관리 버튼 자리를 줄여 긴 이름을 더 보여 줍니다. 고정한 항목은 색이 채워진 핀으로 표시하며, 상단과 목록의 핀을 누르면 같은 고정 상태를 바꿀 수 있습니다.

## 대화를 삭제하면 무엇이 지워지나요?

**일반 대화**에서 삭제를 누르면 확인창을 표시합니다. 확인하면 해당 대화를 중지하고 앱의 대화 기록·초안·첨부 사본·추출 캐시·전용 폴더를 함께 정리합니다. 목록에서만 숨기는 동작이 아니므로 삭제 전에 필요한 내용을 따로 보관하세요.

사용자가 선택한 **원본 파일**, 따로 저장한 결과, 다른 대화·업무 파일, 개인 Claude 설정·스킬·플러그인은 삭제하지 않습니다. 잠긴 파일 등으로 정리를 끝내지 못하면 보류 안내를 남기고 다음 앱 실행 때 다시 정리합니다. 소유 정보를 확인하지 못한 폴더나 연결된 경로는 추측해 삭제하지 않습니다.

**업무**의 삭제는 기존처럼 **앱 목록에서만 제거**합니다. 원래 Claude 세션과 업무 폴더·결과 파일을 보존하며, 설정의 보관한 업무에서 복원할 수 있습니다. 일반 대화 삭제와 구분해 주세요.

Claude Code 자체의 세션 기록은 앱 전용 폴더 밖에도 별도로 저장될 수 있습니다. 일반 대화 삭제는 **앱이 관리하는 대화 데이터 정리**이며, Claude 자체 기록·서버 기록까지 모두 지우는 기능은 아닙니다.

## 실행 환경과 저장 위치

일반 대화는 사용자 스킬·플러그인·슬래시 명령과 파일·명령·MCP 도구를 사용하지 않는 별도 실행 범위를 연결할 때마다 적용합니다. 기존 업무의 실행 환경이나 개인 Claude 설정 파일은 수정하지 않습니다. 설치된 CLI에서 필요한 제한 옵션을 확인하지 못하면 일반 대화를 연결하지 않고 이유를 안내합니다. 제한 없는 업무 연결로 자동 전환하지 않습니다.

기존 로그인·모델·회사 정책은 유지합니다. 이 구분은 Claude의 호출 기능을 제한하는 것이며 Windows 프로세스를 별도 보안 샌드박스에 넣는 기능은 아닙니다. 회사에서 관리하는 인증·보안 정책은 계속 적용됩니다.

기본 앱 상태 폴더를 사용하는 경우 대화 전용 공간은 `%LOCALAPPDATA%\CompanyAgent\local-ui\chat-spaces\<대화 ID>`에 있습니다. `workspace`는 연결 경로, `cache`는 추출 캐시이며, 앱이 관리하는 첨부 사본은 같은 상태 폴더의 첨부 저장소에 있습니다. 파일을 직접 지우기보다 앱의 대화 삭제 기능을 사용하세요.

파일을 보내는 순간에만 제한된 분량을 읽고 텍스트 추출 결과를 해시로 재사용합니다. 이미지·PDF의 Base64 사본을 별도 캐시로 쌓지 않으며, 폴더 감시·추가 상주 프로세스를 만들지 않습니다.
