# AX Workspace 0.23.31 — 이어 할 일 전환·반응성 및 실행 안정성 개선

2026-10-23

- **VDI 실행 준비:** 실행 자료를 검사한 뒤 폴더 이름을 확정할 때 생기는 일시적인 접근 거부·파일 잠금을 최대 약 3.35초 동안 재시도합니다. 계속 실패하면 대상 경로와 실패 단계를 안내합니다. 정상 실행에는 추가 대기가 없으며, 회사 보안 정책이나 폴더 권한을 변경하지 않습니다.
- **연속 지금 반영:** Claude가 요청 처리를 시작하기 전에 다시 중지되는 경우와, 완료 직후 다음 요청으로 전환하는 시점이 겹치는 경우를 보완했습니다. 접수 확인이 필요하면 ‘접수 확인 중…’으로 표시하고 선택한 대기 요청을 보존합니다. 이미 실행한 요청은 자동 재전송하지 않습니다.
- **지금 반영 중 잘못된 연결 오류:** 실제 Claude 2.1.306에서 확인한 정상 중지 응답을 실행 실패로 오인하던 문제를 수정했습니다. 현재 세션의 중지 확인과 종료 응답을 모두 받은 뒤 다음 요청으로 전환하며, 정상 전환 시 기존 연결과 선택 설정을 유지합니다. 실제 실행 오류는 계속 표시합니다.
- **응답 중 버튼 반응성:** 출력이 몰릴 때 화면 갱신을 나누어 처리하고 중복 목록 조회를 합쳤습니다. 진행 기록 저장·조회와 응답 전송이 취소·지금 반영·순서 변경을 함께 막던 잠금 범위를 줄였습니다. 대기 요청, 작성 중 입력, 첨부파일과 기록 저장은 유지합니다.
- **일시적인 화면 통신 복구:** 이벤트 조회가 일시적으로 실패하면 마지막으로 처리한 위치부터 제한적으로 다시 읽습니다. 작업 요청을 재전송하거나 Claude 작업을 자동 재실행하지 않습니다.
- **일반 대화·업무 정렬:** 진행 숫자가 없으면 아이콘과 이름을 가운데 정렬합니다. 숫자가 표시되어도 두 버튼의 너비와 한 줄 배치를 유지합니다.
- **작업 중 업데이트 선택:** 진행 중인 작업 때문에 전환이 대기 중이면 ‘작업 중지 후 업데이트’를 선택할 수 있습니다. 확인한 뒤 작성 중인 입력과 첨부를 먼저 저장하고, 이 앱이 관리하는 작업과 연결을 정리한 후 업데이트합니다. 이미 수행한 파일 변경은 되돌리지 않으며, 중지한 요청을 자동 재전송하지 않습니다.
- **업데이트 대기 판정:** 실제 작업이 끝난 뒤 남아 있는 ‘결과 확인 필요’ 기록 때문에 전환이 계속 대기하는 경우를 개선했습니다. 실제 도구 실행과 연결 정리가 끝나지 않았다면 완료로 표시하지 않습니다.
- **이전 버전 초안 복원:** 0.23.28 등 다른 버전으로 전환하며 보관한 정상적인 초안도 현재 버전에서 복원합니다. 복원 내용을 저장한 뒤 이전 보관 기록을 정리합니다.
- **초안 충돌 처리:** 현재 작성 중인 내용은 덮어쓰지 않습니다. 상단 ‘복원·정리’에서 이전 초안을 현재 입력 뒤에 추가하거나, 확인 후 보관 기록만 지울 수 있습니다. 복원은 요청을 자동 전송하지 않으며, 저장 실패 시 보관 기록을 유지합니다.
- **자료 폴더 탐색:** 폴더 오른쪽의 첨부용 `+`를 폴더 열기 화살표로 바꿨습니다. 폴더 이름이나 화살표로 내부 자료를 열고 상위 폴더로 돌아올 수 있습니다. 폴더를 입력창에 끌어 첨부하는 기능은 유지합니다.
- **사내 배포 안내:** GitLab Release 삭제와 최신 설치 채널 복구가 서로 다른 작업임을 설명하고, 이전 채널 백업을 확인해 복구하는 절차를 추가했습니다.

이번 파일은 **0.23.31 동일 버전 수정 배포**입니다. 이미 0.23.31을 사용 중이면 새 버전 알림 대신 새 설치 파일로 교체해야 합니다. VDI 실행 준비 개선은 새 EXE에 포함되므로 기존 설치 파일을 재사용하면 적용되지 않습니다.

실행기·대기 요청·화면 회귀 검사와 실제 브라우저 조작을 확인했습니다. 이번 전환·반응성 수정은 관련 289개 테스트를 통과했고, 권한 조건이 필요한 1개 테스트는 제외했습니다. 기존 로그인을 사용하는 별도 테스트에서 실제 Claude 2.1.306의 텍스트 응답 중·Read 도구 요청 중 연속 전환과 최종 답변 완료를 확인했습니다. 사내 VDI의 실제 보안 정책 환경은 검증하지 않았으며, 모든 `ede_diagnostic` 오류가 해결됐다는 의미는 아닙니다.

## 기존 버전에서 처음 업데이트할 때

이미 실행 중인 0.23.30 이하 화면에는 새 ‘작업 중지 후 업데이트’ 버튼이 추가되지 않습니다. 기존 업데이트가 작업 대기로 계속 막히면 앱의 **완전 종료**에서 작업 중지를 확인한 뒤 새 설치 파일을 실행하세요. 창을 닫아 트레이에 남기는 것만으로는 완전 종료되지 않을 수 있습니다. 0.23.31부터 이후 업데이트에 새 선택 동작을 사용할 수 있습니다.

사내 PC에는 사내 GitLab 설정으로 만든 설치 파일을 배포하세요. 공개 GitHub 설치 파일은 사내 서버 설정을 대신하지 않습니다. 개인 Claude 설정과 회사 정책은 변경하지 않습니다.
