# 0.23.5 — 작은 업데이트 아이콘과 상세 진행 기록

## 변경 내용

- 새 버전이 있으면 설정 옆에 32px 원형 다운로드 아이콘이 나타납니다. 사이드바를 접거나 **다음에 하기**를 선택해도 남으며, 클릭하면 변경 내용 창을 다시 엽니다. 설치는 **업데이트하기**를 눌렀을 때만 시작합니다.
- 현재 도구와 동작은 짧게 유지하고, **진행 내용**을 펼치면 실제 CLI의 공개 설명, 도구·스킬 입력과 결과, 하위 작업자 보고, 후크·오류 기록을 확인합니다. 기존 활동 버튼에서는 해당 요청을, 오른쪽 **진행 기록 보기**에서는 업무 전체를 엽니다.
- 상세 패널은 대화 영역 안에 배치합니다. 입력창을 크게 밀어 올리지 않으며, 이전 기록을 읽는 중에 새 출력이 도착해도 읽던 위치를 유지합니다.
- 이전 버전에서 남긴 도구 활동 요약도 보존합니다. 상세 내용이 없는 업무는 수집되지 않은 기록임을 안내합니다.

## 수집·보관 범위

현재 사용자의 앱 상태 폴더 아래 `progress/<업무 ID>.sqlite3`에 기록합니다. 기존 Claude 설정·원본 세션 파일은 변경하지 않습니다. 각 본문은 최대 64 KiB, 업무별 데이터베이스는 최대 32 MiB로 제한합니다. 오래된 기록 정리나 긴 내용 생략은 화면에 안내합니다. 이미지·문서의 바이너리 본문, 내부 추론, 인증·제어 프로토콜은 저장하지 않으며 알려진 인증 문자열 형태를 가립니다. 일반 파일 내용과 업무 입력·출력은 로컬 기록에 포함될 수 있습니다.

공개 텍스트는 기존 대화에서 계속 스트리밍하고 상세 기록에는 완성된 블록을 저장합니다. 부분 전송과 완성 메시지가 겹쳐도 중복하지 않으며, 같은 메시지 ID의 서로 다른 내용과 하위 작업자 보고를 구분합니다. 터미널 화면 장식이나 CLI가 앱에 제공하지 않은 출력은 복원하지 않습니다. [Claude 출력 스트림 계약](https://code.claude.com/docs/en/agent-sdk/streaming-output)을 참고하세요.

펼칠 때 50개씩 읽고 화면 메모리에 최대 250개를 유지합니다. 접으면 상세 DOM·목록·진행 중 조회를 해제합니다. 일반 대화 이벤트에는 본문을 넣지 않고 최신 메타데이터 한 건으로 합쳐 승인·결과 이벤트를 밀어내지 않습니다. 로그 읽기·저장 실패는 업무 실행을 중단하지 않습니다. 기존 Python의 기본 모듈 `sqlite3`을 사용하며 새 패키지를 설치하지 않습니다.

## 검증

- 업데이트, 상세 기록, 도구 요약, 실행 카드, 대화·기록 복원, 승인, 초기 화면, 진단, 업데이트 설치·패키징 및 레이아웃 결합 검사: **403개 중 401개 통과, 환경 조건 2개 생략**.
- 마지막 스크롤 조정 후 진행 화면 13개 집중 검사를 다시 통과했습니다. 실제 프로세스를 사용하는 모의 CLI·서버 검사 41개 중 40개 통과, 환경 조건 1개 생략 및 Python 진단 4개 통과를 확인했습니다. 검사 모음 간 중복 항목은 합산하지 않습니다.
- 분리된 모의 CLI와 로컬 서버로 실제 도구 입력·결과, 요청별 분리, 재생 중복, 하위 작업, 80건을 넘는 기록, 인증과 Origin 검사, 숨긴 업무 차단, 기록 용량 제한, 오류 격리를 확인했습니다.
- 브라우저에서 다음에 하기 이후 아이콘 유지·변경 내용 재열기, 접힌 사이드바의 32px 아이콘, 65개 기록의 이전 페이지 조회, 긴 출력의 마지막 항목, 패널 접기 후 상세 행 0개, 기록이 없는 업무 전환을 확인했습니다. 실제 AI 요청이나 앱 설치를 실행한 검증은 아닙니다.
- Windows에서 단일 EXE를 빌드하고 내장 파일 추출을 검증했습니다. EXE/VBS ZIP의 공통 앱 파일 **127개**가 일치하며, 상세 기록 모듈과 화면 파일을 두 배포본에 포함했습니다. Python 실행 환경이나 설치 프로그램은 포함하지 않습니다.

실제 사내 GitLab 접속, 사내 Python 3.11.5와 Windows 정책 조합의 전체 실행은 현장 검증이 필요합니다. 이 환경의 일부 기존 실행기 검사는 도구 실행 계정과 대화형 Windows 사용자가 달라 WS-31로 중단되었습니다. 이를 우회하기 위해 PC 보안 설정이나 개인 Claude 설정을 바꾸지 않았습니다.
