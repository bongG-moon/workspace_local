# AX Workspace 0.23.28

- 사용자 말풍선 내부를 왼쪽 정렬해 긴 문장과 여러 줄 요청의 시작점을 맞췄습니다.
- 업데이트 내역에서 배포 서버의 이력과 설치본 기본 변경사항을 별도로 선택할 수 있습니다. 기본 화면은 실제 배포 이력입니다.
- 사내 배포 도구가 이전 이력을 동기화할 때 GitLab 릴리스에서 직접 수정한 설명을 우선 반영합니다. 기존 릴리스와 태그는 덮어쓰지 않습니다.
- 같은 설명을 다시 게시해 등록 시각만 달라진 경우에는 설명 충돌 경고를 표시하지 않습니다.
- 제외된 이전 기록은 검증 가능한 버전·기록 ID와 실패 사유를 안내합니다.

GitLab에서 설명을 수정한 후에는 사내 배포 도구로 다시 게시하여 이력을 동기화하고, 앱의 업데이트 내역에서 다시 확인을 누르세요. Deploy Token은 릴리스 API 조회가 제한되므로 Access Token 또는 서버에서 허용된 CI Job Token이 필요합니다.
