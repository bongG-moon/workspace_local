# Claude Code 명령어·단축키

원본 Claude Code CLI 기준입니다. Workspace·VS Code의 메뉴와 키는 다를 수 있습니다. 현재 설치에서 `/`를 입력해 보이는 항목을 먼저 확인하세요. 없는 명령을 억지로 실행하거나 명령 하나 때문에 재설치하지 않습니다. 아래 기능은 별도 표시가 없으면 Claude Code 기능이며 Company Agent가 새로 만든 명령이 아닙니다.

처음에는 **`@`로 파일 선택, `Ctrl+J`로 줄바꿈, `Esc`로 중단, `/help`로 도움말**만 익혀도 됩니다. 전체 사용 흐름은 [Claude Code 기본 사용법](CLAUDE_CODE_BASICS.md)을 먼저 읽으세요.

## 1. 입력·중단·확인에 필요한 키

| 하고 싶은 일 | 키 | 주의 |
| --- | --- | --- |
| 보내기 | Enter | 보내기 전 대상 확인 |
| 줄바꿈 | Ctrl+J | Shift+Enter 지원은 터미널마다 다름 |
| 파일 지정 | @ | 목록에서 실제 파일 선택 |
| Windows 이미지 붙이기 | Alt+V | 첨부 표시 확인, 민감 내용 제외 |
| 현재 응답 중단 | Esc | 이미 수행한 작업이 되돌아가지는 않음 |
| 상세 실행 내용 보기 | Ctrl+O | 로그 공유 전 민감 내용 확인 |
| 이전 입력 찾기 | Ctrl+R | 화면에 따라 Enter가 바로 전송할 수 있으므로 내용부터 확인 |
| 입력칸에서 모드 바꾸기 | Shift+Tab | 여러 모드를 순환하므로 Plan 표시 확인. 승인창에서는 다른 동작일 수 있음 |
| 긴 요청을 편집기로 쓰기 | Ctrl+G | 기본 편집기가 준비된 환경에서 사용 |
| 중단 또는 입력 지우기 | Ctrl+C | 일반 복사 키로 생각하지 마세요. 대기 중 반복하면 종료될 수 있음 |
| 빈 입력칸에서 종료 | Ctrl+D | 현재 화면의 종료 확인을 따름. 글이 있으면 문자 삭제 동작일 수 있음 |
| 현재 키 도움말 | 빈 입력칸에서 ? | 실제 설치의 키 설정 우선 |

[공식 입력·키 안내](https://code.claude.com/docs/en/interactive-mode)를 2026-09-20에 확인했습니다. 조직별 버전·키 재설정에 따라 다를 수 있습니다. 실행을 멈추는 것과 이미 바뀐 파일을 복구하는 것은 다릅니다.

## 2. 대화 안에서 쓰는 명령

| 명령 | 언제 쓰나요? |
| --- | --- |
| `/help` | 현재 도움말 |
| `/status` | 현재 실행 환경·상태 확인 |
| `/context` | 대화에 들어간 내용과 사용량 확인 |
| `/usage` | 계정에서 제공하는 사용량·한도 확인. 최신 공식 문서에서 `/cost`·`/stats`는 별칭이며 이전·사내 버전은 다를 수 있음 |
| `/compact` | 같은 업무를 이어가며 긴 대화 요약 |
| `/clear` | 다른 업무로 새 대화 시작 |
| `/resume` | 이전 대화 이어가기 |
| `/plan` | 지원하는 버전에서 계획 모드로 전환 |
| `/init` | 프로젝트를 분석해 시작 지침 준비 |
| `/memory` | Claude 지침·기억 관리 |
| `/skills` | 사용 가능한 스킬 확인 |
| `/plugin` | 플러그인 등록 확인 |
| `/hooks` | 자동 처리 등록 확인 |
| `/mcp` | 연결 도구 확인 |
| `/tasks` | 백그라운드 작업 확인 |
| `/permissions` | 적용 중인 도구 권한 확인·관리. 회사 기준이나 승인 절차를 임의로 완화하지 않음 |
| `/copy` | 지원하는 버전에서 답변을 복사. 복사 대상에 민감 내용이 없는지 확인 |
| `/rewind` | 되돌릴 수 있는 대화·파일 변경 범위 확인. 외부 작업 전체의 취소가 아님 |
| `/model` | 사용 모델 확인·선택 (회사 기준 유지) |

명령은 메시지 맨 앞에 입력합니다. 현재 사용 가능한 항목은 계정·플랫폼·버전마다 다릅니다. [공식 명령 안내](https://code.claude.com/docs/en/commands)

**입력 위치를 구분하세요.** `/help`는 Claude 대화 입력칸, `claude --continue`는 운영체제 터미널에 입력합니다. 설치 명령이나 터미널 명령을 자연어 질문처럼 보내지 마세요. 사용량 값이 없거나 사내 가격과 연결되지 않으면 실제 청구액을 추측하지 않습니다.

Company Agent가 제공하는 명령은 `/company-agent:skills`, `/company-agent:learning`, `/company-agent:business-check`입니다. 각각 스킬 선택, 자동 학습 관리, 업무 준비 확인 용도입니다. 진단 성공은 실제 Office·메일·DB 작업의 성공이 아닙니다. `/revise-claude-md`는 이 하네스에 포함되지 않습니다.

## 3. 작업 중 다음 질문과 제안 문장

실행 중 보낸 메시지는 대기하다가 도구 실행 경계 등에 전달될 수 있습니다. ‘지금 작업을 보완’하는지 ‘다음 업무’인지 명확히 적으세요. 반드시 완료 후 시작해야 한다면 결과를 받은 다음 보냅니다. Tab은 다음 업무를 예약하는 키가 아닙니다.

```text
현재 요청 보충: 원본을 보존하고 실제 확인한 범위만 알려줘.
```

입력칸에 제안 문장이 보이는 것과 메시지를 전송하는 것은 다릅니다. 제안은 CLI·조직 설정에 따라 없을 수 있고, Company Agent가 자동으로 후속 질문을 보내지는 않습니다. [공식 실행 중 메시지·제안 안내](https://code.claude.com/docs/en/interactive-mode#queue-messages-while-claude-works)

## 4. 압축·기억·프로젝트 지침은 다른 일

큰 작업이 끝났다고 매번 압축할 필요는 없습니다. 먼저 결과 파일과 남은 일을 확인합니다. 대화가 길어졌을 때 원본 CLI에서 아래처럼 중요한 조건을 남길 수 있습니다.

```text
/compact 현재 목표, 원본 보존 조건, 최종 파일 경로, 검증한 범위와 미확인 사항을 남겨줘
```

압축에도 처리가 필요하며 비용 절감률을 보장하지 않습니다. 회사 모델의 자동 압축 지원은 운영 환경에서 확인합니다. 이 하네스는 매 작업 후 강제 `/compact`를 실행하지 않습니다. [공식 대화 관리](https://code.claude.com/docs/en/sessions)

이미지 작업 후 압축이 잦다면 같은 이미지·긴 출력이 반복되는지 `/context`에서 먼저 확인합니다. 최초 검토 범위는 유지하고 수정 후 변경·영향 부분만 다시 봅니다. 압축 후에는 유효한 현재 작업의 로컬 스킬 선택만 이어가고 필요한 본문은 다시 불러옵니다. 압축을 막거나 조직의 모델·자동 압축 설정을 임의로 바꾸지는 않습니다.

Claude의 `CLAUDE.md`와 자동 기억은 대화 요약과 다릅니다. Company Agent 개인 기억도 별도입니다. 기본 `CLAUDE.md` 자동 생성은 짧은 시작 안내이며 `/init`의 코드 분석을 대신하지 않습니다. 자동 학습 역시 프로젝트 지침을 몰래 고치는 기능이 아닙니다. [공식 기억 안내](https://code.claude.com/docs/en/memory)

## 5. 되돌리기·여러 세션·종료

원본 CLI의 `/rewind`는 되돌릴 대상을 확인하는 메뉴입니다. 모든 외부 작업·명령 실행·메일 발송을 취소하는 기능은 아닙니다. 중단 후에는 실제 파일과 실행 기록을 먼저 확인하세요. [공식 되돌리기 한계](https://code.claude.com/docs/en/checkpointing)

서로 독립적인 업무만 별도 폴더·대화로 나눕니다. 같은 파일을 동시에 수정하면 충돌할 수 있습니다. 하나의 회사 계정 사용량이 세션별로 독립되는 것도 아닙니다. 폴더 간 이동과 새 대화는 기억·권한 범위를 다시 확인할 기회입니다.

터미널에서 다시 시작할 때 `claude`는 새 실행, `claude --continue`는 최근 대화 이어가기 용도로 사용할 수 있습니다. 인증은 기존 회사 안내를 따릅니다. 이 명령들은 대화 입력칸의 슬래시 명령과 다릅니다. [공식 CLI 실행 옵션](https://code.claude.com/docs/en/cli-reference)

Workspace는 전원 버튼으로 종료하세요. 창의 X만 닫으면 프로그램이 계속 실행될 수 있습니다.
