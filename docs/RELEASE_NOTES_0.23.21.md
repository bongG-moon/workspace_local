0.23.21은 배포·실행 권한 진입 경로·이어 할 일·화면 모드를 보완합니다. 이미 같은 0.23.21 로컬 시험본을 사용 중이라면 트레이에서 완전 종료한 뒤 새 파일을 실행하세요. 실행 중인 동일 버전은 기존 창을 재사용합니다.

- GitLab 소스 게시: README가 있는 기존 기본 브랜치로 구성 파일을 올릴 때 새 브랜치용 start_sha를 보내던 HTTP 400 원인을 수정했습니다. 기존 파일별 충돌 확인, 브랜치 변경 재확인과 게시 후 SHA 검증은 유지합니다.
- 최신 실행기: 구형 EXE와 내부 앱 버전을 구분해 표시하고 설정에서 ‘최신 실행기 바로가기 만들기’를 제공합니다. 현재 앱과 같은 버전의 EXE를 기존 배포 출처에서 받아 체크섬 검증 후 전용 바로가기를 만듭니다. 원래 EXE를 덮어쓰지 않습니다. 지정 Python 경로를 유지하며 일시적 바로가기 오류는 재시도할 수 있습니다.
- 관리자 실행: 새 EXE 또는 ‘Company Workspace (최신)’ 바로가기를 Windows에서 관리자 권한으로 실행하면 그 권한을 상속합니다. 기존 앱을 완전 종료한 뒤 실행하세요. 앱 내부 권한 전환은 다시 추가하지 않으며 Windows·Claude 개인 설정을 바꾸지 않습니다.
- 이어 할 일: 대기 목록에서 ‘지금 반영’ 또는 ‘지금 실행’을 누를 수 있습니다. 선택 항목의 기존 본문과 첨부를 사용하고 현재 중지가 확인된 뒤 같은 대화에서 실행합니다. 나머지 항목 순서는 유지하며 중복 클릭·응답 유실·자동 실행 경합을 방어합니다.
- 화면 모드: 상단 해·달 아이콘으로 밝은 모드와 어두운 모드를 바로 전환합니다. 설정에서는 밝게·어둡게·시스템 설정 따르기를 선택하며 상단 버튼과 동기화됩니다. 대화·자료·팝업·제목 표시줄·PC 알림에 적용하며 재실행에도 유지합니다. 기존 밝은 모드의 색상과 결과 이미지·HTML 자체 색상은 유지합니다. 주기적인 테마 확인 프로세스는 추가하지 않습니다.
- 배포 방식: EXE ZIP과 VBS ZIP을 별도로 제공합니다. 기존 Python 3.11 이상을 사용하며 Python을 설치·다운로드하지 않습니다.

구형 EXE의 관리자 실행 문제가 있었다면 앱 업데이트만으로 원래 EXE가 바뀌지는 않습니다. 최신 EXE를 직접 받거나 설정에서 최신 실행기 바로가기를 준비한 뒤 사용하세요. 해당 버전의 EXE가 배포 서버에 게시되어 있어야 바로가기를 준비할 수 있습니다.

로컬 검증은 격리된 임시 상태·합성 CLI·로컬 GitLab 대역·실제 네이티브 창을 사용합니다. 외부에서 접근할 수 없는 사내 GitLab 재게시와 운영 PC의 UAC·보안 제품 조합은 별도 확인이 필요합니다. 자세한 검사 결과는 docs/VALIDATION_0.23.21.md에 기록합니다.
