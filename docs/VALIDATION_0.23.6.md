# 0.23.6 — 주요 활동과 현재 동작 표시 개선

## 변경 내용

- 새 버전이 있을 때만 설정 바로 위에 업데이트 아이콘을 표시합니다. 원형 표시는 28px로 줄이고 클릭 영역은 42×40px로 유지합니다. 사이드바를 접어도 같은 순서로 표시하며, 업데이트가 없으면 빈 행을 남기지 않습니다.
- 주요 중간 설명은 대화에서 계속 보여 주고, 도구·스킬 활동은 여러 개의 짧은 행으로 표시합니다. **입력·결과 자세히 보기**를 누르면 해당 요청의 상세 기록을 엽니다.
- 입력창 위에는 실제로 수신한 동작을 표시합니다. 도구 호출 준비와 실행 보고를 구분하고, 승인·질문 대기를 우선 표시합니다. 모델이나 모드 설정만 바꿨을 때 업무 실행으로 처리하지 않습니다.
- 기존 CLI 인증·설정, 승인 동작, 실행 카드, 상세 기록과 사내 배포 경로를 유지합니다.

## 메모리와 기록 범위

짧은 도구 요약은 최대 80건을 유지하고 요청별 최대 6개 행을 표시하며 진행·대기 중인 호출을 우선합니다. 바뀐 행만 갱신하며 상세 입력·결과를 요약에 복사하지 않습니다. 상세 기록은 기존과 같이 디스크에 저장하고 펼칠 때 50개씩 읽습니다. 화면에는 최대 250개를 유지하며 접으면 상세 목록과 조회를 해제합니다. 건당 본문 64 KiB, 업무별 데이터베이스 32 MiB 제한은 유지합니다. 공개 응답의 중복 판별은 본문 복사본 대신 제한된 해시값으로 처리하고, 완성된 상세 텍스트의 임시 버퍼는 해제합니다. 상태 알림은 같은 단계에서 반복하지 않고 최신 한 건으로 합칩니다.

상태에는 CLI가 실제로 전달한 공개 동작만 사용합니다. 내부 추론이나 진척률을 만들지 않으며 도구 호출 준비를 실행 완료로 표시하지 않습니다. 상세 기록이 없던 이전 업무의 입력·결과는 새로 복원하지 않습니다.

## 검증

- 상태·상세 기록·활동 요약·대화 복원·승인·업데이트·패키징·진단·초기 화면 결합 검사: **420개 중 418개 통과, 환경 조건 2개 생략**.
- 실제 프로세스를 사용하는 모의 CLI와 서버 검사: **41개 중 40개 통과, 환경 조건 1개 생략**. 검사 모음 사이의 중복 항목은 합산하지 않습니다.
- 별도 상태 검사에서 동일 단계의 1,000개 부분 출력, 오래된 요청의 재생, 하위 작업, 승인·선택 상태, 텍스트 지문 크기 제한과 완료 버퍼 해제를 확인했습니다. 프런트에서는 동일 상태 100회 수신 시 상태 본문의 추가 쓰기가 없고 요약 행이 재사용됨을 확인했습니다.
- 마지막 완료 기록 정리·긴 한글 본문 처리 보완 후 상태·요약·상세 기록 58개 중 57개 통과, 심링크 권한 조건 1개 생략을 확인했습니다.
- 브라우저에서 업데이트를 미룬 뒤 아이콘 유지, 설정 위 배치, 접힌 사이드바 순서, 실제 원형 28px, 새 버전이 없을 때 숨김 및 높이 0을 확인했습니다.
- 브라우저에서 6개 요약과 공개 중간 설명, 상세 50개 조회 및 이전 기록 65개까지 조회, 접은 뒤 상세 행 0개와 요약 6개 유지를 확인했습니다. 도구 실행 보고 → 답변 작성 → 도구 호출 준비로 실제 수신 프레임에 따른 상태 전환도 확인했습니다.

- 단일 EXE 빌드와 내장 파일 추출 검증을 통과했습니다. EXE/VBS ZIP의 공통 앱 파일 **127개**가 동일합니다. Python 실행 환경·설치 프로그램은 포함하지 않습니다.

브라우저 검증은 격리된 모의 CLI 자료를 사용했습니다. 실제 AI 요청이나 업데이트 설치를 실행한 검증은 아닙니다. 사내 GitLab 및 사내 PC의 전체 실행은 현장 확인 범위입니다.
