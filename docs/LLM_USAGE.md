# LLM 사용량 표시

왼쪽 하단 앱 메뉴 위에 `LLM 토큰 사용량`을 표시합니다. 서비스에서 제공하는 수치는 **팀 사용 금액/예산**입니다. 실제 토큰 개수로 변환하지 않으며 상세 패널에 기준을 설명합니다.

운영자는 앱을 실행하는 계정에 `LLMOPS_MCP_URL` 환경변수를 지정합니다. 기본 팀 별칭은 `hcp-pro-tier`이고 `LLMOPS_TEAM`으로 변경할 수 있습니다. 사내 서버 주소나 KEY를 배포 소스에 기록하지 않습니다. 환경변수 변경 후 앱을 완전히 종료하고 다시 실행하세요.

KEY는 `SK_BUDGET_HUD_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_API_KEY`, 사용자 `.claude/settings.json`의 `env.ANTHROPIC_AUTH_TOKEN`, `OPENAI_API_KEY` 순서로 읽습니다. 스토어 연결 KEY와 별개이며 브라우저·로그·업무 요청에 전달하지 않습니다. 인증 헤더를 다른 주소로 리디렉션하지 않습니다.

- 앱의 `--demo` 실행 또는 명시적 `LLMOPS_DEMO=1`에서만 예시 수치를 표시합니다. 실제 조회 실패를 예시나 0으로 대체하지 않습니다. 운영 환경에서는 이 변수를 해제하세요.
- 조회는 별도 스레드에서 수행하며 대화 처리 잠금을 사용하지 않습니다. 5분 캐시, 동시 조회 합치기, 수동 새로고침 최소 15초 간격, 실패 후 1분 대기, 네트워크 조회 약 9초 제한을 적용합니다.
- MCP initialize/session-id/initialized/tool 호출을 사용하며 JSON과 여러 이벤트를 포함한 SSE를 처리합니다. 응답 크기는 512 KiB로 제한합니다.
- 80%는 주의, 95%는 한도 임박으로 표시합니다. 색상과 문구를 함께 사용하고 작업을 강제로 중단하지 않습니다. 한도 0은 비율을 계산하지 않고 `한도 미설정`으로 표시합니다.
- 인증 오류는 `LLM Key 확인이 필요합니다.`, 연결 오류는 조회 실패로 구분합니다. 이전 값이 있으면 마지막 확인 시각과 함께 유지합니다.
- 오프셋 없는 초기화 시각은 서비스의 한국 시간 기준으로 해석하고 `KST`를 표시합니다.

검증: `tests/test_llm_usage.py`의 로컬 MCP HTTP 시험, `tests/test_extension_requests.py`의 독립 실행/초안 보존 시험. 사내 MCP 실제 연결은 사내망에서 별도로 확인해야 합니다.
