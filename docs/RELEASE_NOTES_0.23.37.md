# AX Workspace 0.23.37 — 외부 대화 불러오기와 알림 개선

다른 도구에서 이어 쓴 Claude 대화를 해당 업무 또는 일반 대화에 불러오고, 입력창의 안내를 더 편하게 확인할 수 있습니다.

- **대화 내용 불러오기:** 동일한 Claude 세션에 외부에서 추가된 대화가 확인되면 해당 대화 입력창 위에 버튼이 나타납니다. 외부 작업을 마친 뒤 대화를 선택해 확인하고, 버튼을 눌러 가져오세요. 이미 앱을 열어 둔 경우 해당 대화를 다시 선택하면 확인합니다. 작성 중인 입력과 첨부는 유지합니다.
- **확인 시점과 안전한 처리:** 대화를 선택할 때 비동기로 한 번 확인하며 주기적인 대화 파일 조회는 하지 않습니다. 기존 대화와 원본이 정확히 일치하지 않거나 앱의 표시 한도(150개 메시지 또는 50만 자)를 넘으면 기존 기록을 보존하고 불러오지 않습니다.
- **안내 위치와 표시 시간:** 승인 모드 변경 안내를 입력창 위 중앙에 표시하고 3초 뒤 닫습니다. 안내가 입력창의 버튼을 가리지 않습니다.
- **사용량 조회와 업데이트:** 사용량을 새로고침해도 준비 중인 업데이트의 상태 확인을 불필요하게 무효화하지 않도록 수정했습니다.

Claude Code 2.1.306에서는 앱이 비대화식으로 생성한 세션이 `/resume` 선택 목록에 표시되지 않을 수 있습니다. 이 릴리스는 목록 표시 기능을 추가하지 않습니다. 동일한 설정과 작업 폴더에서 세션 ID를 직접 지정해 이어갈 수 있습니다.

대화 기록 저장 잠금의 성능 구조는 변경하지 않았습니다. 테스트 중 확인된 저장 전 답변 노출 및 이벤트 순서 경합을 방지하기 위해 기존 저장 방식을 유지합니다.

관련 기능은 격리된 로컬 테스트 및 Edge 화면으로 검증했습니다. 실제 사내 운영 서버와 사용자 데이터에서는 별도 확인이 필요합니다.
