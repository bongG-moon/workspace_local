# Workspace 0.21.9 검증 기록

검증일: 2026-10-01. 일반 HTML 미리보기와 좌우 패널 색상 변경을 검증했습니다.

## 변경 내용

- 특정 보고서 표식이 없는 일반 HTML/HTM도 정적 웹 화면으로 열립니다. 작은따옴표, 추가 클래스, 대문자 태그와 속성 주변 공백 때문에 코드로 분류되던 조건을 제거했습니다.
- 미리보기의 **화면 / 코드** 버튼으로 같은 파일을 전환합니다. 코드는 원문 앞 100,000자까지 표시하고 복사할 수 있습니다. 원본 파일은 수정하지 않습니다.
- CSS의 외부 자원 참조를 제거해도 무관한 색상·레이아웃 규칙을 보존합니다. 기존 보고서 전용 보정은 실제 보고서 구조가 확인된 문서에만 적용합니다.
- 스크립트·이벤트·외부 요청·폼 전송은 미리보기에서 동작하지 않습니다. iframe의 빈 sandbox, no-referrer와 선행 CSP를 유지합니다.
- 보기 전환 시 이전 iframe을 제거하고, 닫기·업무 전환 시 보관한 원문과 DOM을 해제합니다. 늦게 도착한 이전 닫기 이벤트가 새 미리보기를 닫지 않도록 처리했습니다.
- 좌측 업무와 우측 자료·결과 패널을 연한 블루그레이로 변경했습니다. 선택 항목과 검색·폴더·파일 카드도 같은 톤으로 조정했습니다.

## 자동 검사

HTML 처리, 파일 미리보기, 파일 동작, 레이아웃, 로컬 서버 관련 101개 검사를 실행했습니다. 격리 계정에서 실행기 검사 3개가 WS-31로 중단됐으며, 실제 로그인 계정에서 해당 3개를 재실행해 모두 통과했습니다. 최종 결과는 98개 통과, 선택적 연동 검사 3개 건너뜀입니다.

```text
python -X utf8 -m unittest tests.test_html_workspace_preview tests.test_workspace_file_preview tests.test_workspace_file_actions_frontend tests.test_workspace_layout_frontend tests.test_local_workspace
```

별도로 프런트엔드 상태·리치 콘텐츠·파일 동작 42개 검사를 통과했습니다. 늦은 닫기 이벤트 방어를 추가한 뒤 파일 동작 8개를 다시 실행해 통과했습니다. 서로 겹치는 검사는 총합으로 더하지 않았습니다.

주요 확인 항목:

- 일반 HTML, 문서 조각, 기존 보고서 및 표식 표기 변형
- 원본 소스 반환, 100,000자 잘림, 1 MiB 제한, 지원 인코딩, 원본 바이트 보존
- 스크립트·iframe·메타 이동·외부 URL·폼 전송 제거, CSS의 다른 규칙 보존
- 가짜 표식, 중복 속성, CSS escape·문자열·주석 처리
- 화면/코드 전환 시 추가 API 호출 없음, 원문의 문자 표시, 기존 iframe 제거
- 업무 전환과 늦은 응답·닫기 이벤트가 다른 파일 미리보기를 덮지 않음
- HTML을 닫고 다른 파일을 열 때 보기 방식 초기화

CSS escape를 반복한 1,000,012자 입력의 별도 측정은 약 0.25초였습니다. 이 측정은 CSS 필터의 처리 시간이며 브라우저 전체 메모리 사용량이나 모든 HTML의 성능 보장은 아닙니다.

## 실제 Windows 화면 확인

가상 업무와 가상 HTML만 사용해 소스 기반 체험 창과 최종 EXE의 WebView2 창을 Computer Use로 확인했습니다.

- 연한 블루 패널, 선택된 업무, 자료 카드와 중앙 대화 영역 구분
- 표식 없는 일반 HTML의 제목·카드·표·배경색 표시
- 외부 이미지 URL과 CSS import가 있어도 나머지 배치 유지
- 화면 → 코드 → 화면 전환, 원문 코드 및 복사 버튼 표시
- 최대화 및 709×465 캡처 크기 창에서 전환·닫기·파일 열기 버튼 표시
- 최종 EXE의 인증된 API에서 일반 HTML과 표기 변형 HTM은 html, 일반 TXT는 text로 반환
- 검증용 파일 3개의 원본 내용 불변

전체 스크립트 동작을 앱 미리보기 안에서 실행하는 기능은 아닙니다. 외부 스타일·폰트·이미지 또는 JavaScript 생성 내용은 원본과 다를 수 있으며 **기본 앱에서 열기**로 확인합니다. 이번 검증에서는 외부 앱을 자동 실행하지 않았습니다. 모든 실제 회사 문서·보안 정책·화면 배율 조합을 검증한 결과는 아닙니다.
