# 0.23.26 사내 최신 설치 EXE 검증

검증일: 2026-10-15. 이 문서는 로컬 구현·검증 기록이며 사내 GitLab 게시 완료를 뜻하지 않습니다.

## 구현 범위

- 사내 배포 설정을 내장한 `AX-Workspace-Install.exe`를 생성합니다. 게시용 토큰·SSH 키는 포함하지 않습니다.
- 최신 채널 → 채널에서 해시가 확인된 SHA256 목록 → 해당 버전의 NSIS Setup을 순서대로 검증합니다.
- 기존 업데이트 채널의 파일 항목은 그대로 유지합니다. 배포 패키지에는 4개 ZIP·Setup·최신 설치 EXE·SHA256 목록이 들어갑니다.
- 다운로드는 64KB 단위로 처리합니다. UI 진행률은 최대 초당 8회 갱신하며 상주 서비스·앱 폴링은 추가하지 않습니다.
- Windows 파일 실행 시 쓰기 핸들이 열려 있으면 실행이 거절되는 문제를 점검했습니다. 다운로드 후 읽기 전용으로 다시 열어 해시를 확인하고, 설치 프로세스가 끝날 때까지 변경·삭제를 막습니다.

## 확인한 결과

| 검사 | 결과 |
| --- | --- |
| 실제 C# 컴파일 기반 프로토콜·파일 수명 검사 | 46개 통과 |
| Windows 설치 EXE 생성·내장 설정·덮어쓰기 거부 | 2개 통과 |
| 사내 배포 도구 core/workflow/installer/GUI | 104개 통과; 마지막 보고서 검증 강화 후 installer 15개 재검사 통과 |
| 릴리즈 이력·GitLab 업데이트·설치·배포·GitHub 파일 구성 | 78개 통과 |
| 서버 시작 응답과 현재 버전 | 1개 통과 |

중복 재검사를 제외한 관련 자동 검사 231개가 통과했습니다. 화면·문서 조정 후 설치 EXE 빌드와 배포 구성 5개도 다시 확인했습니다.

- 같은 설정을 가진 설치기가 채널 변경에 따라 0.23.26과 0.23.27을 선택합니다.
- 잘못된 해시·파일 크기·버전·제품명·리디렉션과 취소를 처리하고 불완전한 파일을 실행하지 않습니다.
- 실제 생성한 무해한 테스트 EXE를 실행해 Windows 읽기 전용 파일 잠금과 실행의 호환성을 확인했습니다.
- 실제 생성한 NSIS Setup도 운영 설치기 엔진을 통과했습니다. 이 검사는 실행기를 대체하여 **NSIS를 실제 설치하지 않았습니다**.
- 예시 HTTPS 서버 설정으로 EXE·VBS 공통 소스 154개가 같은 전체 배포 파일 7개를 생성하고 게시 검증기로 검사했습니다.
- Computer Use로 실제 설치 폼을 확인했습니다. 처음 발견한 고해상도 글자 겹침을 수정한 뒤 준비·진행·완료 화면을 확인했습니다. 이 화면 검사는 가상 다운로드·실행기를 사용했습니다.

## 남은 운영 확인

외부에서 사내 GitLab에 접속하거나 게시하지 않았습니다. 사내에서 실제 서버 주소·Project ID를 넣고 배포하면 도구가 익명 다운로드와 해시를 확인합니다. 사내 인증서·프록시·EXE 실행 정책과 실제 사용자 설치는 해당 환경에서 확인해야 합니다.

로컬 검증 파일의 서버는 `example.invalid` 예시입니다. 이 EXE를 사용자에게 배포하지 마세요. 사용자용 설치 EXE는 사내 배포 도구에서 실제 설정으로 생성합니다.
