# AX Workspace 0.23.44 — 큰 파일 미리보기와 발표 자료 호환 개선

버전은 **0.23.44**를 유지하고 2026-11-09에 설치 파일과 배포 자료를 갱신했습니다. 큰 파일의 미리보기와 발표용 HTML 호환을 보완했으며, 기존 자료 탐색과 대화 사용성 개선도 포함합니다.

## 이번 수정본의 추가 개선

- HTML과 CSV/TSV의 미리보기 파일 한도를 **10MB**로 늘렸습니다. HTML 코드 탭은 앞 **100,000자**, 표 화면은 앞 **100행과 30열**을 표시합니다. 표시 범위와 전체 행 수를 구분해 안내합니다.
- 큰 CSV/TSV에서도 **이 범위로 질문**과 최신 값으로 교체가 동작하도록 원본 확인 범위를 맞췄습니다. 원본이 바뀌면 기존 인용의 전송을 계속 차단합니다.
- CSV를 읽을 때 전체 문자열의 중복 복사를 줄였습니다. 큰 HTML의 CSS 처리 메모리도 줄이고, 긴 처리 중 다른 업무의 요청도 진행할 수 있도록 보완했습니다. 큰 파일 자체를 처음 읽고 표시하는 시간은 필요합니다.
- HTML의 같은 **화면 / 코드** 탭을 다시 눌러도 내용을 불필요하게 다시 만들지 않으며, 현재 스크롤 위치를 유지합니다.
- 발표용 HTML의 슬라이드가 숨겨져 빈 화면이 되던 문제를 수정했습니다. 앱이 인식하는 발표 자료는 **모든 장을 세로로 스크롤**해 확인하며 원래 비율과 표, 글자 배치를 유지합니다. 원본 파일은 바꾸지 않고 스크립트도 실행하지 않습니다. 슬라이드 전환이나 문구 편집은 **기본 앱에서 열기**로 사용하세요.
- Excel, PowerPoint, PDF는 기존처럼 기본 앱으로 확인합니다. 채팅에 문서를 첨부해 내용을 전달하는 기능과 앱 안의 미리보기 지원은 별개입니다.

## 자료 확인과 변경 비교

- CSV와 TSV는 **원본 표를 먼저** 보여 줍니다. 표시된 행과 열의 범위를 안내하며, 그래프는 확인할 지표를 골라 볼 수 있습니다. 요청에 대한 분석 결과와 그래프는 채팅 답변에서 확인합니다.
- 표의 셀이나 그래프의 점과 구간을 선택해 **이 범위로 질문**할 수 있습니다. 질문 초안에서 실제 값을 확인하고, 원본이 바뀌면 최신 범위로 교체할 수 있습니다.
- 미리보기의 **넓게 보기 / 팝업으로 보기**를 제공하며, 같은 업무에서 파일을 다시 열 때 정렬과 선택 등 검토 상태를 유지합니다.
- 코드는 현재 파일을 줄 번호와 문법 색상으로 보여 줍니다. **변경 내용 보기**에서 수정 전후를 한 화면 또는 나란히 비교하며, 새 파일과 삭제 파일도 보관된 변경 기록으로 확인합니다.
- 명령 실행 중 관찰한 폴더 변경은 확인된 업무 결과와 구분합니다. 다른 업무의 변경이 섞일 수 있는 후보는 내용을 보고 **이 업무 결과에 추가**하거나 제외할 수 있습니다.
- 미리보기를 열 수 없으면 이해하기 쉬운 설명과 파일 종류에 맞는 **기본 앱에서 열기 / 폴더에서 보기**를 안내합니다.

## 대화와 업무 목록

- 업무 목록과 자료 목록의 간격을 줄이고 탐색창의 기본 너비와 코드 표시 높이를 다듬었습니다. 스킬과 기능은 핵심 정보를 먼저 보여 주고 긴 설명은 **더 보기**로 펼칩니다.
- 업무 홈은 **최근 진행 업무**를 최근 활동 순서로 보여 줍니다. 직접 정한 업무 이름은 유지하고, 이름을 비운 새 업무는 첫 요청의 목적에 맞춰 이름을 만듭니다.
- 현재 대화를 실제로 열어 확인하면 관련 알림을 읽음으로 처리합니다. 알림 항목을 누르면 해당 대화로 이동하며 읽음 처리가 승인이나 답변을 대신하지 않습니다.
- 첨부가 있는 요청 말풍선의 위아래 여백과 파일 버튼을 줄였습니다. 라이트와 다크 모드의 로고, 아이콘 정렬과 주변 효과도 정리했습니다.
- 설치 방식에 따라 달라지는 Claude 실행 파일 탐색을 보완하고, 여러 업무를 오갈 때의 클릭과 화면 갱신을 다듬었습니다.
- 사용 도움말과 안내서에 최신 버튼명, 파일 확인, 사용량 조회, 선택 확장 스토어의 설치와 업데이트 방법을 반영했습니다.
- 기존 폴더 순서 변경은 유지됩니다. 접기 화살표를 짧게 누르면 접거나 펼치고, 약 1초 누른 뒤 끌면 순서를 바꿉니다. 폴더 설정의 위로 이동 / 아래로 이동과 **Alt+↑ / Alt+↓**도 사용할 수 있습니다.

## 설치와 사내 배포

- 일반 설치: **AX-Workspace-0.23.44-Setup.exe**
- 사내 반입과 재빌드: **workspace-local-0.23.44-source.zip**
- 기존 업데이트용 EXE/VBS ZIP과 호환 파일명도 함께 갱신했습니다. 같은 0.23.44의 수정본은 설정의 빌드 번호로 구분할 수 있습니다. 기존 0.23.44 사용자는 최신 Setup을 다시 받아 설치하세요. 같은 버전의 다른 빌드가 실행 중이면 트레이에서 완전히 종료한 뒤 실행합니다.

P&T AI Square 확장은 **0.1.0** 배포본을 계속 사용할 수 있습니다. 관리자용 Distribution ZIP에서 서버 주소를 지정해 사내 설치 파일을 만듭니다. 기본 앱의 기존 확장 연결과 개인 데이터는 유지합니다.

VDI 클릭 진단 도구 1.0.0은 기존 파일을 계속 제공합니다. 격리된 시험의 결과와 실제 사내 서버 및 VDI 환경의 동작은 구분해야 합니다.
