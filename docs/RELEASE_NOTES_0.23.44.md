# AX Workspace 0.23.44 — 업무 폴더 순서 변경

왼쪽 업무 목록에서 폴더 순서를 바꿀 수 있습니다. 기존 접기 화살표를 사용해 별도 손잡이 없이 목록을 정리합니다.

- **화살표를 짧게 클릭:** 폴더를 접거나 펼칩니다. 폴더 이름을 눌러도 기존처럼 동작합니다.
- **화살표를 약 1초 누른 뒤 드래그:** 폴더를 원하는 위치로 옮깁니다. 이동할 위치가 선으로 표시되며, 놓았을 때 폴더가 뜻하지 않게 접히지 않습니다.
- **다른 이동 방법:** 폴더 옆 `···`의 폴더 설정에서 **위로 이동 / 아래로 이동**을 사용하거나, 화살표에 키보드 초점을 두고 **Alt+↑ / Alt+↓**를 누릅니다.
- **자동 저장:** 변경한 폴더 순서는 앱을 다시 열어도 유지됩니다. 폴더 안의 업무, 대화, 초안, 첨부와 실제 작업 디렉터리는 그대로 유지합니다.
- **오동작 방지:** 1초가 지나기 전에 마우스를 크게 움직이거나, Escape를 누르거나, 다른 창 또는 입력창으로 이동하면 순서 변경을 취소합니다. 검색 중에는 검색어를 지운 뒤 순서를 바꿀 수 있습니다.

설치 파일은 `AX-Workspace-0.23.44-Setup.exe`, 사내 반입용 소스는 `workspace-local-0.23.44-source.zip`입니다. 기존 자동 업데이트용 EXE/VBS ZIP과 호환 파일명도 제공합니다. 사내 운영 서버에는 이 소스 ZIP으로 새 버전을 빌드하고 최신 채널을 갱신해 주세요.

기존 VDI 클릭 진단 도구 1.0.0도 함께 제공합니다. 진단 도구는 별도 실행 파일이며, 이번 폴더 정렬 기능이 VDI 좌표 문제나 Claude 연결 및 답변 문제의 수정이라는 의미는 아닙니다. P&T AI Square 확장과 플랫폼은 기존 배포본을 사용합니다.
