어려운 명령어 없이 업무를 시작하는 방법부터 차근차근 안내합니다.

앱 화면에 표시된 버튼 이름으로 설명해요
처음 시작자료와 결과이어서 하기·분기실행 예약창 닫기·알림업무 정리편리한 입력앱 업데이트도움이 필요할 때

1. 내 상황에 맞게 시작하기

왼쪽 새 업무를 누르면 아래 세 가지 방법이 나옵니다. ‘업무’는 한 가지 일을 위한 대화이며, ‘업무 폴더’는 그 일의 자료와 결과를 저장하는 곳입니다.

1

새 업무 공간 만들기

새로운 보고서나 분석을 시작할 때

  1. 새 업무를 누릅니다.
  2. 업무 이름을 적고 새 업무 공간 만들기를 고릅니다.
  3. 저장 위치를 확인합니다. 바꾸려면 위치 변경을 누릅니다.
  4. 폴더 사용 동의에 체크하고 업무 시작을 누릅니다.

새 폴더와 빈 대화가 준비됩니다. 기본 저장 위치는 화면에 표시된 바탕화면 아래 폴더입니다.

예: ‘10월 실적 보고서’ 업무를 만들고 엑셀 자료를 추가하기
2

기존 폴더 사용하기

이미 자료를 한 폴더에 모아 뒀을 때

  1. 새 업무 → 기존 폴더 사용하기를 고릅니다.
  2. 찾아보기에서 폴더를 엽니다.
  3. 원하는 폴더 안에서 선택을 확정합니다.
  4. 폴더 사용 동의에 체크하고 업무 시작을 누릅니다.

그 폴더에서 새 대화를 시작합니다. 폴더를 고르는 것만으로 예전 대화를 가져오지는 않습니다.

예: 바탕화면 ‘회의자료’ 폴더의 문서를 요약하기
3

기존 세션 활용하기

전에 Claude와 나눈 대화를 이어갈 때

  1. 새 업무 → 기존 세션 활용하기를 누릅니다.
  2. 목록에서 이전 대화를 고릅니다. 알고 있는 대화 번호(세션 ID)로 찾아도 됩니다.
  3. 대화 내용과 원래 폴더를 확인합니다.
  4. 업무에 추가하고 이어가기를 누릅니다.
  5. 추가할 내용을 입력하고 보냅니다. 폴더 확인이 나오면 확인합니다.

이전 대화와 원래 작업 폴더가 함께 연결됩니다. 목록을 불러오기만 해서는 AI 작업이 시작되지 않습니다.

폴더 사용 동의란? Claude가 그 폴더의 자료와 기존 자동 처리 설정을 사용하도록 허용하는 단계입니다. 내가 알고 신뢰하는 폴더인지 확인하세요. 같은 대화가 다른 Claude 창에서 작업 중이라면, 그 작업을 마친 뒤 여기서 이어가세요.

2. 자료를 넣고 결과 확인하기

  1. 자료 추가를 누르고 앱 안의 선택창에서 파일을 고릅니다. 폴더를 열어 이동하고, 여러 파일을 선택한 뒤 추가할 수 있습니다. 왼쪽 바로가기로 바탕화면·문서·다운로드에 빠르게 갈 수 있습니다.
  2. 또는 탐색기의 파일을 입력창에 끌어 놓으세요. 오른쪽 업무 공간·결과의 파일도 입력창으로 끌어 참조할 수 있습니다. 입력창에 첨부 표시가 생겼는지 확인하세요.
  3. 원하는 결과를 적고 Enter 또는 보내기를 누릅니다. 줄을 바꾸려면 Shift+Enter를 누르세요. 예: ‘첨부한 표에서 매출이 줄어든 부서를 찾아 이유를 설명해 줘.’
  4. 질문이나 승인 요청이 나오면 내용을 읽고 답합니다. 선택지만 눌러도 되는 질문은 항목을 클릭할 수 있습니다.
  5. 완료 후 오른쪽 이번 결과에서 파일을 확인합니다. 기본 앱에서 열기로 엑셀·PowerPoint·메모장·웹 브라우저 등 PC에 연결된 앱에서 열 수 있습니다.

경로를 알고 있다면 경로로 추가를 쓸 수 있습니다. 앱 선택창으로 찾기 어려운 위치는 선택창의 Windows 선택 기능을 이용하세요. 취소하면 기존 입력과 첨부는 그대로 남습니다.

지금 어떤 일을 하는지 확인하기

입력창 위 상태 줄에 최근 도구와 동작이 표시됩니다. 예를 들어 자료 읽기 · Read · 분기 실적.csv는 해당 파일을 읽는 도구를 호출한 기록입니다. 스킬을 쓰면 Skill과 스킬 이름이 함께 나옵니다. 여러 도구를 동시에 호출한 경우 함께 표시되는 개수도 확인할 수 있습니다.

활동을 누르면 그 요청의 도구·스킬 기록을 펼쳐 볼 수 있습니다. ‘요청’은 도구를 불렀다는 뜻이고, ‘실행 중’은 Claude가 진행 정보를 보냈다는 뜻입니다. ‘결과 수신’은 해당 도구의 응답이 돌아왔다는 뜻이며 전체 업무나 백그라운드 작업의 완료와는 다릅니다. ‘결과 미확인’은 종료나 연결 중단으로 결과를 확인하지 못했다는 뜻입니다.

승인·질문이 나왔을 때는 필요한 응답이 우선 표시됩니다. 도구 기록만으로 Claude의 내부 판단 과정이나 정확한 진척률을 알 수는 없습니다. 현재 보관된 최근 활동만 표시하며, 이전 버전에서 수집하지 않은 도구 기록은 새로 만들어 표시하지 않습니다.

첨부한 원본 파일은 이동되나요?

파일을 고르는 기능은 원본을 옮기지 않습니다. 탐색기에서 끌어 넣어 업로드한 파일은 앱 관리 공간에 복사됩니다. 이미 업무 공간에 있는 파일은 그 경로를 참조합니다. 첨부한 뒤 요청에서 원본 수정을 지시하면 실제 파일이 바뀔 수 있습니다.

이미지·표·코드는 어디서 보나요?

대화에 제공된 이미지·표·코드는 대화 영역에서 확인할 수 있고, 생성된 파일은 ‘이번 결과’에서 열 수 있습니다. 코드가 표시됐다는 이유만으로 실행되는 것은 아닙니다. HTML의 앱 미리보기는 정적 화면이며, 기본 브라우저에서 열면 해당 파일의 스크립트와 외부 연결이 동작할 수 있습니다.

3. 이어서 분석하거나 다른 방향 시도하기

같은 대화에서 이어서 하기

완료된 업무를 선택하고 입력창에 다음 부탁을 적으면 됩니다. 새 업무를 만들 필요가 없습니다.

‘방금 만든 표를 부서별로 나눠 줘.’
‘같은 내용으로 발표용 요약도 만들어 줘.’

작업 중이라면 다음 두 버튼으로 처리 순서를 고릅니다.

  • 끝나고 이어서: 현재 요청이 끝난 다음 순서대로 실행합니다.
  • 지금 반영: 현재 요청을 중지하고 새 요청으로 이어갑니다. 이미 수정한 파일은 되돌리지 않습니다.

이어 할 일을 누르면 대기 중인 부탁을 수정·취소하거나 순서를 바꿀 수 있습니다. 승인·질문 대기 중에는 먼저 응답해야 다음 일이 진행됩니다.

대화 분기로 다른 안 만들기

원래 대화를 남겨 두고 다른 방향을 비교할 때 씁니다.

  1. 현재 작업과 승인·질문을 마칩니다.
  2. 업무 제목 옆 대화 분기를 누릅니다.
  3. 안내를 확인하고 새 업무를 만듭니다.
  4. 새 업무에 다른 방향의 요청을 보냅니다. 첫 요청 때 별도 Claude 대화가 만들어집니다.
원래 대화는 ‘자세한 보고서’, 분기한 대화는 ‘임원용 한 장 요약’으로 이어가기

두 대화는 같은 폴더를 사용합니다. 다른 안을 보관하려면 ‘새 파일 이름으로 저장해 줘’라고 요청하세요. 대기 요청·예약·첨부 초안은 복제하지 않습니다. 현재는 마지막 완료 기록을 기준으로 분기합니다.

4. 정해진 시간에 실행 예약하기

  1. 예약할 업무를 먼저 선택합니다.
  2. 입력창 위 실행 예약을 누릅니다. 미리 적은 요청과 첨부가 있다면 가져옵니다.
  3. 실행할 요청에 할 일을 적습니다.
  4. 한 번·매일·매주 중 하나를 고르고 날짜·시간이나 요일을 정합니다.
  5. 저장을 누른 뒤 이어 할 일에서 다음 실행 시각을 확인합니다.
예: 매주 월요일 오전 9시, ‘이 폴더의 지난주 자료를 읽고 주간 요약을 새 파일로 만들어 줘.’

예약을 고치거나 멈추려면 이어 할 일에서 해당 예약의 수정·일시정지·삭제를 누릅니다. 다시 시작하려면 예약 재개를 누릅니다.

예약이 실행되려면
  • PC가 깨어 있고 앱이 실행 중이어야 합니다. 창을 닫아 트레이 아이콘만 남긴 상태에서도 실행됩니다.
  • PC가 꺼져 있거나 절전 중이면 깨워서 실행하지 않습니다. 놓친 예약을 나중에 한꺼번에 실행하지도 않습니다.
  • 시간은 이 PC의 현재 시간대를 따릅니다. 이전 작업이나 응답 대기가 있으면 먼저 해결해야 합니다.
  • 앱을 완전히 종료했다가 다시 켰다면 폴더와 대기·예약 내용을 확인하고 이어 실행해 주세요.
  • 예약도 현재 Claude 인증과 승인 방식이 필요합니다. 승인·질문이 생기면 자동으로 대신 답하지 않고 사용자의 응답을 기다립니다.

5. 창을 닫아도 계속 일하나요?

네. 트레이 아이콘이 남아 있으면 백그라운드에서 계속 동작합니다. 작업 표시줄 오른쪽의 작은 위쪽 화살표(숨겨진 아이콘 표시)를 누르면 Workspace 아이콘을 찾을 수 있습니다.

내가 누른 것화면은?작업·예약은?
최소화 −작업 표시줄로 내려갑니다.계속 진행됩니다.
창 닫기 × / 트레이로 보내기창이 숨겨지고 트레이 아이콘이 남습니다.계속 진행됩니다. 질문이 나오면 응답을 기다립니다.
설정 → 완전히 종료창과 트레이 아이콘이 종료됩니다.진행 중인 작업을 멈추고 예약도 실행하지 않습니다.
PC 절전 / 전원 끄기PC가 쉬거나 꺼집니다.그동안 진행할 수 없습니다.

다시 보려면 트레이 아이콘 우클릭 → 앱 열기를 누르세요. 끝내려면 같은 메뉴의 완전 종료 또는 앱 설정의 완전히 종료를 누릅니다. 트레이를 사용할 수 없는 환경에서는 창 닫기가 앱 종료로 동작할 수 있으므로 설정의 창 동작 안내를 확인하세요.

완료나 응답 요청 알림을 받으려면

  1. 설정 → PC 알림이 켜져 있는지 확인합니다.
  2. 작업 완료, 승인·질문·선택 대기, 오류·확인 필요 중 필요한 항목을 켭니다.
  3. 다른 앱에서 일하거나 Workspace 창을 닫아 두어도 PC 알림으로 알려줍니다. 알림의 업무 열기를 누르면 해당 대화로 돌아갑니다.

알림은 다른 앱의 화면을 강제로 빼앗지 않습니다. 현재 보고 있는 업무는 화면 안의 상태를 확인하세요. 여러 알림이 겹치면 순서대로 표시될 수 있습니다.

Windows가 알림 표시를 제한하는 상태에서는 PC 배너가 나오지 않을 수 있습니다. 이때도 질문과 완료 기록은 앱에 남습니다.

알림을 놓쳤다면 상단 ‘알림’을 누르세요. ‘응답 필요’에서 아직 답해야 할 업무를 찾을 수 있습니다. 알림을 읽음으로 바꾸는 것은 승인이나 답변이 아닙니다. PC 알림을 꺼도 앱 알림함의 기록은 확인할 수 있습니다. 브라우저로 접속한 경우에는 별도의 브라우저 알림 허용이 필요할 수 있습니다.

6. 업무 목록을 깔끔하게 정리하기

  • 이름 변경: 업무 제목에서 알아보기 쉬운 이름으로 바꿉니다.
  • 핀 고정: 자주 쓰는 업무를 목록 위에 고정합니다. 손잡이를 끌어 같은 고정 그룹 안에서 순서를 바꿀 수 있습니다.
  • 목록에서 삭제: 업무의 삭제 버튼을 누른 뒤 확인창에서 내용을 읽고 확인합니다. 취소하면 그대로 남습니다.

삭제되는 것은 앱 목록의 표시뿐입니다. 실제 Claude 대화 기록과 업무 폴더·결과 파일은 지우지 않습니다. 원래 Claude 대화가 저장되어 있다면 새 업무 → 기존 세션 활용하기로 다시 추가할 수 있습니다.

진행 중이거나 응답을 기다리는 업무, 대기 요청·실행할 예약이 남은 업무는 바로 제거할 수 없습니다. 필요한 답변을 마치고 대기·예약을 정리한 뒤 다시 시도하세요. 앱이 임의로 작업을 중지하거나 예약을 없애지 않습니다.

파일이 어떻게 바뀌었는지 확인하기

이번 결과 → 파일 변경 비교에서 요청과 파일을 고르면 앱이 저장한 이전·이후 내용을 볼 수 있습니다. 지원하는 텍스트 파일의 일부 범위만 보관하며, 이미지·Office 문서는 파일 정보로 표시될 수 있습니다. 원본을 자동으로 되돌리는 기능은 아닙니다.

스킬·도구 목록 보기

스킬·도구에서 공통 또는 폴더를 골라 설치된 스킬을 봅니다. 도구·연결 서버·명령은 선택한 업무의 실제 Claude 연결에서 제공한 정보입니다. ‘연결 필요’는 연결을 확인해야 한다는 뜻이고, ‘CLI 미제공’은 항목이 0개라는 뜻이 아닙니다.

7. 익숙해지면 더 빠르게

Enter로 보내고, Shift+Enter로 줄을 바꾸세요. 작업 중에 Enter로 보내면 현재 요청을 마친 뒤 이어서 처리하도록 대기합니다. 보내기 버튼도 그대로 사용할 수 있습니다.

입력창 아래 모델·Effort·승인을 눌러 현재 업무의 설정을 바꿀 수 있습니다. 설정만 바꿔서는 AI 작업을 시작하지 않습니다. 연결에서 제공한 항목만 선택할 수 있으며, 개인 Claude 설정 파일을 자동으로 덮어쓰지 않습니다.

Effort와 승인 모드는 무슨 뜻인가요?

Effort는 답변을 만들 때 생각하는 수준입니다. 모델에 따라 지원하는 값이 다릅니다. 승인 모드는 파일 변경이나 명령 실행 전에 어떻게 확인받을지 정합니다. 기존 설정을 사용해도 괜찮습니다.

⚠ Bypass는 파일 수정과 명령 실행 등의 승인 확인을 생략할 수 있습니다. 별도 위험 확인을 거쳐 해당 업무에서만 선택하며, Shift+Tab이나 Alt+M으로 우연히 켜지지 않습니다.

스킬·파일 자동완성 사용하기

/ 뒤에 스킬·명령의 앞부분을 적거나 @ 뒤에 파일 이름을 적으면 후보를 보여줍니다. ↑·↓ 또는 Ctrl+P·Ctrl+N으로 이동하고 Tab이나 Enter로 고르세요. 후보를 고른 뒤 Enter를 한 번 더 눌러 보내면 됩니다. Esc를 누르면 후보만 닫고 적은 내용은 그대로 둡니다.

한글을 조합하는 중에는 Enter가 글자 입력을 확정합니다. 이때 요청을 보내거나 후보를 선택하지 않습니다. 자동완성이나 모델 목록을 여는 것만으로 AI 작업을 시작하지 않습니다.

Ctrl+S로 적던 내용을 잠시 치워 두기

긴 요청을 쓰다가 다른 질문을 먼저 하고 싶을 때 Ctrl+S를 누르세요. 글과 첨부를 잠시 보관하고 입력창을 비웁니다. 빈 입력창에서 Ctrl+S를 다시 누르면 꺼낼 수 있습니다. 다른 요청을 보낸 뒤에도 입력창이 비어 있으면 보관한 내용을 다시 보여 줍니다.

새로 쓰고 있는 내용은 덮어쓰지 않습니다. 보관 공간은 업무마다 한 개입니다. 다른 글을 적고 Ctrl+S를 다시 누르면 보관한 내용을 새 글로 교체합니다.

터미널의 모든 기능을 단축키로 쓸 수 있나요?

터미널 안에서만 관리되는 일부 기능은 설정 → 고급 기능 → 원본 Claude Code 열기에서 사용하세요. Ctrl+B(작업 백그라운드 전환), Ctrl+T(터미널 작업 목록), Ctrl+G(외부 편집기), Ctrl+D(CLI 종료), Esc 두 번(되감기)이 해당합니다.

이 키를 앱의 트레이 실행·이어 할 일·대화 분기처럼 다른 의미의 기능에 연결하지 않습니다. 사용자 본인이 바꾼 Claude 단축키 파일도 그대로 두며 앱에 자동으로 가져오지 않습니다.

도움이 필요할 때

앱은 어떻게 실행하나요?

받은 ZIP 파일을 먼저 압축 해제한 뒤 EXE 또는 VBS 실행기를 더블클릭합니다. 앱 전용 로그인은 없으며 AI 기능은 이 PC의 기존 Claude Code 설치와 인증을 사용합니다. 별도의 Company Agent 플러그인은 필요하지 않습니다. 업데이트할 때는 새 버전을 실행하세요. 같은 버전이나 더 최신 버전이 이미 열려 있으면 그 창을 엽니다. 새 버전으로 바꿀 때는 진행 중인 업무가 끝난 뒤 전환합니다. 0.21.5부터 보내지 않은 입력과 첨부를 보관해 새 화면에 복원합니다. 0.21.4 이하에서 처음 넘어올 때만 초안을 따로 보관하고 ‘확인’를 선택하세요. 이후 종료와 새 실행은 자동으로 처리합니다. 대기열·예약은 재시작 후 내용을 확인하고 이어 실행하세요.

연결되지 않거나 실행 오류가 나오면요?

먼저 ‘설정 → 업무 연결 → 다시 확인’을 누르고 표시된 안내를 확인하세요. 앱은 설치된 Python 3.11 이상, Windows PowerShell, .NET Framework 4.6.2 이상과 WebView2 Runtime을 사용하며 이를 자동 설치하지 않습니다. 오류가 계속되면 오류 코드와 화면을 담당자에게 전달하세요. 개인 Claude 인증·모델·스킬·연결 도구나 PC 보안 설정을 임의로 초기화할 필요는 없습니다.

예약이 안 되거나 다음 요청이 멈춰 있어요.

PC가 깨어 있고 트레이 아이콘이 있는지, ‘이어 할 일’에 일시정지·응답 대기·설정 확인 안내가 있는지 확인하세요. 앱을 다시 시작했다면 폴더와 예약을 확인하고 이어 실행합니다. 현재 모델·승인 설정을 확인하라는 안내가 있으면 먼저 설정을 해결하세요. 전송 여부가 불확실한 요청은 중복 실행을 막기 위해 자동으로 다시 보내지 않습니다.

알림은 왔는데 답변을 어디에 해야 하나요?

알림의 ‘업무 열기’ 또는 앱 상단 ‘알림 → 응답 필요’에서 업무를 엽니다. 승인 창은 작업 내용을 읽고 허용 여부를 정하고, 질문은 선택지 또는 입력창으로 답하세요. 알림을 닫거나 읽음으로 표시하는 것만으로는 작업이 재개되지 않습니다.

기존 Claude 환경과 어떤 관계인가요?

이 앱은 기존 Claude Code를 편리한 화면으로 사용하는 도구입니다. 기존 인증과 회사 정책을 따르며 Windows 설정이나 개인 플러그인을 자동으로 바꾸지 않습니다. 인증 갱신처럼 원본 Claude에서만 가능한 기능은 ‘설정 → 고급 기능 → 원본 Claude Code 열기’를 이용하세요.

앱을 최신 버전으로 바꾸기

새 버전이 나오면 설정 → 앱 업데이트에서 확인할 수 있습니다. 업데이트를 확인하는 것만으로는 설치하거나 작업을 멈추지 않습니다.

  1. 업데이트 내용 보기를 눌러 바뀐 기능과 수정 사항을 읽습니다.
  2. 원할 때 다운로드하고 업데이트를 누릅니다. 앱이 파일을 내려받고 확인하는 동안 기존 업무를 계속할 수 있습니다.
  3. 진행 중인 업무나 승인·질문을 마치면 새 버전으로 전환합니다. 작성 중인 내용과 첨부는 보관해 복원합니다.
  4. 다음에도 원래 사용하던 EXE나 VBS를 실행하면 정상적으로 설치된 최신 버전이 열립니다.

이 기능이 처음 들어가는 버전은 한 번 직접 받아야 합니다. 0.21.10 이하를 쓰고 있다면 새 Release ZIP을 받아 실행한 뒤부터 앱 안의 업데이트를 사용할 수 있습니다.

인터넷 연결이 어려워도 기존 앱을 사용할 수 있습니다. 자동 확인은 설정에서 끌 수 있으며, 새 버전 확인으로 직접 확인할 수도 있습니다. Python이나 Claude Code의 개인 설정을 바꾸거나 설치하지 않습니다.
