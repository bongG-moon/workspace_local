일반 대화와 업무, 이렇게 고르세요

왼쪽 위의 일반 대화 / 업무를 선택하면 시작 버튼·검색·목록이 함께 바뀝니다. 별도 로그인 없이 기존 Claude Code 인증과 회사 연결 환경을 사용합니다.

일반 대화

질문, 번역, 글 다듬기, 첨부 자료 요약에 사용하세요. 새 대화를 누르고 바로 질문합니다. 폴더를 고를 필요가 없고 왼쪽에는 최근 대화가 보입니다.

업무

파일 작업, 결과물 제작, 스킬·플러그인 사용, 실행 예약에 사용하세요. 새 업무에서 폴더를 선택하며 기존 폴더별 업무 목록과 오른쪽 자료·결과를 이용합니다.

첫 화면의 질문 예시를 누르면 입력창에 초안이 들어갑니다. 원하는 내용으로 고친 뒤 보내세요. 예시 선택만으로 전송하지 않으며, 작성 중인 글과 첨부는 그대로 유지합니다. 최근 대화를 선택하면 이어서 이야기할 수 있습니다.

일반 대화의 모델을 바꾸고 싶어요.

처음에는 기존 Claude Code 실행 환경의 기본 모델을 사용합니다. 입력창 아래 모델을 눌러 연결이 제공하는 목록에서 고르거나, 회사에서 사용할 수 있는 모델 이름을 직접 입력하세요. 첫 선택 시 연결을 준비하며 질문을 자동으로 보내지는 않습니다.

선택은 현재 앱 실행 중 이 대화에만 적용되며 다른 대화와 개인 기본 설정은 유지됩니다. 기존 설정 사용을 누르면 이번 연결에서 처음 확인한 기본 모델로 돌아갑니다. 답변이 끝난 뒤 바꾸면 다음 질문부터 적용됩니다. 앱을 켜 둔 상태에서 재연결할 때 선택을 복원하지 못하면 전송 전에 모델을 다시 확인합니다. 앱을 완전히 종료한 뒤에는 Claude Code의 현재 설정을 다시 확인합니다. 모델을 바꿔도 일반 대화의 파일·도구 제한은 그대로입니다.

화면을 오가도 진행 중인 업무는 계속되며, 선택 버튼의 진행·응답 필요 표시로 확인할 수 있습니다. 각 화면의 마지막 선택과 입력 초안을 구분합니다. 화면 전환만으로 기존 대화의 종류가 바뀌거나 새 Claude 연결이 생기지는 않습니다.

일반 대화에서는 PC 폴더 탐색·파일 수정·프로그램 실행·MCP 도구를 사용하지 않습니다. 사용자 스킬·플러그인도 호출하지 않으며 회사의 로그인·보안 정책은 계속 적용됩니다. 필요한 제한 기능이 없는 CLI에서는 안내 후 연결을 보류합니다. 파일 작업이 필요하면 업무에서 시작하세요.

좌우 패널의 기존 색상과 중앙 뉴트럴을 조합한 A2 화면을 사용합니다. 사이드바는 작은 글자·아이콘과 한 줄 제목으로 정리하며, 폴더 아이콘과 들여쓰기로 업무를 구분합니다. 라이트·다크 모두 같은 배치입니다. 긴 업무 이름은 상단과 목록에서 한 줄로 생략되며, 마우스를 올리면 전체 이름을 확인할 수 있습니다.

맨 위 AX Workspace 로고를 누르면 현재 모드의 홈으로 돌아갑니다. 작성 중인 글과 진행 중인 작업은 유지됩니다. 빠른 실행은 Ctrl+Shift+P로 열 수 있습니다.

업무 목록 위에는 스킬과 기능과 검색창이 있고, 아래에는 설정·전체 예약·단축키·사용 도움말을 2×2로 모았습니다. 사이드바를 접으면 아이콘으로 사용할 수 있습니다. 일반 대화에서는 스킬·예약 메뉴를 숨깁니다.

폴더 아이콘은 열고 닫은 상태에 따라 바뀝니다. 폴더에는 처음 5개 업무를 보여 주고, 6개 이상이면 더 보기로 나머지를 펼칩니다. 검색 중에는 일치하는 업무가 모두 표시됩니다.

일반 대화에 파일을 주려면

일반 대화와 첨부 자료 읽기는 별도 승인 없이 진행됩니다. 앱이 선택한 파일의 사본을 준비해 전달하므로 폴더나 파일마다 Claude 승인을 누를 필요가 없습니다.

대화 폴더의 모든 권한이 열려 있는 건가요?

PC 폴더 권한을 바꾸는 기능은 아닙니다. Windows 파일 권한과 회사 정책은 그대로 유지합니다. 일반 대화는 첨부한 사본의 내용을 전달하며, 원본 파일 수정이나 프로그램 실행은 업무 모드에서 기존 승인 방식으로 진행합니다.

  1. 자료 추가로 파일을 고르거나 입력창에 끌어 놓습니다.
  2. “첨부한 자료를 세 문장으로 요약해줘”처럼 질문하고 Enter를 누릅니다.
  3. 자료별 읽은 범위와 실패 안내를 확인하세요. 첨부 표시만으로 전체 내용을 읽었다는 뜻은 아닙니다.

파일 형식별로 무엇이 빠질 수 있나요?

Office 파일의 이미지·도형·차트·서식, DOCX 머리말, PPTX 발표 노트는 텍스트 추출에 포함하지 않습니다. XLSX는 파일에 저장된 셀 값만 읽으며 매크로·수식·외부 링크를 실행하지 않습니다. 차트 모양을 묻고 싶으면 해당 부분을 이미지로 첨부하세요.

PDF는 연결된 모델·사내 서버의 문서 입력 지원이 필요합니다. 원문 전달은 모든 페이지의 읽기 완료를 뜻하지 않으므로 응답의 확인 범위를 보세요. 읽지 못하면 필요한 부분을 텍스트나 페이지 이미지로 직접 준비하세요.

EXE·ZIP 등 실행·압축 파일, HWP와 이전 Office 형식은 일반 대화에서 읽지 않습니다. 암호·DRM·손상 등으로 읽지 못하면 이유를 안내하며 보호를 우회하지 않습니다. 기존 업무의 첨부 형식은 그대로입니다.

원본을 바꾸지 않고 앱에 보관한 사본만 사용합니다. 선택한 자료 내용은 기존 Claude 연결의 모델·서버로 전달되므로 사용 가능한 자료 범위를 확인하세요.

일반 대화를 지우면 전용 폴더도 정리해요

대화의 삭제 버튼을 누르고 확인하면 해당 요청을 중지한 뒤 앱의 대화 기록·초안·첨부 사본·추출 캐시·대화 전용 폴더를 함께 정리합니다. 목록에서만 숨기는 기능이 아니므로 필요한 내용은 먼저 따로 보관하세요.

직접 선택한 원본 파일, 다른 대화·업무의 파일, 따로 저장한 결과와 개인 Claude 설정은 남깁니다. 파일이 잠겨 정리를 끝내지 못하면 보류 안내를 남기고 다음 앱 실행 때 다시 시도합니다.

업무의 ‘목록에서 삭제’와는 다릅니다. 업무는 기존처럼 목록에서만 제거하고 실제 파일과 대화는 남깁니다. 일반 대화 삭제도 Claude 자체 세션 기록이나 서버 기록까지 모두 지우는 기능은 아닙니다.

1. 업무를 시작하는 세 가지 방법

업무 화면에서 왼쪽 새 업무를 누르면 아래 세 가지 방법이 나옵니다. ‘업무’는 한 가지 일을 위한 대화이며, ‘업무 폴더’는 그 일의 자료와 결과를 저장하는 곳입니다.

1

새 업무 공간 만들기

새로운 보고서나 분석을 시작할 때

  1. 새 업무를 누릅니다.
  2. 업무 이름을 적고 새 업무 공간 만들기를 고릅니다.
  3. 저장 위치를 확인합니다. 바꾸려면 위치 변경을 누릅니다.
  4. 폴더 사용 동의에 체크하고 업무 시작을 누릅니다.

새 폴더와 빈 대화가 준비됩니다. 기본 저장 위치는 화면에 표시된 바탕화면 아래 폴더입니다.

예: ‘10월 실적 보고서’ 업무를 만들고 엑셀 자료를 추가하기
2

기존 폴더 사용하기

이미 자료를 한 폴더에 모아 뒀을 때

  1. 새 업무 → 기존 폴더 사용하기를 고릅니다.
  2. 찾아보기에서 폴더를 엽니다.
  3. 원하는 폴더 안에서 선택을 확정합니다.
  4. 폴더 사용 동의에 체크하고 업무 시작을 누릅니다.

그 폴더에서 새 대화를 시작합니다. 폴더를 고르는 것만으로 예전 대화를 가져오지는 않습니다.

예: 바탕화면 ‘회의자료’ 폴더의 문서를 요약하기
3

기존 세션 활용하기

전에 Claude와 나눈 대화를 이어갈 때

  1. 새 업무 → 기존 세션 활용하기를 누릅니다.
  2. 목록에서 이전 대화를 고릅니다. 알고 있는 대화 번호(세션 ID)로 찾아도 됩니다.
  3. 대화 내용과 원래 폴더를 확인합니다.
  4. 업무에 추가하고 이어가기를 누릅니다.
  5. 추가할 내용을 입력하고 보냅니다. 폴더 확인이 나오면 확인합니다.

이전 대화와 원래 작업 폴더가 함께 연결됩니다. 목록을 불러오기만 해서는 AI 작업이 시작되지 않습니다.

폴더 사용 동의란? Claude가 그 폴더의 자료와 기존 자동 처리 설정을 사용하도록 허용하는 단계입니다. 내가 알고 신뢰하는 폴더인지 확인하세요. 같은 대화가 다른 Claude 창에서 작업 중이라면, 그 작업을 마친 뒤 여기서 이어가세요.

여러 업무를 동시에 사용할 때

동시에 작업할 수 있는 Claude 연결은 최대 5개입니다. 작업이 끝나면 오래된 완료 연결부터 정리해 평소에는 전체 연결을 3개까지 유지해요. 진행 중이거나 승인·답변을 기다리는 업무, 이어 할 일이 있는 업무는 끊지 않습니다.

예를 들어 3개가 작업 중이고 2개가 완료되면 완료된 2개의 연결만 정리합니다. 대화·파일·예약은 그대로 남고, 다시 메시지를 보내거나 예약 시간이 되면 같은 대화와 설정으로 재연결해요. 재연결할 때는 잠시 준비 시간이 걸릴 수 있어요.

5개 연결이 모두 사용 중이면 새 업무를 시작할 때 새 업무를 연결할까요? 확인창이 나옵니다. 종료할 업무의 이름과 상태를 확인한 뒤 기존 작업 중지 후 연결을 누르세요. 업무 생성일이 아니라 현재 연결이 시작된 시간이 가장 오래된 업무가 대상입니다.

기존 업무의 요청과 연결이 종료된 다음 새 요청을 보냅니다. 기존 대화와 저장된 파일은 유지되며 이미 수행한 파일 변경은 되돌리지 않습니다. 기존 업무의 이어 할 일과 예약은 일시정지되므로, 그 업무에서 내용을 확인하고 이어 실행해 주세요.

취소하거나 종료를 확인하지 못하면 입력한 내용과 첨부파일을 유지합니다. 예약 실행과 스킬 목록 자동 조회는 다른 진행 중인 업무를 임의로 중단하지 않고 연결 자리가 비기를 기다립니다. 동시에 사용하는 Claude와 MCP가 많으면 메모리 사용량도 늘어날 수 있습니다.

2. 자료를 넣고 결과 확인하기

우측 자료 목록은 첨부 가능한 확장자와 같은 기준으로 문서·이미지·소스·EXE·압축 파일을 표시합니다. 폴더는 한 항목으로 표시하고 클릭할 때만 내부를 조회합니다. ‘← 상위 폴더’는 한 단계 위 폴더, ‘업무 폴더’는 처음 위치로 돌아갑니다. 폴더 옆 +를 누르거나 폴더를 입력창으로 끌면 폴더 경로를 자료로 추가합니다. 하위 파일을 일괄 복사하거나 읽지 않으며, 이후 처리는 업무의 도구·승인 설정을 따릅니다. 일반 대화에서는 폴더 첨부를 지원하지 않습니다.

EXE처럼 미리보기를 지원하지 않는 파일은 안내와 ‘폴더에서 보기’를 제공합니다. 선택·첨부만으로 실행하거나 압축을 풀지 않습니다. 숨김·인증 정보로 보이는 이름은 자동 목록에서 제외합니다. build·dist 같은 폴더도 목록에서 열어 확인할 수 있습니다. 목록은 한 폴더씩 개수·시간을 제한해 조회하며, 일부만 표시되면 안내합니다. 추가·삭제한 자료는 상단 새로고침으로 확인하세요.

  1. 자료 추가를 누르고 앱 안의 선택창에서 파일을 고릅니다. 폴더를 열어 이동하고, 여러 파일을 선택한 뒤 추가할 수 있습니다. 왼쪽 바로가기로 바탕화면·문서·다운로드에 빠르게 갈 수 있습니다.
  2. 또는 탐색기의 파일을 입력창에 끌어 놓으세요. 오른쪽 업무 공간·결과의 파일도 입력창으로 끌어 참조할 수 있습니다. 입력창에 첨부 표시가 생겼는지 확인하세요.
  3. 원하는 결과를 적고 Enter 또는 보내기를 누릅니다. 줄을 바꾸려면 Shift+Enter를 누르세요. 예: ‘첨부한 표에서 매출이 줄어든 부서를 찾아 이유를 설명해 줘.’
  4. 질문이나 승인 요청이 나오면 내용을 읽고 답합니다. 선택지만 눌러도 되는 질문은 항목을 클릭할 수 있습니다.
  5. 완료 후 오른쪽 이번 결과에서 파일을 확인합니다. 기본 앱에서 열기로 엑셀·PowerPoint·메모장·웹 브라우저 등 PC에 연결된 앱에서 열 수 있습니다.

경로를 알고 있다면 경로로 추가를 쓸 수 있습니다. 앱 선택창으로 찾기 어려운 위치는 선택창의 Windows 선택 기능을 이용하세요. 취소하면 기존 입력과 첨부는 그대로 남습니다.

자료와 결과가 닫혀 있으면 중앙 상단의 열기 아이콘으로 펼칩니다. 열려 있을 때는 중앙 아이콘이 숨겨지고, 우측 패널 안의 접기 아이콘으로 닫을 수 있습니다.

자료와 결과 너비 조절하기

넓은 앱 창에서는 대화와 오른쪽 자료와 결과 사이의 경계선을 좌우로 끌어 너비를 조절할 수 있습니다. 마지막으로 정한 너비는 패널을 닫았다 다시 열거나 앱을 재시작해도 유지됩니다. 가운데 대화가 너무 좁아지지 않는 범위에서 조절되며, 경계선을 두 번 클릭하면 기본 너비로 돌아갑니다.

키보드로는 Tab으로 경계선에 이동한 뒤 ←로 넓히고 →로 줄입니다. Enter는 기본 너비로 되돌립니다. 좁은 창에서는 임시 패널로 열리며 너비를 끌어 조절하지 않습니다.

지금 어떤 일을 하는지 확인하기

실행 카드와 진행 내용의 오른쪽 펼치기를 누르면 상세 내용이 나오고, 접기로 다시 줄일 수 있습니다. 제목 줄 어디를 눌러도 같은 동작을 합니다. 키보드로 이동한 뒤 Enter 또는 Space로도 열고 닫을 수 있습니다.

입력창 위 상태 줄에 최근 도구와 동작이 표시됩니다. 예를 들어 자료 읽기 · Read · 분기 실적.csv는 해당 파일을 읽는 도구를 호출한 기록입니다. 스킬을 쓰면 Skill과 스킬 이름이 함께 나옵니다. 여러 도구를 동시에 호출한 경우 함께 표시되는 개수도 확인할 수 있습니다.

대화에는 여러 도구·스킬 활동이 짧게 표시됩니다. 입력·결과 자세히 보기를 누르면 그 요청의 실제 입력과 결과를 펼쳐 볼 수 있습니다. ‘요청’은 도구를 불렀다는 뜻이고, ‘실행 중’은 Claude가 진행 정보를 보냈다는 뜻입니다. ‘결과 수신’은 해당 도구의 응답이 돌아왔다는 뜻이며 전체 업무나 백그라운드 작업의 완료와는 다릅니다. ‘결과 미확인’은 종료나 연결 중단으로 결과를 확인하지 못했다는 뜻입니다.

승인·질문이 나왔을 때는 필요한 응답이 우선 표시됩니다. 도구 기록만으로 Claude의 내부 판단 과정이나 정확한 진척률을 알 수는 없습니다. 현재 보관된 최근 활동만 표시하며, 이전 버전에서 수집하지 않은 도구 기록은 새로 만들어 표시하지 않습니다.

EXE나 압축파일도 첨부할 수 있나요?

EXE와 ZIP·7z·RAR·TAR·GZ·BZ2·XZ·ZST·CAB·ALZ·EGG 등을 지원합니다. 자료 추가, 경로 입력, @파일 또는 드래그로 첨부할 수 있습니다. 첨부만으로 파일을 실행하거나 압축을 풀지는 않습니다. 이후 처리 가능 여부는 연결된 Claude 도구와 승인 설정에 따릅니다.

한 번에 최대 12개를 추가할 수 있습니다. 드래그로 복사하는 파일은 각각 50MB까지, 앱에 저장하는 복사본은 합계 512MB까지 지원합니다. 더 큰 파일은 자료 추가나 경로로 추가를 통해 원본 경로를 선택하세요. 전송 전 형식과 용량을 확인하며, 연결이 끊겼다는 안내가 나오면 자료 목록을 먼저 확인한 뒤 다시 시도하세요.

첨부한 원본 파일은 이동되나요?

파일을 고르는 기능은 원본을 옮기지 않습니다. 탐색기에서 끌어 넣어 업로드한 파일은 앱 관리 공간에 복사됩니다. 이미 업무 공간에 있는 파일은 그 경로를 참조합니다. 첨부한 뒤 요청에서 원본 수정을 지시하면 실제 파일이 바뀔 수 있습니다.

작업이 끝나면 오른쪽 자료·결과 목록이 자동으로 갱신됩니다. 탐색기에서 파일을 삭제했다면 자료와 결과 상단의 새로고침을 누르세요. 두 탭을 함께 갱신해 삭제된 파일을 목록에서 숨깁니다. 파일을 확인할 수 없는 경우에는 안내를 표시하고 기존 결과를 유지합니다. 대화와 파일 변경 이력은 그대로 남습니다.

이미지·표·코드는 어디서 보나요?

대화에 제공된 이미지·표·코드는 대화 영역에서 확인할 수 있고, 생성된 파일은 ‘이번 결과’에서 열 수 있습니다. 코드가 표시됐다는 이유만으로 실행되는 것은 아닙니다. HTML의 앱 미리보기는 정적 화면입니다. 폭이 고정된 보고서·슬라이드는 창 너비에 맞춰 자동 축소하며, 창 크기를 바꾸면 다시 맞춥니다. 긴 자료는 아래로 스크롤해 읽고, 코드 탭은 팝업의 남는 높이를 사용합니다. 기본 브라우저에서 열면 해당 파일의 스크립트와 외부 연결이 동작할 수 있습니다.

3. 이어서 분석하거나 다른 방향 시도하기

답변 중지와 연결 종료 구분하기

  • 답변 중지: 지금 처리하는 요청만 멈춥니다. Claude가 중지를 확인하면 연결과 대화는 유지됩니다. 답변 작성뿐 아니라 그 요청의 도구 작업도 중지 대상입니다.
  • 설정 → 업무 연결 종료: 현재 업무에 연결된 Claude Code를 종료합니다. 앱과 대화 기록은 남고, 다음 요청 때 다시 연결합니다.
  • 설정 → 완전히 종료 또는 트레이 → 완전 종료: 앱과 앱에서 실행한 업무 연결을 모두 닫습니다. 창의 X로 숨기는 것과 다릅니다.

중지 완료 안내가 나온 뒤 같은 입력창에 새 부탁을 보내세요. 중지 확인 중에는 입력을 보관하고 보내기를 잠시 멈춥니다. 이미 만든 파일·수정한 내용은 되돌리지 않고, 앞의 요청도 자동으로 다시 보내지 않습니다.

중지 확인이 되지 않거나 연결 오류가 생기면 연결을 닫고 재연결이 필요할 수 있습니다. 화면의 안내를 먼저 확인하세요. 직접 중지했다는 이유만으로 실패로 표시하지는 않으며, 실제 오류는 별도로 알려드립니다.

같은 대화에서 이어서 하기

완료된 업무를 선택하고 입력창에 다음 부탁을 적으면 됩니다. 새 업무를 만들 필요가 없습니다.

‘방금 만든 표를 부서별로 나눠 줘.’
‘같은 내용으로 발표용 요약도 만들어 줘.’

작업 중이라면 다음 두 버튼으로 처리 순서를 고릅니다.

  • 보내기: 현재 요청이 정상 완료되면 다음 요청을 순서대로 자동 실행합니다.
  • 지금 반영: 현재 요청을 중지하고 새 요청으로 이어갑니다. 이미 수정한 파일은 되돌리지 않습니다.

이어 할 일을 누르면 대기 중인 부탁을 수정·취소하거나 순서를 바꿀 수 있습니다. 승인·질문 대기 중에는 먼저 응답해야 다음 일이 진행됩니다. 오류·직접 중지·연결 종료가 발생하면 남은 부탁은 대기에 보관합니다. 상태를 확인한 뒤 이어 실행을 눌러 주세요. 이미 일시 정지된 부탁·예약은 새 부탁을 추가해도 자동 재개하지 않습니다.

대화 분기로 다른 안 만들기

원래 대화를 남겨 두고 다른 방향을 비교할 때 씁니다.

  1. 현재 작업과 승인·질문을 마칩니다.
  2. 업무 제목 옆 대화 분기를 누릅니다.
  3. 안내를 확인하고 새 업무를 만듭니다.
  4. 새 업무에 다른 방향의 요청을 보냅니다. 첫 요청 때 별도 Claude 대화가 만들어집니다.
원래 대화는 ‘자세한 보고서’, 분기한 대화는 ‘임원용 한 장 요약’으로 이어가기

두 대화는 같은 폴더를 사용합니다. 다른 안을 보관하려면 ‘새 파일 이름으로 저장해 줘’라고 요청하세요. 대기 요청·예약·첨부 초안은 복제하지 않습니다. 현재는 마지막 완료 기록을 기준으로 분기합니다.

4. 정해진 시간에 실행 예약하기

왼쪽 아래 ‘전체 예약’을 누르면 모든 업무의 예약을 한눈에 볼 수 있어요. 업무 이름·요청 요약·다음 실행·반복 주기와 멈춘 이유를 확인합니다. 검색하거나 상태별로 좁히고, 예약 관리를 누르면 해당 업무의 수정·일시정지 화면으로 이동합니다. 목록을 열거나 선택하는 것만으로 예약을 실행하지 않습니다.

  1. 예약할 업무를 먼저 선택합니다.
  2. 입력창 위 실행 예약을 누릅니다. 미리 적은 요청과 첨부가 있다면 가져옵니다.
  3. 실행할 요청에 할 일을 적습니다.
  4. 한 번·평일·매일·매주·매월·간격 반복 중 하나를 고르고 날짜·시간이나 요일을 정합니다.
  5. 저장을 누른 뒤 이어 할 일에서 다음 실행 시각을 확인합니다.
예약 방식시간 설정 방법
한 번앞으로 실행할 날짜와 시간을 고릅니다.
평일월요일~금요일에 실행할 시간을 고릅니다.
매일매일 같은 시간에 예약합니다.
매주실행할 요일을 하나 이상 고르고 시간을 정합니다.
매월1~31일 중 날짜와 시간을 정합니다. 해당 날짜가 없는 달은 건너뜁니다.
간격 반복시간·분으로 간격을 입력하고 매일의 시작·종료 시간을 정합니다. 시작을 기준으로 종료 시간 전까지 예약합니다.

예를 들어 간격을 8시간 0분, 시작을 07:00, 종료를 23:59로 정하면 07:00 → 15:00 → 23:00에 예약되고 다음 날 07:00부터 반복됩니다. 간격은 합계 1분~24시간이며, 자정을 넘는 구간은 지원하지 않습니다. 입력 아래 요약에서 선택한 방식과 하루 예약 시각을 확인하세요. 예약 시각은 요청을 등록하는 기준이며, 진행 중인 업무나 응답 대기가 있으면 기존 대기 규칙을 따릅니다.

예: 매주 월요일 오전 9시, ‘이 폴더의 지난주 자료를 읽고 주간 요약을 새 파일로 만들어 줘.’

예약을 고치거나 멈추려면 이어 할 일에서 해당 예약의 수정·일시정지·삭제를 누릅니다. 다시 시작하려면 예약 재개를 누릅니다.

예약이 실행되려면
  • PC가 깨어 있고 앱이 실행 중이어야 합니다. 창을 닫아 트레이 아이콘만 남긴 상태에서도 실행됩니다.
  • PC가 꺼져 있거나 절전 중이면 깨워서 실행하지 않습니다. 놓친 예약을 나중에 한꺼번에 실행하지도 않습니다.
  • 시간은 이 PC의 현재 시간대를 따릅니다. 이전 작업이나 응답 대기가 있으면 먼저 해결해야 합니다.
  • 앱을 완전히 종료했다가 다시 켰다면 폴더와 대기·예약 내용을 확인하고 이어 실행해 주세요.
  • 예약도 현재 Claude 인증과 승인 방식이 필요합니다. 승인·질문이 생기면 자동으로 대신 답하지 않고 사용자의 응답을 기다립니다.

5. 창을 닫아도 계속 일하나요?

작업 중에 완전 종료를 누르면 숨겨진 앱 창이 열리고 “작업 중인 내용이 있습니다. 그래도 종료하시겠습니까?”를 묻습니다. 취소하면 작업은 그대로 계속됩니다. 종료를 누르면 이 앱의 모든 진행 중인 작업과 승인·답변 대기를 중지한 뒤 창과 트레이 아이콘을 종료합니다. 이미 저장된 대화와 파일은 유지되지만, 진행 중이던 변경은 완료되지 않았을 수 있습니다. 앱이 꺼져 있는 동안 예약은 실행되지 않습니다.

완전 종료 중에는 잠시 기다려 주세요. ‘앱을 열어 확인해 주세요’가 보이면 종료가 끝났다는 뜻이 아니라, 연결 정리 결과를 확인하지 못했다는 뜻입니다. 앱을 열어 표시된 이유와 종료 다시 시도를 확인하세요. PC 설정이나 Claude 로그인을 바꿀 필요는 없습니다.

  2. 작업 완료, 승인·질문·선택 대기, 오류·확인 필요 중 필요한 항목을 켭니다.
  3. 다른 앱에서 일하거나 Workspace 창을 닫아 두어도 PC 알림으로 알려줍니다. 알림의 업무 열기를 누르면 해당 대화로 돌아갑니다.

알림은 다른 앱의 화면을 강제로 빼앗지 않습니다. 현재 보고 있는 업무는 화면 안의 상태를 확인하세요. 여러 알림이 겹치면 순서대로 표시될 수 있습니다.

Windows가 알림 표시를 제한하는 상태에서는 PC 배너가 나오지 않을 수 있습니다. 이때도 질문과 완료 기록은 앱에 남습니다.

알림을 놓쳤다면 상단 ‘알림’을 누르세요. ‘응답 필요’에서 아직 답해야 할 업무를 찾을 수 있습니다. 알림을 읽음으로 바꾸는 것은 승인이나 답변이 아닙니다. PC 알림을 꺼도 앱 알림함의 기록은 확인할 수 있습니다. 브라우저로 접속한 경우에는 별도의 브라우저 알림 허용이 필요할 수 있습니다.

6. 업무 목록을 깔끔하게 정리하기

  • 이름 변경: 왼쪽 업무 이름에 마우스를 올리고 연필 버튼을 누르세요. 새 이름을 입력하고 Enter 또는 이름 저장을 누릅니다. 키보드의 Tab으로 선택해도 이름 변경·고정·삭제 버튼을 사용할 수 있으며, 터치 화면에서는 버튼이 계속 보입니다. 한글을 조합하는 중의 Enter는 글자 입력만 마칩니다.
  • 핀 고정: 자주 쓰는 업무를 같은 폴더 안에서 위에 고정합니다. 상단이나 목록의 핀을 누르면 고정·해제할 수 있으며, 고정한 핀은 색이 채워져 표시됩니다. 손잡이를 끌어 같은 폴더·고정 그룹 안에서 순서를 바꿀 수 있습니다.
  • 목록에서 삭제: 업무의 삭제 버튼을 누른 뒤 확인창에서 내용을 읽고 확인합니다. 취소하면 그대로 남습니다.

삭제되는 것은 앱 목록의 표시뿐입니다. 실제 Claude 대화 기록과 업무 폴더·결과 파일은 지우지 않습니다. 원래 Claude 대화가 저장되어 있다면 새 업무 → 기존 세션 활용하기로 다시 추가할 수 있습니다.

진행 중이거나 응답을 기다리는 업무, 대기 요청·실행할 예약이 남은 업무는 바로 제거할 수 없습니다. 필요한 답변을 마치고 대기·예약을 정리한 뒤 다시 시도하세요. 앱이 임의로 작업을 중지하거나 예약을 없애지 않습니다.

비슷한 업무를 폴더에 모으기

  1. 왼쪽 업무 목록 → 새 폴더를 누르고 이름을 입력합니다. 예: 주간 보고, 분석, 개인 업무.
  2. 업무 이름을 누른 채 끌어 폴더 제목이나 펼쳐진 폴더 안의 업무·빈 공간에 놓아도 옮길 수 있습니다. 이름을 짧게 클릭하면 업무가 열리고, 일정 거리 이상 끌었을 때만 이동합니다. 기존 왼쪽 손잡이도 계속 사용할 수 있습니다. 같은 폴더 안에서는 기존처럼 순서를 바꿉니다. 폴더에서 꺼내려면 폴더에 속하지 않은 업무 또는 목록 맨 아래 빈 공간에 끌어 놓으세요.
  3. 폴더 제목을 누르면 접거나 펼칩니다. 폴더 이름이나 업무 이름으로 검색하면 접힌 폴더 안의 일치하는 업무도 표시됩니다.
  4. 폴더 제목 옆 ···에서 이름을 바꾸거나 폴더를 삭제합니다. 확인창에서 폴더만 삭제를 누르면 폴더가 없어지고 안의 업무는 일반 목록에 그대로 남습니다. 대화나 파일을 삭제하지 않습니다.

이 폴더는 앱의 업무 목록을 정리하는 공간입니다. 실제 작업 디렉터리, 대화 기록, 파일, Claude 설정은 이동하거나 바꾸지 않습니다. 폴더는 한 단계로 만들며, 폴더 아이콘과 들여쓰기로 소속을 구분합니다. 폴더에 넣지 않은 업무는 별도 구분 제목 없이 표시됩니다. 접힘 상태와 분류는 앱을 다시 열어도 유지됩니다.

파일이 어떻게 바뀌었는지 확인하기

이번 결과의 파일 카드에는 파일 종류·이름·변경 상태·확인 시각이 표시됩니다. 카드의 미리보기·기본 앱에서 열기·폴더에서 보기·이 결과로 요청으로 확인하거나 이어서 요청할 수 있습니다. 이번 결과 → 파일 변경 비교에서 요청과 파일을 고르면 앱이 저장한 이전·이후 내용을 볼 수 있습니다. 지원하는 텍스트 파일의 일부 범위만 보관하며, 이미지·Office 문서는 파일 정보로 표시될 수 있습니다. 원본을 자동으로 되돌리는 기능은 아닙니다.

스킬과 기능 목록 보기

스킬과 기능에서 공통 또는 폴더를 골라 설치된 스킬과 현재 연결을 봅니다. 다음 세 가지를 구분하면 쉬워요.

  • 실행 기능 (기존 도구): AI가 수행하는 개별 동작입니다. 파일 읽기, 창 목록 확인, 클릭 등이 해당합니다.
  • 연결된 기능(MCP) (기존 연결 서버): 실행 기능을 제공하는 연결 묶음입니다. 예를 들어 화면 작업 MCP 하나가 창 읽기·클릭 같은 여러 실행 기능을 제공합니다. 인터넷 서버뿐 아니라 내 PC에서 실행되는 프로그램일 수도 있습니다.
  • 빠른 요청(/명령) (기존 명령): 입력창에 /이름으로 부르는 바로가기입니다. 예: /help. 원본 Claude Code에서만 사용할 수 있는 항목도 있습니다.

스킬은 이 기능들을 어떤 순서로 사용할지 정리한 업무 방법입니다. PowerShell처럼 터미널에 넣는 코드는 별도로 실행 명령이라고 부릅니다.

실행 기능·연결·빠른 요청 목록은 선택한 업무의 실제 Claude 연결이 제공한 정보입니다. ‘연결 필요’는 연결을 확인해야 한다는 뜻이고, ‘CLI 미제공’은 항목이 0개라는 뜻이 아닙니다. 목록을 보는 것만으로 작업을 실행하지 않습니다.

7. 익숙해지면 더 빠르게

최신 대화는 자동으로 따라갑니다. 답변·도구 진행·이미지가 추가되어도 맨 아래를 보여 줍니다. 이전 내용을 읽으려고 위로 올리면 읽던 위치를 유지하고, 새 메시지를 보내거나 맨 아래로를 누르면 다시 따라갑니다. 창 크기를 바꾸거나 최소화했다 돌아와도 이 선택을 유지합니다.

내가 보낸 말풍선과 본문은 오른쪽으로 정렬됩니다. 짧은 입력은 내용만큼 작게 표시하고, 긴 입력은 화면 안에서 줄바꿈합니다. 코드·표·목록은 읽기 쉬운 정렬을 유지합니다.

Enter로 보내고, Shift+Enter로 줄을 바꾸세요. 작업 중에 Enter로 보내면 현재 요청을 마친 뒤 이어서 처리하도록 대기합니다. 보내기 버튼도 그대로 사용할 수 있습니다.

입력창 아래 모델·Effort·승인을 눌러 현재 업무의 설정을 바꿀 수 있습니다. 설정만 바꿔서는 AI 작업을 시작하지 않습니다. 연결에서 제공한 항목만 선택할 수 있으며, 개인 Claude 설정 파일을 자동으로 덮어쓰지 않습니다.

Effort와 승인 모드는 무슨 뜻인가요?

Effort는 답변을 만들 때 생각하는 수준입니다. 모델에 따라 지원하는 값이 다릅니다. 승인 모드는 파일 변경이나 명령 실행 전에 어떻게 확인받을지 정합니다. 기존 설정을 사용해도 괜찮습니다.

⚠ Bypass는 파일 수정과 명령 실행 등의 승인 확인을 생략할 수 있습니다. 별도 위험 확인을 거쳐 해당 업무에서만 선택하며, Shift+Tab이나 Alt+M으로 우연히 켜지지 않습니다.

작업 중에도 승인 목록이나 Shift+Tab / Alt+M으로 지원되는 모드를 바꿀 수 있습니다. Claude가 변경을 확인한 뒤 이후 도구 호출부터 적용합니다. 이미 나온 승인·질문은 자동으로 허용되거나 닫히지 않으므로 직접 답하세요. 연결된 CLI가 실시간 변경을 지원하지 않거나 거절하면 현재 모드를 유지하고 이유를 안내합니다.

스킬·파일 자동완성 사용하기

/ 뒤에 스킬·빠른 요청의 앞부분을 적거나 @ 뒤에 파일 이름을 적으면 후보를 보여줍니다. ↑·↓ 또는 Ctrl+P·Ctrl+N으로 이동하고 Tab이나 Enter로 고르세요. 후보를 고른 뒤 Enter를 한 번 더 눌러 보내면 됩니다. Esc를 누르면 후보만 닫고 적은 내용은 그대로 둡니다.

Claude 연결이 보고한 목록과 현재 업무 폴더·공통 위치에서 찾은 스킬을 함께 보여줍니다. 새로 설치한 스킬은 폴더 스킬 또는 공통 스킬로 표시하며, 실제 호출 가능 여부는 전송 시 Claude가 확인합니다. 스킬을 추가한 직후라면 약 5초 뒤 검색어를 다시 입력하세요. 목록 확인은 짧게 보관한 설치 정보를 사용하며 매번 Claude를 다시 실행하지 않습니다.

한글을 조합하는 중에는 Enter가 글자 입력을 확정합니다. 이때 요청을 보내거나 후보를 선택하지 않습니다. 자동완성이나 모델 목록을 여는 것만으로 AI 작업을 시작하지 않습니다.

추가한 스킬이 / 자동완성에 없어요.
  1. 현재 선택한 업무의 폴더를 확인하세요. 폴더 전용 스킬은 그 폴더의 .claude/skills/스킬이름/SKILL.md에 있어야 합니다. 공통 스킬은 현재 Claude 설정 폴더의 skills/스킬이름/SKILL.md에 둡니다. 보통 %USERPROFILE%\.claude가 설정 폴더이며 다른 설정 폴더를 지정했다면 그 위치를 사용합니다.
  2. .instructions.md나 .assetspec.json만 작업 폴더에 만든 것은 Claude 스킬 등록과 다릅니다. 생성 도구를 사용했다면 최종 SKILL.md가 어디에 설치됐는지 확인하세요. 기존 .claude/commands/이름.md 형식도 지원합니다.
  3. user-invocable: false처럼 직접 호출을 숨긴 스킬은 추천하지 않습니다. 꺼진 스킬이나 비활성 플러그인도 설치 설정을 확인하세요. 플러그인 스킬은 /플러그인이름:스킬이름으로 표시될 수 있습니다. Claude가 보고한 /apps/web:스킬이름 같은 하위 폴더 명령도 그대로 사용할 수 있습니다.
  4. 설치 직후 약 5초 뒤 /와 이름 일부를 다시 입력합니다. 후보는 보이지만 Claude가 호출을 인식하지 못하면 진행 중인 요청을 마친 뒤 상단의 Claude Code 재시작으로 목록을 다시 확인하세요.

앱은 스킬 파일을 자동으로 옮기거나 개인·회사 설정을 바꾸지 않습니다. 다른 업무 폴더에 설치된 스킬은 해당 업무를 선택해서 확인하세요.

기존 개인 스킬을 복사하지 않고 사용·수정하기

다른 도구가 관리하는 개인 스킬이 있다면 원본을 유지하고, 업무 폴더의 .claude/skills 또는 그 안의 개별 스킬 폴더를 원본에 연결해 사용할 수 있습니다. Windows에서는 이런 폴더 연결을 정션이라고 합니다. 앱도 표준 스킬 위치의 연결 폴더를 읽으므로, 앱용 스킬 사본을 따로 관리할 필요가 없습니다.

그 업무 전용 스킬 폴더 전체가 연결되어 있으면 원본 도구에서 새 스킬을 만들거나 수정해도 같은 파일을 읽습니다. 업무 폴더의 연결된 위치에서 수정한 내용도 원본에 반영됩니다. 개별 스킬만 연결한 경우에는 그 스킬만 공유합니다. 새 스킬은 연결된 스킬이름/SKILL.md에 만들고, 약 5초 뒤 /스킬이름을 입력해 확인하세요.

이미 다른 스킬이 들어 있는 폴더를 덮어쓰지 마세요. 연결된 위치에서 파일을 삭제하면 원본 파일도 삭제되므로, 연결만 해제할 때는 파일을 지우지 않고 폴더 연결 자체를 해제해야 합니다. 앱에서 목록을 확인하는 것만으로 원본을 수정하거나 스킬을 실행하지는 않습니다.

버튼이나 링크의 강조 테두리는 무엇인가요?

버튼·링크의 강조 테두리는 Tab 등으로 키보드 이동할 때 현재 위치를 알려줍니다. 앱 실행·창 재표시·마우스 사용 중 자동으로 받은 포커스에는 테두리를 표시하지 않습니다. 입력칸의 커서와 선택된 업무·드래그 강조는 별도입니다.

화면과 팝업의 전환 효과를 줄이고 싶어요

팝업을 열거나 업무·대화 화면, 자료·결과 탭을 바꿀 때 투명한 상태에서 0.3초 동안 나타납니다. 일반 팝업은 닫힐 때도 부드럽게 사라집니다. 파일 미리보기는 내용을 즉시 해제하며 닫힙니다. 입력·전송·팝업 닫기는 효과가 끝날 때까지 기다리지 않으며, 답변이 출력되는 중에는 효과를 반복하지 않습니다. Windows의 접근성 설정에서 애니메이션 효과를 끄면 전환 효과도 자동으로 꺼집니다. 별도 설정이나 재시작은 필요하지 않습니다.

간편 화면은 무엇인가요?

간편 화면은 업무 목록과 채팅에 집중하도록 부가 도구를 숨기는 보기입니다. 상단의 밝기(다크모드) 버튼 바로 옆 아이콘으로 전환합니다. 켜져 있으면 아이콘 배경이 보라색이며, ON/OFF 글자는 표시하지 않습니다. 아이콘에 마우스를 올리면 전환 설명을 볼 수 있습니다. 우측 자료 패널과 모델·스킬·예약 등 부가 메뉴를 숨기며, 밝기 버튼은 간편 화면에서도 사용할 수 있습니다. 다시 누르면 기존 화면과 패널 배치로 돌아가며, 선택은 다음 실행에도 유지됩니다.

업무·대화 종류, 작성 중인 글과 첨부, 모델·승인 설정, 진행 중인 작업과 예약은 유지합니다. 승인 요청·답변 중지·알림도 계속 표시하며, 파일 끌어 놓기·붙여넣기와 /스킬이름·@파일 입력을 사용할 수 있습니다. 숨긴 모델 선택 등을 단축키나 /model로 직접 열면 기존 화면으로 돌아가 해당 도구를 보여줍니다.

명령으로 설정 열기 · 스킬과 플러그인 관리

업무를 선택한 뒤 채팅 입력창에 아래 명령을 입력하고 Enter를 누르세요. 설정 명령은 AI 질문이나 이어 할 일로 등록되지 않습니다.

  • /model: 모델 선택창을 엽니다. /model 모델명으로 직접 변경할 수도 있습니다. 현재 요청이 끝난 뒤 바꿀 수 있습니다.
  • /effort: 사고 수준을 고릅니다. /effort high처럼 입력할 수 있습니다.
  • /permissions: 승인 모드를 고릅니다. 실행 중 변경은 해당 CLI 연결이 지원할 때 가능합니다.
  • /skills: 스킬 사용 상태를 관리합니다. 사용, 이름만 제공, 직접 호출만, 사용 안 함을 선택할 수 있습니다. 별도 지정 해제 옵션은 저장 범위에 따라 ‘공통·기존 설정 따르기’(이 프로젝트에서만), ‘스킬 기본 설정 따르기’(사용자 공통)로 표시됩니다. 선택한 범위의 별도 지정만 지우며, 프로젝트별 설정과 회사 정책은 계속 우선할 수 있습니다. ‘사용 안 함’은 끄는 값을 저장하며 파일을 삭제하지 않습니다. 관리창의 ‘사용 상태·저장 범위 도움말’에서 각 옵션과 예시를 확인할 수 있습니다.
  • /plugin: 설치된 플러그인을 켜거나 끕니다. 삭제나 새 설치는 하지 않습니다. 플러그인에서 제공한 스킬은 플러그인 단위로 관리합니다.

스킬과 기능 → 스킬·플러그인 관리에서도 같은 화면을 열 수 있습니다. 기본 저장 범위인 ‘이 프로젝트에서만’은 같은 폴더를 사용하는 업무와 터미널에 적용됩니다. ‘사용자 공통’은 다른 프로젝트에도 영향을 줍니다. 프로젝트에 별도 설정이 있으면 사용자 공통 값보다 먼저 적용됩니다. 이 경우 공통 설정의 변경을 잠그고 이유를 표시하므로, 해당 프로젝트 설정을 먼저 확인하세요.

스킬 원본은 복사·수정하지 않습니다. Claude 표준 설정 파일에 저장하며, 관리 화면의 ‘설정 저장 위치’에서 대상 경로를 확인할 수 있습니다. 스킬 상태 변경은 앱에서 확인한 CLI 2.1.260 이상을 대상으로 제공합니다. 회사 관리 설정이나 변경할 수 없는 원본 조건이 있으면 선택이 잠깁니다.

사용 상태를 저장하면 변경한 설정을 바로 적용할까요?라는 확인창이 나옵니다. 지금 적용을 선택하면 관리창에 표시된 업무의 Claude Code를 재연결합니다. 대화, 파일과 작성 중인 입력은 유지됩니다. 작업 중에는 중단할 내용을 읽고 중지하고 적용을 선택하세요. 중단된 요청은 자동으로 다시 보내지 않으며, 이어 할 일과 실행 예약이 있으면 일시 정지되므로 재연결 후 직접 재개합니다.

나중에는 설정만 저장하고 현재 연결은 유지합니다. 관리창의 저장한 설정 적용으로 다시 시도하거나, 작업이 끝난 뒤 해당 업무 상단의 Claude Code 재시작을 누르세요. 관리창의 ‘저장된 스킬 설정’과 ‘저장된 업무 설정’은 파일에 저장한 값이며, 실행 중인 연결에 이미 적용됐다는 뜻은 아닙니다. 재연결에 실패해도 저장한 값은 유지되며 관리창에서 다시 시도할 수 있습니다. 같은 폴더의 다른 업무나 사용자 공통 설정을 사용하는 다른 업무·원본 터미널은 각각 다시 불러오거나 재시작해야 합니다. 프로젝트 로컬 설정을 직접 생성한 경우 Git에 공유되지 않도록 .claude/settings.local.json의 제외 여부도 확인하세요.

스킬의 사용 안 함은 스킬 호출과 목록 제공을 끄는 설정입니다. 스킬 원본 파일을 삭제하거나 일반 파일 읽기 권한을 차단하지 않습니다.

플러그인을 껐는데 이전 기능을 계속 찾으면요?

먼저 변경한 설정을 적용해 Claude Code를 재연결하세요. 재연결은 기존 대화를 유지하므로 예전에 전달된 플러그인 지침까지 지우지는 않습니다. 이전 기능을 계속 찾으면 같은 폴더에서 새 업무로 시작해 확인해 보세요. 독립적으로 설치된 후크·스킬이나 프로젝트 지침은 플러그인과 별개로 남아 있을 수 있습니다. 새 업무에서도 같은 오류가 생기면 플러그인 또는 하네스 담당자에게 오류와 선택한 저장 범위를 전달하세요. 앱이 꺼진 플러그인을 다시 켜거나 개인 파일을 자동으로 지우지는 않습니다.

버튼을 누르지 않아도 연결 목록 확인하기

‘스킬과 기능’을 열거나 업무 폴더·조회 범위·연결 기준 업무를 변경하면 선택한 업무의 연결을 자동으로 확인합니다. 기본 스킬 탭에서도 실행 기능·MCP·빠른 요청 목록까지 함께 준비하므로 ‘다시 확인’을 따로 누르지 않아도 됩니다. 빠르게 선택을 바꾸면 마지막 선택만 조회하고, 연결 실패 시 자동 재시도를 반복하지 않습니다. 다른 폴더를 선택했다가 돌아오거나 ‘다시 확인’을 눌러 재시도할 수 있습니다. 기존 연결을 재사용하며, 다른 모든 업무를 한꺼번에 연결하지 않습니다.

선택한 업무 폴더의 설정·후크·MCP를 사용해 목록을 확인하며, 처음 연결하는 폴더도 별도 확인창 없이 연결합니다. 스킬 탭은 설치 정보만 읽고 Claude를 실행하지 않습니다. 연결 실패 시에는 다시 확인으로 재시도하세요. CLI가 목록을 제공하지 않은 경우 0개로 간주하지 않으며, 첫 실제 요청 이후에 실행 기능 목록이 나타날 수 있습니다. 목록 조회를 위해 AI 질문을 보내거나 도구 실행 승인을 자동으로 허용하지 않습니다.

빠르게 선택을 바꾸면 마지막 선택을 기준으로 확인하고, 연결 중인 요청은 중복 실행하지 않습니다. 목록 확인에만 쓰인 오래된 연결도 기존 유휴 연결 정리 대상에 포함합니다. 진행 중·승인 또는 답변 대기·이어 할 일이 있는 연결은 유지하며, 화면을 닫은 뒤 반복 조회하지 않습니다.

도움이 필요할 때

앱은 어떻게 설치하고 실행하나요?

사내 AX-Workspace-Install.exe를 받았다면 사내망에 연결한 상태에서 실행하세요. 최신 버전과 변경 내용을 확인하고 최신 버전 설치를 누르면 해당 설치 파일을 받아 검증한 뒤 설치 화면을 엽니다. 담당자가 같은 서버·프로젝트에 새 버전을 게시하면 같은 EXE로 최신 버전을 바로 설치할 수 있습니다. 사내망에 연결되지 않으면 연결 후 다시 시도하세요.

Setup 설치 파일을 받았다면 AX-Workspace-0.23.27-Setup.exe를 열어 설치하고 시작 메뉴의 AX Workspace를 누르세요. 바탕화면 바로가기는 설치할 때 선택할 수 있습니다. ZIP 파일을 받았다면 먼저 압축 해제한 뒤 EXE 또는 VBS 실행기를 더블클릭합니다. 앱 전용 로그인은 없으며 AI 기능은 이 PC의 기존 Claude Code 설치와 인증을 사용합니다. 별도의 Company Agent 플러그인은 필요하지 않습니다. 업데이트할 때는 새 버전을 실행하세요. 같은 버전이나 더 최신 버전이 이미 열려 있으면 그 창을 엽니다. 새 버전으로 바꿀 때는 진행 중인 업무가 끝난 뒤 전환합니다. 0.21.5부터 보내지 않은 입력과 첨부를 보관해 새 화면에 복원합니다. 0.21.4 이하에서 처음 넘어올 때만 초안을 따로 보관하고 ‘확인’를 선택하세요. 이후 종료와 새 실행은 자동으로 처리합니다. 대기열·예약은 재시작 후 내용을 확인하고 이어 실행하세요.

설치 파일을 다시 실행하거나 앱을 제거하려면요?

먼저 트레이의 AX Workspace 아이콘을 우클릭해 완전 종료하세요. 창의 X는 숨기기만 하므로 설치·제거 전에 앱이 끝났는지 확인합니다. 사내 최신 설치용 AX-Workspace-Install.exe는 같은 파일을 다시 실행하면 최신 버전을 확인합니다. 버전별 Setup을 받은 경우에는 원하는 버전의 Setup 파일을 실행하세요.

제거하려면 Windows 설정 → 앱에서 AX Workspace → 제거를 선택합니다. 설치된 프로그램과 바로가기를 지우며, 기존 업무·대화·예약·설정, Claude 설정과 실제 업무 파일은 유지합니다. 다시 설치하면 같은 Windows 사용자의 기존 내용을 사용할 수 있습니다.

현재 사용자 계정에 설치하며, 설치만으로 PC 시작 시 자동 실행되거나 새 서비스가 생기지는 않습니다. Python 3.11 이상, 최신 Claude Code 설치·인증과 기존 Windows 실행 환경은 미리 준비해 주세요.

MCP를 설치한 뒤 Claude Code를 다시 시작하라고 나오면요?
  1. 다시 연결할 업무를 선택합니다.
  2. 상단 연결 상태 옆의 Claude Code 재시작 버튼을 누릅니다. 설정 → 업무 연결 → Claude Code 재시작에서도 같은 기능을 사용할 수 있습니다.
  3. 작업 중이거나 승인·답변을 기다리고 있다면 안내를 읽고 중지하고 재시작을 누릅니다. 이미 만들어지거나 수정된 파일은 그대로 남습니다.
  4. 재시작 완료 후 같은 대화에서 이어서 요청합니다. 스킬과 기능 화면에서 새 연결이 제공한 목록을 확인할 수 있습니다.

현재 업무의 Claude Code 연결을 닫고 같은 세션·폴더로 다시 엽니다. 앱 전체나 별도로 연 터미널은 종료하지 않으며, 보내지 않은 글과 첨부는 유지합니다. 이전 요청을 자동으로 다시 보내지 않습니다. 대기 요청·예약이 일시정지되었다면 내용을 확인한 뒤 이어 실행하세요.

다시 확인은 설치·실행 경로를 점검하고, Claude Code 재시작은 실제 연결 프로세스를 다시 여는 기능입니다. 재시작 성공만으로 모든 MCP의 인증과 동작까지 검증되는 것은 아닙니다. MCP가 별도 인증이나 설정을 요구하면 해당 안내를 따르세요.

연결되지 않거나 실행 오류가 나오면요?

먼저 ‘설정 → 업무 연결 → 다시 확인’을 누르고 표시된 안내를 확인하세요. 앱은 설치된 Python 3.11 이상, Windows PowerShell, .NET Framework 4.6.2 이상과 WebView2 Runtime을 사용하며 이를 자동 설치하지 않습니다. 오류가 계속되면 오류 코드와 화면을 담당자에게 전달하세요. 개인 Claude 인증·모델·스킬·연결 도구나 PC 보안 설정을 임의로 초기화할 필요는 없습니다.

예약이 안 되거나 다음 요청이 멈춰 있어요.

PC가 깨어 있고 트레이 아이콘이 있는지, ‘이어 할 일’에 일시정지·응답 대기·설정 확인 안내가 있는지 확인하세요. 앱을 다시 시작했다면 폴더와 예약을 확인하고 이어 실행합니다. 현재 모델·승인 설정을 확인하라는 안내가 있으면 먼저 설정을 해결하세요. 전송 여부가 불확실한 요청은 중복 실행을 막기 위해 자동으로 다시 보내지 않습니다.

알림은 왔는데 답변을 어디에 해야 하나요?

알림의 ‘업무 열기’ 또는 앱 상단 ‘알림 → 응답 필요’에서 업무를 엽니다. 승인 창은 작업 내용을 읽고 허용 여부를 정하고, 질문은 선택지 또는 입력창으로 답하세요. 알림을 닫거나 읽음으로 표시하는 것만으로는 작업이 재개되지 않습니다.

기존 Claude 환경과 어떤 관계인가요?

이 앱은 기존 Claude Code를 편리한 화면으로 사용하는 도구입니다. 기존 인증과 회사 정책을 따르며 Windows 설정이나 개인 플러그인을 자동으로 바꾸지 않습니다. 인증 갱신처럼 원본 Claude에서만 가능한 기능은 ‘설정 → 고급 기능 → 원본 Claude Code 열기’를 이용하세요.

새 버전은 어디서 확인하나요?

새 버전이 있으면 왼쪽 아래 설정 바로 위에 작은 다운로드 아이콘이 나타납니다. 다음에 하기를 눌렀어도 이 아이콘에서 변경 내용을 다시 볼 수 있습니다. 현재 버전이 최신이면 아이콘은 표시하지 않습니다. 아이콘을 누르는 것만으로 설치가 시작되지는 않습니다.

어떤 일을 하고 있는지 자세히 보기

대화에는 주요 설명과 최근 도구·스킬 호출을 여러 항목으로 보여 줍니다. 입력창 위에는 실제로 전달받은 도구 호출 준비, 실행 보고, 답변 작성 등의 동작을 짧게 보여 줍니다. 더 자세히 보고 싶으면 진행 내용을 펼치거나, 대화의 입력·결과 자세히 보기 또는 오른쪽의 진행 기록 보기를 누르세요.

  1. 도구·스킬을 부를 때 사용한 입력, 실행 결과, Claude가 전달한 중간 설명이 시간순으로 나옵니다. 하위 작업자가 전달한 내용도 구분해 표시합니다.
  2. 이전 기록으로 앞부분을 보고 최신 기록으로 돌아옵니다. 긴 내용은 해당 항목을 펼쳐 읽습니다.
  3. 다 읽었다면 접으세요. 현재 업무는 계속 진행되며 상세 화면을 접어도 새 기록은 남습니다.

이 기능을 넣기 전의 업무에는 상세 기록이 없을 수 있습니다. Claude가 앱에 전달하지 않는 터미널 전용 내용은 표시할 수 없으며, 보관·표시 제한으로 생략한 부분은 안내합니다. 상세 기록은 실행 버튼이 아니므로 내용을 펼치는 것만으로 명령을 다시 실행하지 않습니다.

화면이 너무 밝거나 어두울 때

앱에서 Ctrl을 누른 채 마우스 휠을 움직이면 화면을 확대·축소할 수 있습니다. 변경할 때 오른쪽 위에 현재 배율이 잠깐 표시됩니다. 열려 있는 팝업에서도 확인할 수 있습니다.

상단의 달 아이콘을 누르면 어두운 모드로, 해 아이콘을 누르면 밝은 모드로 바로 바뀝니다. 선택은 자동으로 저장되고 설정창에도 반영됩니다. 설정 → 화면 모드에서 밝게, 어둡게, 시스템 설정 따르기 중 하나를 고르세요. 고르면 바로 적용되고 다음에도 유지됩니다. 시스템 설정 따르기는 Windows 앱 밝기 설정에 맞춰 바뀝니다. 대화, 자료·결과, 팝업, 제목 표시줄과 PC 알림이 함께 바뀌며 이미지나 HTML 결과물 자체의 색상은 바꾸지 않습니다.

대기 목록의 요청을 먼저 실행하기

  1. 입력창 위의 이어 할 일 목록에서 먼저 실행할 항목을 찾으세요. 휴지통 버튼으로 삭제하거나 드래그로 순서를 바꿀 수 있고, 목록 관리에서 전체 요청을 확인할 수 있습니다.
  2. 현재 요청이 진행 중이면 지금 반영, 쉬고 있으면 지금 실행을 누르세요.
  3. 진행 중인 요청은 중지를 확인한 뒤 같은 대화에서 선택한 항목을 시작합니다. 첨부도 함께 사용하며 다른 대기 항목의 순서는 유지됩니다.

중지나 연결에 문제가 생기면 대기 항목을 지우지 않고 다시 확인할 수 있도록 남깁니다. 일시 정지·승인·질문 대기 상태라면 화면 안내에 따라 먼저 처리하세요. 현재 입력창에 작성하던 내용은 바뀌지 않습니다.

실행 파일과 실행 권한

Setup으로 설치했다면 시작 메뉴나 바탕화면의 AX Workspace 바로가기를 사용하세요. ZIP 배포본은 압축을 푼 최신 EXE를 그대로 실행하면 됩니다. 별도 최신 실행기 바로가기를 만들 필요는 없습니다. 앱 내부 업데이트만으로 예전 다운로드 EXE 자체가 바뀌지는 않으므로, 아주 오래된 EXE에서 권한 문제가 생기면 최신 EXE를 다시 받아 실행하세요.

현재 앱을 트레이에서 완전 종료한 뒤 최신 EXE를 우클릭해 관리자 권한으로 실행하세요. 일반 실행은 일반 Windows 환경에서 더블클릭합니다. 개인 설정이나 캐시를 지울 필요는 없습니다.

설정창은 항목별 카드로 구분되어 있으며 본문만 스크롤되고 제목과 닫기 버튼은 항상 위에 남습니다. 연결 동작의 차이는 중지·재시작·연결 종료 안내, Windows 권한 설명은 실행 권한 자세히 보기를 펼쳐 확인하세요. 사용 도움말 상단에서 AX Workspace를 만든 이유, 사용 안내서 순서로 자료를 열 수 있어요. 소개 자료도 인터넷 없이 읽을 수 있습니다.

Windows에서 일반·관리자 권한으로 실행하기

현재 0.23.27 앱과 Claude·도구는 프로그램을 열어 준 Windows 환경의 권한을 그대로 사용합니다. EXE도 이 권한을 상속하는 방식(asInvoker)이며, 설정의 현재 권한은 실제 실행 상태를 표시합니다. 앱 설정에는 권한을 바꾸는 선택칸이나 재시작 버튼이 없습니다.

  1. 일반 권한으로 열려면 일반 Windows 환경에서 EXE를 더블클릭하세요.
  2. 관리자 권한이 필요하면 EXE를 우클릭해 관리자 권한으로 실행을 선택하고 Windows 승인창이 나오면 본인이 확인하세요.
  3. 관리자 PowerShell에서 실행하면 관리자 권한을 그대로 유지합니다. VBS도 실행한 Windows 환경의 권한을 상속합니다.
  4. 다른 권한으로 열려면 기존 앱에서 설정 → 완전히 종료 또는 트레이 아이콘 우클릭의 완전 종료를 선택한 뒤 다시 실행하세요. 창의 X는 트레이로 숨기기이므로 완전 종료가 아닙니다.

진행 중인 작업이 있으면 종료 확인을 읽고 결정하세요. 기존 대화와 업무 폴더는 유지됩니다. 이어 할 일과 예약은 다시 열었을 때 내용을 확인하고 재개합니다.

Windows 관리자 권한과 Claude의 승인 모드는 별개입니다. 작업 중 승인 모드를 바꾸면 CLI 확인 후 이후 도구 호출에 적용하며 이미 나온 승인·질문은 직접 답해야 합니다. PC가 원래 관리자 토큰을 사용하는 환경이면 더블클릭도 관리자 실행일 수 있습니다. 앱은 기존 Windows 정책·같은 사용자·세션과 개인 Claude 설정을 유지합니다.

새로 받아도 계속 관리자 권한으로 표시돼요. 설정이 남은 건가요?

화면 모드 저장과 Windows 권한은 별개입니다. 다크 모드는 %LOCALAPPDATA%\CompanyAgent\local-ui\appearance.json에 저장하므로 새 EXE에서도 유지됩니다. 현재 앱은 관리자 권한을 저장하거나 캐시에서 복원하지 않습니다. 예전 execution-mode.json 파일이 남아 있어도 읽거나 적용하지 않습니다.

  1. 설정 → 앱과 Claude 실행 권한에서 현재 권한과 앱·실행기 버전을 확인하세요.
  2. 기존 창의 X만 누른 상태라면 트레이에서 완전 종료하세요. 숨겨진 앱은 처음 실행한 권한을 그대로 유지합니다.
  3. 관리자 터미널에서 열었는지, 바로가기의 속성 → 바로 가기 → 고급이나 EXE의 속성 → 호환성에 관리자 실행이 지정되어 있는지 확인하세요. 앱 설정과 별개인 Windows 실행 조건입니다.
  4. UAC가 꺼져 있거나 회사 정책상 처음부터 관리자 토큰을 사용하는 PC에서는 더블클릭도 관리자 실행일 수 있습니다. 현재 보안 정책은 유지하고 필요한 실행 조건을 담당자와 확인하세요.

관리자 표시 때문에 캐시나 local-ui 폴더를 삭제할 필요는 없습니다. 업무·예약·첨부나 개인 Claude 설정을 초기화하지 마세요. 개발용 --execution-mode 옵션도 현재 권한이 맞는지 검사할 뿐, 권한을 바꾸거나 Windows 승인창을 열지 않습니다.

지난 업데이트 내역 보기

설정 → 앱 업데이트 → 업데이트 내역을 누르고 배포 서버의 이력 또는 설치본 기본 변경사항을 선택한 뒤 버전을 고르세요. 최신 버전을 쓰고 있어도 이전 변경 내용을 읽을 수 있어요. 이 창에서는 설치하거나 업무를 중지하지 않습니다.

사내 배포 설명과 GitLab 릴리스 설명은 사내 서버에 남아 있는 문구예요. 배포 도구가 기존 기록을 가져오면 이전 버전도 확인할 수 있어요. 파일만 남은 버전은 배포 파일 기록으로 구분하고, 날짜는 패키지 등록일로 표시합니다. 당시 설명이 남아 있지 않거나 조회할 수 없으면 그 사실을 알려드려요.

앱 변경 이력은 앱에 포함된 과거 설명이에요. 사내에 실제 배포된 버전이나 날짜를 뜻하지 않으며, 사내 설명 대신 표시하지 않습니다.

GitLab 릴리스에서 직접 수정한 설명을 우선 표시합니다. 설명 수정 후에는 사내 배포 도구로 다시 게시해 동기화하고 이 창에서 다시 확인을 누르세요. 연결이 안 되면 저장된 배포 기록을 보여 주며, 설치본 기본 변경사항은 별도로 선택해 볼 수 있어요. 창을 열 때만 필요한 조회를 하고 최근 결과를 재사용하므로 이력을 위해 Claude를 연결하지 않아요.

앱을 최신 버전으로 바꾸기

설정의 업데이트 정보는 현재 버전·최신 버전·배포 서버를 한 행에, 마지막 확인 시각을 그 아래에 표시합니다.

앱을 열 때 새 버전이 있으면 변경 내용과 업데이트하고 다시 시작 / 다음에 하기를 안내합니다. 나중에 하기를 선택해도 왼쪽 아래의 작은 다운로드 아이콘은 남으며, 눌러서 변경 내용을 다시 볼 수 있습니다. 설정 → 앱 업데이트에서도 확인할 수 있습니다. 업데이트를 확인하는 것만으로는 설치하거나 작업을 멈추지 않습니다.

  1. 업데이트 내용 보기를 눌러 바뀐 기능과 수정 사항을 읽습니다.
  2. 원할 때 업데이트하고 다시 시작를 누릅니다. 앱이 파일을 내려받고 확인하는 동안 기존 업무를 계속할 수 있습니다.
  3. 다운로드와 재시작 준비 상태가 차례로 표시돼요. 작업으로 돌아가기로 창을 닫아도 진행 안내는 남습니다. 진행 중인 업무나 승인·질문을 마치면 전환하며, 종료가 시작되기 전에는 전환 취소가 가능합니다.
  4. 기존 앱이 닫히는 동안에도 업데이트를 적용하고 있어요 / 앱을 다시 시작하고 있어요 / 새 화면을 준비하고 있어요 대기창이 유지돼요. 새 화면 준비를 확인한 뒤 대기창을 닫고, 입력 내용과 첨부 복원 후 완료를 알려 줍니다. 오류가 있으면 완료로 표시하지 않고 확인 방법을 안내해요.
  5. 다음에도 원래 사용하던 EXE나 VBS를 실행하면 정상적으로 설치된 최신 버전이 열립니다.

이 기능이 처음 들어가는 버전은 한 번 직접 받아야 합니다. 0.21.10 이하를 쓰고 있다면 새 Release ZIP을 받아 실행한 뒤부터 앱 안의 업데이트를 사용할 수 있습니다.

인터넷 연결이 어려워도 기존 앱을 사용할 수 있습니다. 자동 확인은 설정에서 끌 수 있으며, 새 버전 확인으로 직접 확인할 수도 있습니다. Python이나 Claude Code의 개인 설정을 바꾸거나 설치하지 않습니다.

작성 중인 내용과 보관 자료 관리하기

보내지 않은 메시지도 다시 볼 수 있나요?

입력이 잠시 멈추면 작성 중인 내용과 첨부, Ctrl+S로 보관한 입력을 PC에 자동 저장합니다. 앱을 다시 열면 이어서 작성할 수 있으며, 자동으로 메시지를 보내지는 않습니다. 완전히 종료하거나 업데이트할 때는 마지막 저장을 먼저 확인합니다. 저장에 실패했다는 안내가 나오면 입력을 복사해 따로 보관해 주세요. 전원이 갑자기 꺼지면 마지막 저장 직후의 입력은 남지 않을 수 있습니다.

다른 업무로 옮겼더니 연결 대기라고 나와요.

새 업무를 시작할 자리가 필요하면 이미 완료된 연결을 잠시 정리합니다. 대화는 그대로 보관되고, 다시 요청하면 같은 세션과 설정으로 연결합니다. 진행 중이거나 승인·답변·이어 할 일을 기다리는 업무는 유지합니다.

업무 목록에서 지운 항목을 되살리고 싶어요.
  1. 설정 → 보관과 저장 공간 → 보관한 업무를 엽니다.
  2. 업무 이름이나 폴더로 검색합니다.
  3. 복원을 누르면 업무 목록에 다시 나타납니다.

대화와 원래 작업 파일은 그대로입니다. 복원만으로 Claude나 예약이 실행되지는 않습니다. 이어서 요청할 때 업무 폴더를 확인하세요.

첨부 공간이 부족하다고 나와요.
  1. 설정 → 보관과 저장 공간 → 첨부 저장 공간을 엽니다.
  2. 사용량과 정리할 수 있는 복사본을 확인합니다.
  3. 정리 버튼을 누르고 대상과 용량을 확인합니다. 남은 항목이 있으면 다시 정리할 수 있습니다.

앱에 끌어 넣으면서 만들어진 미사용 복사본만 정리합니다. 원본 파일과 전송한 자료, 초안·예약에서 사용하는 자료는 유지합니다. 최근 추가한 자료는 5분 동안 보존합니다. 예전 버전의 복사본처럼 사용 여부가 불명확한 자료도 자동으로 지우지 않습니다.
