터미널 명령을 외우지 않아도 기존 Claude Code의 모델·스킬·도구로 작업할 수 있는 Windows 앱입니다. 특정 하네스나 플러그인을 설치할 필요는 없습니다.

기존 Claude 환경을 사용합니다

압축을 푼 뒤 EXE 또는 VBS를 실행하세요. 설치된 Python 3.11 이상과 Windows PowerShell이 필요합니다. 앱은 Python이나 Claude를 설치하지 않습니다.

앱 전용 로그인은 없습니다. AI 업무에는 같은 Windows 사용자의 기존 Claude Code 설치와 인증을 사용합니다. 계정·모델·스킬·MCP·후크·회사 정책을 자동으로 바꾸지 않습니다.

이전 버전에서 업데이트할 때는 설정 → 완전히 종료 후 새 실행기를 여세요. 이전 업무 기록의 저장 위치는 호환성을 위해 유지합니다.

첫 업무 시작하기

  1. 새 업무에서 폴더를 고르거나 바탕화면 아래 새 업무 폴더를 만듭니다.
  2. 선택한 폴더의 지침·후크·연결 도구를 확인합니다. 해당 폴더를 사용하도록 동의한 뒤 Claude를 연결합니다.
  3. 자료 추가 또는 @로 파일을 연결하고 하고 싶은 일을 적습니다. 탐색기에서 끌어 놓은 파일은 앱 관리 공간에 복사해 첨부합니다.
  4. 필요한 질문과 승인에 답하고 이번 결과에서 파일을 확인합니다. Office 문서는 기본 앱, HTML은 브라우저 등 연결된 앱으로 열 수 있습니다.

업무와 이전 대화 관리

최근 업무의 손잡이를 끌어 같은 고정 그룹 안에서 순서를 바꿉니다. 핀 버튼으로 자주 쓰는 업무를 위에 고정할 수 있습니다. 저장한 순서는 앱을 다시 열어도 유지합니다.

이전 Claude 대화 불러오기에서 목록이나 세션 ID로 찾으면 원래 폴더와 대화를 함께 불러옵니다. 다른 터미널에서 같은 대화를 실행 중이면 먼저 마친 뒤 이어가세요.

스킬·도구의 공통/폴더 선택은 설치 스킬의 조회 범위입니다. 도구·연결 서버·명령은 선택한 업무의 실제 Claude 연결을 기준으로 확인합니다. 목록을 여는 것만으로 Claude를 새로 실행하지는 않습니다.

작업 중에는 끝나고 이어서로 요청을 대기시키거나 지금 반영으로 현재 요청을 중지한 뒤 이어갑니다. 예약은 PC가 깨어 있고 앱이 실행 중일 때 동작하며 재시작 후 확인하고 재개합니다.

창의 X는 화면만 닫습니다. 트레이에서 다시 열거나 완전히 종료할 수 있습니다. 완료·승인 알림은 상단 알림함에서 확인합니다. PC 배너 표시는 Windows 알림 설정에 따라 달라질 수 있습니다.

알림과 다음 행동을 한곳에서

통합 알림함

상단 알림에서 전체·읽지 않음·응답 필요·완료·확인 필요를 골라 봅니다. 업무 이름을 누르면 그 대화로 이동하고, 읽음 또는 모두 읽음으로 알림을 정리할 수 있습니다.

읽음으로 표시해도 승인하거나 답변하지 않습니다. 아직 기다리는 요청은 응답 필요에 남고, 끝난 요청은 현재 대기 없음으로 구분합니다. 한 업무의 여러 요청은 개수와 함께 모아 보여줍니다.

빠른 실행

왼쪽 빠른 실행이나 Ctrl+K로 업무·설정·결과·스킬을 검색합니다. ↑/↓로 고르고 Enter로 열며, Esc로 닫으면 원래 입력 위치로 돌아갑니다. 팔레트 검색어를 AI에 보내지는 않습니다. 대화 입력창의 /·@와 기존 단축키는 그대로 사용할 수 있습니다.

파일 변경 비교

이번 결과 → 파일 변경 비교에서 요청 기록과 파일을 고르면 저장된 이전·이후 내용을 확인합니다. 수집은 업무를 실행할 때 이루어지며, 같은 폴더의 기록을 함께 표시합니다. 다른 프로그램이 바꾼 내용도 포함될 수 있습니다.

앱 전체에서 최근 요청 8개를 보관하고, 텍스트는 파일당 128 KiB, 요청 전·후 각각 합계 512 KiB까지 수집합니다. 업무 폴더와 바로 아래 하위 폴더 중 지원하는 파일만 확인합니다. Office·PDF·이미지 등은 파일 정보만 표시합니다. 일부만 확인했거나 이전 내용을 저장하지 못했다면 그 이유를 안내합니다. 원본을 되돌리거나 덮어쓰는 기능은 아닙니다.

대화 분기

작업과 승인·질문을 마친 뒤 업무 제목 옆 대화 분기를 누릅니다. 마지막 완료 기록을 바탕으로 별도 업무를 준비하고 첫 요청을 보낼 때 독립된 Claude 대화가 만들어집니다. 원래 대화는 남고 새 업무에서 돌아갈 수 있습니다.

두 대화는 같은 업무 폴더를 사용합니다. 파일 수정은 함께 반영됩니다. 새 업무의 첫 연결에서 폴더 실행 권한을 확인하며, 대기 요청·예약·첨부 초안과 앱의 임시 연결 설정을 복제하지 않습니다. 임의의 과거 메시지 시점에서 분기하지는 않습니다. 설치된 Claude에 필요한 분기 옵션이 없거나 원본 기록을 확인하지 못하면 이유를 안내합니다.

새 화면은 열 때 필요한 항목만 읽고 닫으면 화면 목록을 해제합니다. 팔레트는 이미 불러온 업무만 검색하고, 변경 비교는 선택한 파일만 계산합니다. 기존 Claude 인증·스킬·MCP·Windows 설정을 변경하지 않습니다.

한글을 조합하는 중에는 입력 확정을 우선합니다. 모델·Effort·승인은 입력창 아래에서 클릭해서도 바꿀 수 있고, 설정 변경만으로 업무를 요청하지 않습니다. 로그인 등 터미널 전용 명령은 원본 Claude Code를 이용하세요.

⚠ Bypass는 명시적인 위험 확인 뒤 해당 업무에만 적용합니다. 파일 수정과 명령 실행의 승인 확인을 생략할 수 있으므로 신뢰하는 작업 환경에서만 선택하세요. Shift+Tab으로 실수로 켜지지 않으며 켜진 상태에서는 일반 모드로 돌아갑니다.

파일 이름과 기존 저장 경로 일부에 남아 있는 Company 명칭은 이전 버전과의 호환성을 위한 이름입니다. 특정 Company Agent 설치를 검사하거나 실행하지 않습니다. 개인 Claude 플러그인과 자료를 삭제하지 않습니다.
