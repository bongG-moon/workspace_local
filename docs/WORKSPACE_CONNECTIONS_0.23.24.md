# AX Workspace 0.23.24 — 동시 연결과 확인 후 교체

2026-10-14

## 동작

최대 5개 Claude 연결을 필요할 때만 생성합니다. 완료된 안전한 유휴 연결을 우선 정리하며, 모두 사용 중이면 직접 보내기·연결·재시작 요청에서 가장 오래 연결된 업무의 이름과 상태를 확인한 뒤 교체합니다. 업무 생성일 대신 현재 연결의 시작 시각을 기준으로 합니다. 재시작·설정 변경·종료 중인 연결은 교체 후보에서 제외합니다.

확인한 연결·실행 중인 요청·새 입력에 한정된 일회성 확인을 2분간 유지합니다. 상태 변경, 만료, 중복 클릭 또는 화면 이동에서는 다른 업무를 종료하지 않습니다. 종료를 확인할 수 없으면 새 연결을 시작하지 않고 입력과 첨부를 보존합니다.

중단한 업무의 대화·파일·세션 ID와 확인된 모델·Effort·승인 설정을 보존합니다. 이어 할 일과 예약은 일시정지하고, 사용자가 해당 업무에서 내용을 확인한 뒤 재개합니다. 이미 실행한 파일 변경은 되돌리지 않습니다. 아직 요청을 보내지 않은 준비 전용 연결을 저장된 대화로 잘못 재개하지 않습니다.

예약 실행과 자동 목록 조회는 진행 중인 업무를 강제로 종료하지 않습니다. 강제 교체 후보는 사용자의 연결 요청 때 확인하며 별도의 주기적 프로세스 검사나 타이머를 추가하지 않습니다. 연결 종료는 앱이 소유한 CLI와 하위 프로세스 범위에 한정합니다.

## 완료 연결 메모리 보완 (동일 버전 수정본)

실행 상한은 5개이며, 전체 연결의 평상시 유지 목표는 3개입니다. 완료·연결·설정 변경·대기 목록 변경 시 정리 필요 여부만 표시합니다. 기존 예약 처리 스레드가 대기 요청을 먼저 처리한 뒤 안전한 오래된 완료 연결을 한 번에 하나씩 정리합니다. 추가 타이머·프로세스 검색·Claude 조회는 만들지 않고, 변경 없는 대기 상태에서는 업무 목록을 반복 검색하지 않습니다.

진행 중·승인 및 질문 대기·하위 작업자 실행·설정 전환·미전송 이어 할 일은 정리하지 않습니다. 5개가 모두 작업 중이면 5개를 유지합니다. 3개가 작업 중이고 2개가 완료됐다면 완료된 2개만 정리합니다. 완료된 연결만 5개라면 최근 연결과 현재 보고 있는 업무를 우선해 3개를 남깁니다.

자동 정리는 대화·파일·세션 ID·확인된 모델/Effort/승인 설정과 예약을 보존합니다. 같은 업무에 다음 요청이나 예약이 들어오면 재연결합니다. 종료 확인 실패 시 해당 연결은 재시도 반복 없이 슬롯을 유지하고, 다른 업무의 대기·예약 처리를 중단시키지 않습니다. 앞서 설명한 사용자가 확인하는 강제 교체의 일시정지 동작과 구분됩니다.

보완 검증: 전용 테스트 15개, 기존 연결/교체/자원 관리 테스트 33개, 예약/재시작/종료/준비 및 화면 계약 테스트 묶음 143개, 모델/Effort/승인 제어 테스트 98개가 통과했습니다. 전용 테스트 일부는 143개 묶음에 포함되어 있어 단순 합산하지 않습니다. 실제 테스트용 CLI 5개를 실행해 오래된 PID 2개 종료·3개 유지, 원래 UUID와 설정으로 재연결한 요청의 1회 전송, 앱 종료 후 수집한 PID 6개와 예약 스레드 종료를 확인했습니다. 개인 Claude나 사내 MCP를 실행한 메모리 측정은 포함하지 않습니다.

## 검증 범위

- 구현 기준 연결·예약·중지·재시작·자동 조회·입력 UI 회귀 테스트 288개 통과.
- 5개 연결 제한, 여섯 번째 요청 확인·취소·교체, 승인 대기, 종료 실패, 병렬 요청과 중복 전송 방지.
- 확인 대상의 상태·실행 ID·프로세스 변경 및 확인 만료 시 종료 방지.
- 대화·설정·첨부 보존, 초기화만 수행한 연결의 재개 처리, 대기열·예약 일시정지.
- 테스트용 CLI 프로세스 5개를 실제로 실행해 종료 후 신규 요청 1회 실행과 남은 프로세스 수 확인.

실제 Claude 모델 호출, 사내 PC의 보안 정책·프로필·MCP 조합은 이번 격리 시험에 포함하지 않습니다. 5개 연결로 늘어난 Claude·MCP 자체의 메모리 소비가 동일하다고 보장하지 않습니다. 원격 Release의 상태와 다운로드 해시는 게시 단계에서 별도로 확인합니다.
