# 0.23.19 검증 — 예약 시간 방식과 입력 디자인 개선

2026-10-05 검증. 참고한 포털의 시간 입력 방식만 반영했다. 포털의 CUBE·메일 발송, Agent 실행 대상과 Worker 기능을 앱에 추가하지 않았다. 2026-10-06 공개 배포 준비 과정에서 관련 회귀 검사와 소스·배포 파일 일치를 다시 확인했다.

## 사용법

업무를 선택하고 입력창 위 **실행 예약**을 누른다. 기존 요청과 첨부를 가져오며, **예약 방식**에서 다음 중 선택한다.

| 방식 | 입력 | 시간 규칙 |
| --- | --- | --- |
| 한 번 | 날짜와 시간 | 앞으로 지정한 시각에 한 번 예약 |
| 평일 | 시간 | 월요일~금요일의 같은 시각 |
| 매일 | 시간 | 매일 같은 시각 |
| 매주 | 요일 여러 개와 시간 | 선택한 요일의 같은 시각 |
| 매월 | 1~31일과 시간 | 해당 날짜가 없는 달은 건너뜀 |
| 간격 반복 | 시간·분, 시작·종료 시각 | 매일 시작을 기준으로 종료 시각 전까지 예약 |

간격은 합계 1분~24시간이며, 종료 시각은 시작보다 늦어야 한다. 자정을 넘는 구간은 지원하지 않는다. 8시간 0분·07:00~23:59의 예시는 07:00 → 15:00 → 23:00 → 다음 날 07:00이다. 화면에 시간 규칙과 최대 4개의 예시 시각 및 하루 예약 횟수를 표시한다.

기존 실행 경로, 현재 Claude 인증·모델·승인 모드, 대기열, 일시 정지·수정·삭제와 중복 방지 규칙을 유지한다. PC의 현재 시간대를 사용하며, 앱이 켜져 있고 PC가 깨어 있어야 한다. 재시작 후에는 기존처럼 내용을 확인하고 이어 실행한다. 놓친 시각을 몰아서 실행하지 않고 같은 예약의 요청이 남아 있으면 추가 요청을 쌓지 않는다. 예약 시각은 요청을 대기열에 넣는 기준이며 실제 작업 시작·완료 시각을 보장하지 않는다.

## 검증 결과

- 시간 설정·기존 대기열·예약 API·전체 예약·프런트엔드·버전 진단 관련 123개 검사: 122개 통과, 1개 환경 조건부 생략.
- 월말과 연도 경계, 31일 없는 달, 윤년 2월 29일, 주말 제외, 선택한 여러 요일, 종료 시각 제외, 8시간·2시간 30분·1분·24시간 간격을 확인했다.
- 저장·다시 읽기, 기존 3가지 방식의 기록 호환, 일시 정지 중 수정, 바뀐 방식의 이전 필드 제거, 같은 전송 ID의 중복 방지, 손상된 기록 보존과 실행 차단을 확인했다.
- 새 방식도 기존 서버의 send 경로로 요청을 한 번만 전달하는 것을 격리된 CLI 대역과 가상 시계로 검증했다. 실제 업무용 AI 요청은 보내지 않았다.
- 실제 브라우저의 격리된 체험 화면에서 간격·매월·평일 예약을 저장하고 다음 실행 시각을 확인했다. 잘못된 실행 구간 거절, 수정 시 8시간 값 유지, 전체 예약에 표시되는 시간 규칙도 확인했다.
- 480×800 화면에서 폼의 가로 넘침이 없고 시간·분 단위가 줄바꿈되지 않으며 저장 버튼이 화면 안에 보이는 것을 확인했다.
- 새 EXE를 별도 상태·폴더로 실제 실행해 0.23.19, 평일·매월 31일·8시간 간격 등록, 다음 실행 시각과 정상 종료 및 runtime 정리를 확인했다.
- EXE 내장 ZIP 검증, EXE·VBS의 공통 파일 129개 일치, 원본 122개와 고정 빌드 자산 7개 일치 확인. Python 포함·설치·다운로드 없음.

증거는 로컬 `build/qa-schedule-0.23.19/`와 `build/qa-schedule-all-tests.log`에 보관한다. 사용자 업무나 기존 포털 소스는 변경하지 않았다. 사내 PC 정책과 실제 업무 결과의 품질을 검증했다는 의미는 아니다.

## 같은 버전의 입력 스타일 보완

예약 방식 선택칸을 기준으로 시간·날짜·월별 날짜·간격의 시간/분·시작/종료 입력을 통일했다. 공통 팝업 입력 스타일보다 예약 영역의 스타일이 우선하도록 수정했다. 실제 브라우저에서 여섯 방식의 표시 높이 39px, 글꼴 12px, 안쪽 여백 8px 10px, 모서리 10px와 동일한 배경·테두리를 확인했다. 기존 시간 입력·검증·수정 관련 검사 6개를 통과했고 EXE·VBS ZIP을 같은 0.23.19로 재빌드했다. 화면·측정 증거는 `build/qa-schedule-style-0.23.19/`에 보관했다.
