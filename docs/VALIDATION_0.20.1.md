# 0.20.1 알림 크기·글꼴·모서리 검증

검증일: 2026-09-30. Windows 개발 PC에서 수행했습니다. 모든 운영 PC의 화면 배율·모니터·알림 정책 조합을 검증했다는 뜻은 아닙니다.

## 변경 결과

알림을 368×190에서 340×96 DIP로 줄였습니다. 높이는 약 49%, 면적은 약 53% 감소했습니다. 기존 연보라 색상을 유지하고 상태·업무명·열기/결과 버튼만 남겼습니다. 긴 안내문은 접근성 설명으로 유지하고 알림함 기록·알림 설정·클릭 라우팅은 보존했습니다.

Noto Sans KR의 실제 400·600 굵기를 네이티브 실행 파일에 포함했습니다. 시스템 글꼴 설치 없이 프로세스 내부 GDI+ 글꼴로 표시합니다. 한 개의 둥근 Region과 그에 맞춘 선을 사용하고 기존 시스템 그림자 스타일을 제거했습니다. Windows 비클라이언트 테두리와 모서리 설정도 중복되지 않도록 요청합니다.

## 네이티브 카드와 글꼴

`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-lab/test-notification-card.ps1 -OutputDirectory build/qa-notification-card-compact`로 최종 네이티브 빌드를 검사했습니다.

- 완료·응답 대기·오류 3종을 96/144/192 DPI에서 렌더링: 340×96, 510×144, 680×192 픽셀
- 짧은 한글 업무명과 긴 업무명의 말줄임, 작은 작업 영역·음수 좌표 모니터 배치 확인
- 내장 글꼴의 실제 400·600 굵기, private font family, 서로 다른 굵기의 래스터 결과 확인
- 포함 글꼴의 전체 cmap과 현대 한글 11,172자 유지 확인
- 실제 HWND의 비클라이언트 렌더링 비활성 상태와 자동 모서리 비활성 설정 9/9 확인
- 창 영역과 클라이언트 영역 크기가 같고 추가 비클라이언트 테두리가 없는지 확인
- 별도 테두리 색 속성의 조회는 이 환경에서 지원되지 않아 확인 결과로 계산하지 않음
- 포커스를 받지 않는 표시·버튼 스타일, 열기·닫기 접근성 콜백이 정확한 ID로 한 번만 발생하는지 확인
- 생성·DPI 변경·해제 64회 후 GDI 21→21, USER 20→20

글꼴 생성 도구의 `--check`도 통과했습니다. 기존 출처가 확인된 Noto Sans KR Variable WOFF에서 400·600 정적 글꼴을 생성하며, 압축 바이트 재현성과 전체 문자 매핑을 확인합니다. 원본 라이선스와 생성 출처는 `deploy/fonts/`에 보관합니다.

렌더링 이미지와 네이티브 프레임 조회는 완료했습니다. 실제 마우스로 최종 카드의 버튼을 누르는 동작, 실제 혼합 배율 모니터 간 이동, 모든 Windows 버전·방해 금지 정책 조합은 이번에 검증하지 않았습니다. 접근성 콜백과 IPC 회귀 통과를 실제 마우스 클릭 검증으로 간주하지 않습니다.
