# 사용자 중지 오류 표시 보완 검증 — 2026-10-03

## 수정 범위

질문 대기 중 사용자가 직접 중지했는데도 `ede_diagnostic` 실패 경고와 오류 알림이 생기던 문제를 보완했다. 중지·같은 대화 이어가기 자체는 이전 실제 Windows 시험에서 정상으로 관찰됐다.

실제 0.23.6 배포와 일치하는 `workspace_local` 소스(`9a72917`)를 기준으로 수정했다. 상위 개발 저장소에도 같은 작은 수정만 반영했으며, 서로 다른 버전의 파일 전체를 덮어쓰지 않았다.

## 달라진 동작

- 현재 연결에서 명시적으로 중지 중이고, 기존 세션과 일치하는 알려진 중단 응답만 일반 실패에서 제외한다.
- 해당 응답은 `[ede_diagnostic] result_type=user last_content_type=n/a stop_reason=tool_use` 전체 서명이다. 표식 하나만 있거나 다른 오류가 함께 있으면 제외하지 않는다.
- 남은 질문·승인 상태를 정리하고 이어갈 세션 ID를 보존한다. 정상 완료나 성공 답변을 만들어 내지 않는다.
- 앱이 소유한 CLI의 실제 종료 확인 뒤에만 기존 ‘중지’ 상태를 표시한다.
- 중지하지 않은 작업의 같은 진단, 인증 실패, 실제 종료 실패, 다른 세션, 아직 연결을 확인하지 못한 첫 분기 응답은 기존 오류 처리 경로를 유지한다.
- 원문 응답은 연결 객체의 `last_result`에 남긴다. 이것을 영구 로그 저장으로 설명하지 않는다.
- 화면의 모든 오류 배너를 일괄 삭제하지 않는다. 기존에 발생한 실제 오류를 감추지 않는다.

추가 모델 호출, 자동 재전송, 새 폴링, 추가 대기시간은 없다. 인증·모델·MCP·개인 설정과 사용자가 만든 결과 파일은 변경하지 않는다.

## 검증 근거

동일 합성 입력을 수정 전 HEAD와 수정 후 코드에 전달해 비교했다.

| 상황 | 결과 |
| --- | --- |
| 수정 전 코드 + 사용자 중지 + 알려진 진단 | `cli_turn_incomplete` 오류 발생 — 기존 결함 재현 |
| 수정 후 코드 + 사용자 중지 + 같은 진단 | 오류 없음, 질문 해제, busy 해제, 세션 보존, 거짓 완료 이벤트 없음 |
| 수정 후 코드 + 중지하지 않음 + 같은 진단 | `cli_turn_incomplete` 오류 유지 |

새 회귀 테스트 13개를 포함해 배포 저장소의 관련 테스트 **189개를 재실행했다. 187개 통과, 실패 0, 실행 조건에 따른 생략 2**, 총 67.270초였다. 중지·종료·화면 상태·대기열/즉시 요청·진행 기록·분기·가져오기·실행 정책을 포함한다. 상위 개발 저장소도 기존 관련 테스트 58개와 새 테스트 13개가 모두 통과했다. 두 저장소의 중복 검사를 서로 다른 기능 수로 합산하지 않는다.

새 테스트는 `python -X utf8 -B -m unittest discover -s tests -p test_workspace_stop_classification.py -v`로 재실행할 수 있다. `LocalApp.stop → interrupt → 중단 응답 → 실제 종료 처리`에서 실패/완료 알림이 모두 없으며, 후속 요청 때 새 연결이 같은 native session으로 한 번만 전송되는 것을 검증한다. 첫 세션 정보 누락, 분기의 init 전·후, 일반 오류·인증 오류 혼합, 종료 실패도 포함한다. `git diff --check`를 통과했다.

## 수정 직후의 검증 한계와 배포 상태

아래는 소스 수정 단계의 기록이다. 이후 요청에 따른 0.23.7 패키징·배포 검증은 [별도 기록](VALIDATION_0.23.7.md)에서 확인한다.

- 이번 수정 후 검증은 합성 CLI 응답과 자동 회귀 테스트다. 실제 계정으로 동작하는 새 Windows EXE의 화면 시험을 다시 완료했다고 주장하지 않는다.
- 이미 받은 EXE/ZIP, 설치 캐시, 실행 중인 시험 앱은 수정하지 않았다.
- 새 버전 패키징·커밋·푸시·Release 게시·운영 PC 검증은 이번 변경에 포함하지 않았다.
- 기존 0.23.6 검증의 미완료 업데이트/IME/사내 HCP 항목은 그대로 미검증이다.
