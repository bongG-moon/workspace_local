# 0.23.20 검증 — 실행 권한 선택과 진행 표시

2026-10-06. 앱 설정에서 일반·관리자를 선택하고 앱과 Claude의 실행 권한을 함께 전환합니다. 기본값은 일반이며 Windows 승인을 우회하지 않습니다. 입력창 위 진행 표시를 회전 스피너로 개선했습니다.

## 변경 범위

- 진행 중인 작업·승인·질문이 끝나기를 기다리고 초안·첨부를 보관한 뒤 권한을 전환합니다. 새 앱이 준비된 뒤에만 앱 자체 선택 파일에 저장합니다. Claude 개인 인증·모델·Effort·승인 모드·MCP·스킬·메모리와 Windows 정책을 유지합니다.
- 같은 Windows 계정·로그인 세션·실제 권한 토큰을 확인합니다. 관리자 API는 요청 프로세스의 실제 권한도 검사하며 일반 프로세스에는 최소 실행 정보와 같은 계정의 창 열기만 허용합니다.
- WebView2 샌드박스를 유지하고 전용 창이 인증된 같은 출처 요청만 중계합니다. 동시 요청 4개·응답 32MiB로 제한하며 큰 본문은 사용 후 삭제되는 임시 스트림으로 처리합니다.
- 준비·실행·중지 처리 중에만 12px 보라색 스피너를 회전합니다. 승인·답변 대기는 정적인 표시, 완료·중지·오류는 기본 점으로 표시합니다. 별도 JavaScript 타이머를 추가하지 않으며 움직임 줄이기·고대비 설정을 지원합니다.
- 실행기·서버·진단·README·사내 게시 도구 변경 이력을 0.23.20으로 맞췄습니다. 진단은 `ws33-55`, 대상 소스는 `workspace-0.23.20`입니다.

## 확인 결과

- 전체 검사 2,074개: 2,036개 통과, 환경 조건부 36개 생략, 재실행 가상 응답 형식 누락으로 2개 실패. 가상 응답에 현재 권한 정책 정보를 반영하고 정책이 없는 같은 버전 교체 검사도 추가했습니다. 앱 실행 코드를 약화하거나 검사를 제외하지 않았습니다.
- 수정 후 권한·재실행·업데이트·진단·화면 관련 187개 재검사: 186개 통과, 실제 사용자 진단 옵트인 1개 생략. 기존 실패 2개와 추가 교체 검사가 통과했으며 이후 미해결 실패는 없습니다.
- 실제 사용자 실행기 검사 3개 모두 통과. 병렬 검사 중 버전 보호 검사 1개가 제한 시간을 넘겼으나 단독 재실행과 3개 순차 재검사에서 통과했습니다. 추가 AI 요청이나 개인 설정 변경은 수행하지 않았습니다.

- 새 EXE 내장 검증 통과. EXE·VBS 공통 파일 133개 일치, 원본 126개·고정 빌드 자산 7개 확인. Python과 개인 상태·자격 증명을 포함하지 않습니다.
- 실제 EXE를 별도 상태·캐시에서 실행해 일반 권한, 권한 정책 프로토콜 1, 선택 저장, 전용 창 준비, 실행기 종료 코드 0, 재실행 시 같은 프로세스 재사용과 정상 종료·runtime 정리를 확인했습니다. 스피너 스타일과 권한 선택 화면 코드도 패키지·원본이 일치합니다. 실제 AI는 호출하지 않았습니다.
- 직전 로컬 0.23.19 보완본의 computer-use 검증에서 실행 중 스피너·답변 대기·완료 표시를 확인했습니다. 이번 0.23.20에서 해당 화면 코드는 동일하며 버전·사용 안내를 갱신했습니다. [보완본 검증 기록](VALIDATION_EXECUTION_MODE_0.23.19.md)
