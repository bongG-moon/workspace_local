# AX Workspace 0.23.50 — Claude 경로 비교와 사용 금액 조회 개선

## 터미널에서는 Claude가 응답하지만 앱에서는 인증 오류가 날 때

오류 안내에서 **확인할 사항 → 터미널과 경로 비교**를 누르세요. 앱이 찾은 Claude 설정 폴더와 실행 파일의 위치가 표시됩니다. 이 화면은 **설정 → 업무 연결 → Claude 실행 환경**에서도 열 수 있습니다.

1. 비교하려는 항목의 확인 명령을 복사해 Claude가 정상 작동하는 PowerShell에서 실행하세요.
2. 결과가 앱에 표시된 경로와 다르면 해당 항목만 입력하거나 **폴더 선택** 또는 **파일 선택**으로 지정하세요.
3. **점검 후 적용**을 누르면 실행 점검에 성공한 설정을 다음 새 연결부터 사용합니다. 다시 앱이 경로를 찾게 하려면 해당 항목의 **자동으로 되돌리기**를 누른 뒤 적용하세요.

## 팀 사용 금액을 조회하지 못했을 때

앱 화면이 보이는 동안 팀 사용 금액을 5분마다 확인합니다. 조회에 처음 실패하면 2분 뒤에 다시 확인하고, 실패가 이어지면 5분 간격으로 확인합니다. 서버가 더 긴 대기 시간을 지정하면 그 시간을 따릅니다.

오류가 발생하면 사용량 카드에 조회 상태와 원인 안내가 표시됩니다. **새로고침**으로 직접 확인할 수도 있습니다. 수동 조회는 마지막 시도에서 15초가 지난 뒤 가능하며, 서버가 지정한 대기 시간도 적용됩니다.
