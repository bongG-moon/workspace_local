# Company Workspace 0.12.0 사용 범위와 호환성

2026-09-29 기준입니다. Workspace는 기존 Claude Code를 GUI로 사용하는 별도 앱이며, 로그인·회사 연결·모델·MCP·개인 스킬·기억 설정을 자동 변경하지 않습니다. 새 ZIP을 적용할 때는 기존 앱의 **설정 → 앱 종료**를 누르고 새 폴더에서 `Company-Workspace.vbs`를 실행하세요. 기존 업무와 기록은 이동하거나 삭제하지 않습니다.

## Workspace ZIP과 Company Agent 코어의 차이

**Workspace 0.12.0 ZIP은 앱과 실행기를 교체합니다. 설치된 Company Agent 코어·스킬·후크를 업데이트하는 패키지가 아닙니다.** 코어 버전 번호만 보고 새 기능이 있다고 판단하지 않습니다. 이번 소스의 코어 개선에 대해 새 최소 배포 버전 번호를 선언하지 않았습니다.

| 조합 | 기대할 수 있는 동작 |
|---|---|
| Workspace 0.12.0 + 기존 Company Agent 1.4.28 설치 | 파일 선택·저장 위치·글꼴·카탈로그 메타데이터·대기 배지·외부 열기·입력 보조를 사용할 수 있습니다. 모델/모드/세션 허용은 설치 Claude의 실제 제공·응답 범위에 따릅니다. HTML 디자인은 기존 텍스트 질문, Stop은 설치된 기존 후크 동작을 유지할 수 있습니다. |
| Workspace 0.12.0 + 기능이 확인된 업데이트 코어 | 위 기능에 더해 `workspaceChoice` schema 1 HTML 카드, 정확한 선택 대기의 Stop 보정 구분, 등록된 실행기 도움말 조회 예외를 사용할 수 있습니다. 코어에 helper·runtime·스킬 지침·후크 변경이 함께 적용돼야 합니다. |
| Company Agent 등록을 확인하지 못함 | 확인 가능한 Claude 스킬 메타데이터와 설치 진단을 표시합니다. 관리·코어 전용 기능은 사용 가능하다고 표시하지 않으며 다른 설치로 자동 전환하지 않습니다. |
| 설치 CLI가 목록·제어를 제공하지 않음 | 미확인 또는 지원 불가로 표시합니다. 추정 목록·모드 별칭으로 대체하거나 설정을 다시 쓰지 않습니다. |

Workspace는 CLI 자식 프로세스에 `COMPANY_WORKSPACE_UI=1`을 전달합니다. 지원 코어가 이를 읽고 정확한 선택 계약을 반환해야 카드가 표시됩니다. 이 값은 계정의 영구 환경변수나 개인 설정에 저장하지 않습니다. 기존 코어가 같은 목록을 텍스트로 반복 생성하는 문제까지 Workspace만으로 해결됐다고 판단하지 마세요.

카탈로그는 서버가 상속한 설정 경로의 읽기 전용 메타데이터입니다. 기존 Claude 호출 스크립트가 내부에서 설정 경로를 바꾸는 경우 실제 CLI와 다를 수 있으므로 **설치에서 발견**과 **현재 연결에서 확인**을 따로 봅니다.

## 사용하면서 알아둘 점

- 지원 문서·이미지: MD, TXT, CSV, TSV, HTML/HTM, PDF, PPTX, DOCX, XLSX, PNG, JPG/JPEG, WEBP. 파일 추천이나 앱 미리보기가 AI의 실제 문서 읽기 성공을 뜻하지 않습니다.
- Windows 알림은 화면과 연결된 정확한 Edge 앱 창만 대상으로 합니다. 실행파일·사용자·세션·창 제목·프로세스 수명을 확인하지 못하면 점멸을 요청하지 않습니다. 브라우저 알림에는 업무 제목과 대기 종류만 표시하며 본문·실행 명령은 넣지 않습니다.
- 승인 모드와 연결 한정 규칙은 새 연결에 이어지지 않습니다. 원래 모드를 확인하지 못한 연결에서 기존 설정으로 돌아가면 연결을 닫고 다음 요청에서 원래 설정을 다시 읽습니다. 다른 업무와 개인 기본 설정은 유지합니다.
- 텍스트 미리보기는 UTF-8, BOM 있는 UTF-16, CP949를 손실 치환 없이 읽습니다. 인코딩을 확인할 수 없으면 외부 앱을 안내하며 원본을 바꾸지 않습니다.
- 앱 창의 **X**는 서버를 종료하지 않습니다. 완전한 종료와 새 버전 적용에는 **설정 → 앱 종료**를 사용합니다.

## 확인한 범위와 남은 확인

자동 시험은 가상 CLI, 임시 파일, API 경계, 대기·선택·권한 메시지와 Windows API의 읽기 전용 조회를 포함합니다. 브라우저 화면에서 전체 대기·`/`·`@`·HTML 열기 버튼도 확인했습니다. 이는 실제 회사 모델 응답이나 Office·기본 브라우저에서 업무 문서를 열어 검증했다는 뜻은 아닙니다.

기존 PC의 UAC·보안·계정 설정을 바꾸지 않습니다. UAC-off 회사 PC의 VBS → 제한 토큰 → 실제 Claude 업무, 실제 Edge 작업표시줄 점멸, 회사 Office·보호 문서·연결 앱은 해당 환경에서 추가 확인해야 합니다. 시작 실패 시 같은 묶음의 `Check-Workspace.cmd`로 읽기 전용 진단을 실행하고 [결과 읽는 법](WORKSPACE_STARTUP_DIAGNOSTIC.md)을 참고하세요. 제한 토큰 생성이나 실제 자식 실행은 진단 도구의 확인 범위에 포함되지 않습니다.

현재 소스의 상세 진행·시험 기록은 [구현 진행 기록](WORKSPACE_IMPLEMENTATION_PROGRESS_2026-09-29.md)에 있습니다. 이 링크는 저장소에서 확인하며 실행용 ZIP에는 진행 기록이 포함되지 않을 수 있습니다. 새 ZIP 제작·게시·직원 PC 적용은 각각 별도 확인 사항입니다.
