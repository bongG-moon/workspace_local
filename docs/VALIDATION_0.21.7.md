# 0.21.7 좌우 패널 색상 검증

검증일: 2026-10-01. 이번 기능 변경은 `local_app/web/app.css`의 패널 색상 규칙 22줄입니다. 배포 버전 표기와 현재 사용 문서도 함께 갱신했습니다.

## 디자인

- 좌측 업무 목록: `#eeebf8` → `#e7e2f2`의 연한 라벤더 그라데이션.
- 우측 자료·결과: `#f0edf9` → `#eae5f4`의 조금 더 밝은 라벤더 그라데이션.
- 중앙 대화 영역의 배경은 유지하고, 패널 경계·검색창·선택된 업무·자료 탭·폴더 카드만 주변 색감에 맞췄습니다.
- 새로운 색상 규칙은 `forced-colors:none`에 한정했습니다. Windows 고대비 모드의 기존 시스템 색상 처리를 덮어쓰지 않습니다.
- 그림자는 기존과 같은 CSS 표현이며 새 이미지·애니메이션·타이머·백그라운드 작업을 추가하지 않았습니다.

## 확인 결과

- 별도 가상 업무에서 Computer Use로 실제 WebView2 창을 확인했습니다: 홈, 대화, 선택된 업무, 접힌 아이콘 레일, 작은 창에서 펼친 우측 패널.
- 마지막 글자 대비 보정까지 포함한 0.21.7 EXE에서도 홈 화면을 다시 확인했습니다.
- 새 색 조합의 계산상 대비: 좌측 보조 글자 4.57:1, 선택된 업무·메뉴 4.94:1, 비선택 자료 탭 4.88:1, 숫자 배지 4.51:1. 전체 앱의 접근성 검사를 새로 수행했다는 의미는 아닙니다.
- 기존 레이아웃 회귀 검사 9건 모두 통과. 색상 변경에 대한 별도 구현 복제 테스트는 추가하지 않았습니다.
- VBS ZIP: 소스 110개와 고정된 네이티브 빌드 파일 7개를 검증했습니다.
- 실제 로그인한 Windows 사용자에서 최종 EXE만 있는 한글 경로로 실행했습니다. 기존 Python 3.13.5 및 Claude Code 2.1.286 발견, WebView2 창, 동일 EXE 재실행 시 서버 재사용, 개인 설정 파일 해시 보존을 확인했습니다.
- 이번에는 AI 요청·예약·승인 기능을 다시 실행하지 않았습니다. 해당 기능의 코드 변경이 없으며 이전 단축키 검증 범위는 [0.21.6 기록](VALIDATION_0.21.6.md)에 있습니다.

화면의 가상 대화는 배치 확인용이며 배포 파일에 포함하지 않습니다. 모든 모니터의 색 보정·배율 조합과 실제 Windows 고대비 전환은 수동 확인하지 않았습니다.
