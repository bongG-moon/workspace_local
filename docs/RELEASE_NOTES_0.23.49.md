# AX Workspace 0.23.49 — 업무 이어가기와 Claude 실행 환경 개선

이미 0.23.49를 사용 중이면 트레이에서 앱을 완전히 종료하고 최신 0.23.49 설치 파일을 다시 받아 설치하세요.

## 변경된 파일을 Windows 탐색기에서 찾기

- 채팅의 **이번 요청 중 바뀐 파일**에서 파일 옆 **폴더에서 보기**를 누르면 Windows 탐색기가 열리고 해당 파일이 선택됩니다.
- 오른쪽 **자료** 탭에서 **저장 위치 선택** 옆의 **폴더 열기**를 누르면 현재 업무의 저장 폴더가 열립니다.
- **이번 결과** 탭의 **명령 실행 중 확인된 폴더 변경**에서도 **폴더에서 보기**로 위치를 확인할 수 있습니다. 파일이 이미 삭제됐다면 업무 폴더 안에서 가장 가까운 남아 있는 상위 폴더가 열립니다.

## 같은 폴더에서 새 업무로 이어가기

요청이 끝나면 업무 제목 옆 **이어가기**를 누르세요. 두 가지 방법 중 하나를 고를 수 있습니다.

- **요약으로 시작 (handoff)**을 누르면 진행한 일, 결정 사항, 남은 일을 요약해 같은 폴더의 새 업무로 가져옵니다. 원래 대화는 이전 업무에서 다시 볼 수 있습니다.
- **대화 기록으로 시작 (기존 대화 분기)**을 누르면 마지막으로 완료한 질문과 답변까지 복사합니다. 같은 업무에서 만든 분기는 이름에 **분기1**, **분기2**처럼 번호가 붙습니다.

Claude가 알려준 컨텍스트 사용량이 60%를 넘으면 업무 상단에도 이어가기 안내가 한 번 표시됩니다. 제목 옆 **이어가기**는 그전에도 사용할 수 있습니다.

## 터미널에서는 Claude가 응답하지만 앱에서는 인증 오류가 날 때

오류 안내에서 **확인할 사항 → 터미널과 경로 비교**를 누르세요. 앱이 찾은 Claude 설정 폴더와 실행 파일의 위치가 표시됩니다. 이 화면은 **설정 → 업무 연결 → Claude 실행 환경**에서도 열 수 있습니다.

1. 비교하려는 항목의 확인 명령을 복사해 Claude가 정상 작동하는 PowerShell에서 실행하세요.
2. 결과가 앱에 표시된 경로와 다르면 해당 항목만 입력하거나 **폴더 선택** 또는 **파일 선택**으로 지정하세요.
3. **점검 후 적용**을 누르면 실행 점검에 성공한 설정을 다음 새 연결부터 사용합니다. 다시 앱이 경로를 찾게 하려면 해당 항목의 **자동으로 되돌리기**를 누른 뒤 적용하세요.

## 팀 사용 금액을 조회하지 못했을 때

앱 화면이 보이는 동안 팀 사용 금액을 5분마다 확인합니다. 조회에 처음 실패하면 2분 뒤에 다시 확인하고, 실패가 이어지면 5분 간격으로 확인합니다. 서버가 더 긴 대기 시간을 지정하면 그 시간을 따릅니다.

오류가 발생하면 사용량 카드에 조회 상태와 원인 안내가 표시됩니다. **새로고침**으로 직접 확인할 수도 있습니다. 수동 조회는 마지막 시도에서 15초가 지난 뒤 가능하며, 서버가 지정한 대기 시간도 적용됩니다.

## 터미널에서는 Claude가 열리는데 앱에서는 연결되지 않을 때

**설정 → 업무 연결 → Claude 실행 환경**에서 평소 Claude를 사용하는 PowerShell을 고르세요. **선택한 환경 점검**을 누르면 그 환경에서 Claude가 실행되고 앱 연결에 필요한 옵션을 제공하는지 확인합니다. 로그인과 모델 사용 권한은 실제 요청에서 확인됩니다.

**점검 후 적용**을 누르면 점검에 성공한 환경이 저장됩니다. 다음에 새로 시작하는 연결부터 적용되며, 진행 중인 업무는 기존 연결에서 계속됩니다.

오류 안내의 **확인할 사항**에서 연결이 어느 단계에서 멈췄는지 볼 수 있습니다. 예를 들어 Windows PowerShell 5.1에서 시작 설정 파일을 읽다가 문법 오류가 발생하면, 확인된 오류 줄과 인코딩 단서를 보여줍니다. **진단 요약 복사**로 이 정보를 담당자에게 전달할 수 있습니다.

## 일반 대화와 업무에서 입력할 때

- 입력창 위쪽 경계를 위아래로 끌어 높이를 조절하세요. 손을 놓으면 높이가 저장됩니다. 경계를 두 번 클릭하면 기본 높이로 돌아갑니다.
- 입력창 첫 줄에서 **↑**를 한 번 누르면 작성 중인 글을 계속 편집할 수 있습니다. 1.5초 안에 **↑**를 한 번 더 누르면 이전에 보낸 요청을 불러옵니다. 이전 요청을 살펴본 뒤 **↓**로 가장 최근 위치까지 돌아오면 작성하던 글과 첨부파일이 다시 표시됩니다.
