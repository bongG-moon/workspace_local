# AX Workspace 0.23.28 배포 검증

검증일: 2026-10-18. Windows에서 Python 3.13, Node 및 NSIS 3.12를 사용했습니다.

## 기능과 회귀 검사

업데이트 내역 기능 구현 후 관련 검사에서 중복을 제외한 **493개 통과, 3개 건너뜀, 실패·오류 0개**를 확인했습니다. 백엔드·인증 경로·기존 업데이트·프런트엔드와 사내 배포 도구를 포함합니다. 세 건은 Windows 계정의 심볼릭 링크 생성 권한이 필요한 검사입니다.

- GitLab 기존 채널 기록, 릴리스 설명, 패키지 목록의 우선순위와 출처 구분을 모의 서버로 검증했습니다. 사내에서 수정한 설명을 보존하고, 파일만 확인되는 경우 설명을 만들어 넣지 않습니다.
- 이전 이력 형식과 날짜 형식, 손상된 기록, 부분 실패, 재시도, 조회 시간·개수·용량 제한을 확인했습니다. 기존 최신 버전 채널과 업데이트 ZIP 계약을 유지합니다.
- 인증 없는 요청 거부, 잘못된 요청 거부, 제한된 서버 주소, 토큰·응답 본문 비저장, 캐시와 오프라인 표시를 확인했습니다.

버전·문서·진단 해시를 0.23.28로 갱신한 후 영향받는 **194개 검사를 다시 실행해 192개 통과, 2개 건너뜀, 실패·오류 0개**를 확인했습니다. 이 결과는 위 기능 검사와 중복되므로 합산하지 않습니다. 제외된 두 검사는 명시적 실행이 필요한 실제 일반 사용자 토큰 검사와 심볼릭 링크 생성 권한 검사입니다. 이번 릴리즈에서 전체 저장소의 모든 검사를 다시 실행한 것은 아닙니다.

## 화면 검증

업데이트 내역 화면의 **브라우저 시나리오 11개가 통과**했고 페이지 오류는 0개였습니다.

- 최신 버전에서도 설정에서 이력을 열 수 있으며, 앱 시작이나 설정을 여는 것만으로 이력 조회를 시작하지 않습니다.
- 버전 선택, 출처·날짜, 설명 확인 불가 안내, 오프라인 캐시, 다시 확인, 닫은 뒤 조회 중지를 확인했습니다.
- 라이트·다크, 화면 폭 1440·640·360px에서 가로 넘침을 확인했습니다. 본문 13px·줄간격 25px와 32px 닫기 버튼을 확인했습니다.
- 키보드 이동·닫기·포커스 복원과 기존 입력 보존을 확인했습니다. 서버 설명의 HTML은 실행되지 않고 텍스트로 표시됩니다.
- 이력 확인은 모델 요청·Claude 연결·설치를 실행하지 않습니다.

## 실제 배포 파일

- 최종 EXE를 새로 빌드하고 `--verify-only`로 내장 파일 **171개**를 검증했습니다. EXE와 자동 업데이트용 VBS ZIP의 171개 파일이 바이트 단위로 일치합니다.
- 번들 허용 목록의 소스 **164개**와 고정된 빌드 자산 **7개**, 시작 진단의 정규화된 해시를 확인했습니다. 진단 버전은 `ws33-58`, 대상은 `workspace-0.23.28`입니다.
- 완성한 VBS ZIP을 새 임시 폴더에 풀어 demo/no-browser 모드로 실행했습니다. **8개 검사 그룹·21개 HTTP 요청**에서 버전·새 변경 내용·인증 거부·입력 검사·정적 JS/CSS·사용 안내서를 확인했습니다.
- HTML은 서버가 주입하는 기존 화면 모드 속성을 반영해 비교했습니다. 첫 비교의 기대값을 수정한 뒤 위 실행 검사를 다시 통과했습니다.
- 정상 종료 코드 0, runtime 파일 제거, 새 임시 추출·상태 폴더 정리를 확인했습니다. 개인 업무 상태나 실제 Claude 연결을 사용하지 않았습니다.
- 정식 제품 ID `AX.Workspace.Desktop`, 사용자별 설치, 파일 버전 `0.23.28.0`의 NSIS 설치 파일을 만들었습니다. 현재 사용 중인 앱에 실제 설치·제거를 수행하지는 않았습니다.
- Python·Claude Code·개인 인증·대화 상태는 배포 파일에 포함하지 않습니다.

## 운영 환경 확인 범위

실제 사내 GitLab에는 접속하거나 게시하지 않았습니다. 사내 배포 담당자는 새 소스 ZIP으로 해당 서버·프로젝트에 배포하고, 서버 보존 기록과 토큰 권한에 따른 이전 이력 조회 결과를 확인해야 합니다. 삭제된 설명은 복원할 수 없습니다. 실제 사내 인증·MCP·DRM·Office·AI 응답 및 사용자 PC에서의 설치·업데이트는 이번 격리 검증 범위에 포함하지 않습니다.
