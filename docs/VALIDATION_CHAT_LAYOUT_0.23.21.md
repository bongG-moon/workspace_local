# 0.23.21 채팅 자동 따라가기·사용자 말풍선 검증

검증일: 2026-10-08. 로컬 수정본이며 버전 번호는 0.23.21을 유지합니다. 이 기록은 GitHub 게시 완료를 의미하지 않습니다.

## 반영 내용

- 화면 높이 변화나 프로그램의 스크롤 이동만으로 자동 따라가기를 해제하지 않습니다. 최신 내용을 보는 중이면 답변, 도구 카드, 결과 카드, 이미지 영역, 입력창 및 화면 크기 변화 뒤에도 하단을 유지합니다.
- 사용자가 휠·키보드·터치·스크롤바로 위로 읽으면 해당 위치를 유지합니다. 직접 하단으로 돌아오거나 최신 응답 버튼을 누르거나 새 메시지를 보내면 따라가기를 다시 시작합니다.
- 코드·표·상세 진행 목록의 내부 스크롤을 대화 전체의 스크롤과 구분합니다. 상세 진행 내용을 직접 열 때는 읽는 위치를 우선합니다. 승인 대기 업무를 여는 자동 안내는 따라가기 의도를 해제하지 않습니다.
- 사용자 말풍선과 일반 본문은 오른쪽 정렬하며 내용에 맞춰 너비를 정합니다. 최대 너비는 기본 80%, 좁은 화면은 95%입니다. 긴 텍스트·첨부 파일명은 줄바꿈하고 코드·표·목록 내부의 읽기 정렬은 유지합니다.
- 사용 가이드에 따라가기와 말풍선 동작을 반영했습니다.

## 검증

- 스크롤, 스트리밍, 사용자 입력, 스킬 화면, 상세 진행, 풍부한 콘텐츠, 배치, 승인 카드 관련 **161개 검사 통과**. 이벤트 범위 조정 후 해당 모듈 **111개 검사도 통과**했습니다. 두 집합은 중복되므로 합산하지 않습니다.
- 새 동작 검사 17개에는 내용·뷰포트 증가, 하단 복귀 직후의 높이 변경, 하단 가까이에서 위로 읽기, 스크롤바·터치·키보드, 내부 스크롤, 숨긴 창·스킬 화면·업무 전환, 전송 후 따라가기, 승인 카드 복원이 포함됩니다.
- 실제 WebView2 가상 업무 창에서 짧은 입력, 긴 URL, 여러 줄 입력, 긴 첨부명과 이미지, 밝게·어둡게 표시를 확인했습니다. 20개 조각의 가상 답변과 완료 카드가 추가된 뒤 하단 유지, 위로 읽는 중 새 답변을 받은 뒤 위치 보존, 최신 응답 버튼으로 하단 복귀를 확인했습니다.
- 실제 창 확인에는 합성 메시지와 앱 아이콘 복사본만 사용했습니다. 개인 업무·Claude 요청·사내 서버는 사용하지 않았습니다. 도구 전용 연속 출력, 실제 터치 장치, 물리적 다중 모니터 전환은 자동 동작 검사 범위이며 현장 실측을 의미하지 않습니다.

## 부하와 범위

단일 ResizeObserver가 현재 업무 콘텐츠와 대화 뷰포트만 관찰하고, 스크롤 갱신은 단일 requestAnimationFrame으로 합칩니다. 업무 변경·홈·스킬 화면·숨긴 창에서 불필요한 관찰과 예약된 화면 갱신을 중단합니다. 기존 메시지 버퍼 제한을 유지하며 새 폴링 타이머·서버 요청·상주 프로세스는 추가하지 않습니다. 운영 PC 전체 성능을 새로 측정한 것은 아닙니다.

자동 검사 로그: `build/qa-chat-scroll-final.log`, `build/qa-chat-scroll-last.log`. 실제 화면 확인은 별도 임시 상태의 가상 업무 창에서 수행했으며 검증 창과 서버를 종료했습니다.

로컬 EXE·VBS ZIP을 새로 만들고 공통 파일 145개(소스 138개·생성 자산 7개)의 일치와 EXE 내장 파일 검증을 통과했습니다. 산출물은 `hermes/dist/workspace-chat-layout-20261008`에 있습니다. 이번 변경은 아직 커밋·푸시·GitHub Release에 게시하지 않았습니다.
