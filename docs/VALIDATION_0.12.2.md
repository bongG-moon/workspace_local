검증일: 2026-09-29. 사용법과 지원 범위는 [입력 안내](WORKSPACE_0.12.2_INPUT.md)에 정리했습니다.

## 변경

- 입력창의 스킬·명령 / 파일 / 모델·승인 바로가기, 검색 강조, 후보 설명과 키보드 조작 안내.
- `/` 이름·네임스페이스 내 이름의 앞부분 검색, 문장 중간 삽입, 원래 인자와 커서 보존.
- `@` 문서 및 일반 소스 파일 추천, 공백이 있는 한글 경로 인용, 입력 참조와 첨부 칩 유지.
- 첫 질문 전 기존 Claude CLI 초기화로 명령을 발견. 질문을 대신 보내지 않으며 시작 후크/MCP 초기화는 실행될 수 있습니다.
- 원본 CLI 전환은 앱이 소유한 자식 프로세스의 정리 완료를 확인한 뒤 실행. 작업 전환·종료·늦은 응답·중복 클릭 방어.
- 실행기 재사용 버전을 0.12.2로 맞추고 진단의 고정 소스 해시 및 식별자 `ws33-5`를 갱신했습니다.
