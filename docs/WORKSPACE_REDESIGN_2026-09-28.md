# Company Workspace 0.10 — 업무 중심 GUI 재설계

2026-09-28. 터미널과 경로 명령에 익숙하지 않은 사용자가 기존 Claude Code 실행 환경을 앱 화면으로 사용할 수 있도록 구현한 로컬 미리보기 버전입니다. 기존 화면 구성은 교체했으며 실제 업무 엔진·사용자 설정 연결은 유지했습니다.

## 참고한 실제 서비스

공식 제품 페이지의 화면과 설명을 확인했습니다. 해당 서비스를 설치하거나 실제 계정으로 사용한 검증은 아닙니다. 코드·로고·브랜드 자산은 가져오지 않았습니다.

| 서비스 | 참고한 점 | 이번 구현 |
| --- | --- | --- |
| [Claude Cowork](https://claude.com/product/cowork) | 업무 요청, 자료, 결과를 중심으로 구성 | 새 업무 → 자료 선택 → 자연어 요청 → 승인 → 결과 확인 |
| [Linear](https://linear.app/features) | 일관된 탐색, 현재 업무의 맥락, 간결한 정보 밀도 | 고정·검색·최근 업무와 명확한 진행 상태 |
| [Raycast AI](https://www.raycast.com/core-features/ai) | 집중된 입력과 문맥에 맞는 실행 동선 | 하단 입력창, 요청 시작 카드, 결과에서 후속 요청 |

뉴모피즘은 위 제품들이 사용한다고 주장하는 스타일이 아니라 이번 앱에 적용한 자체 시각 방향입니다. 밝은 porcelain 배경, indigo 강조, 양방향 부드러운 그림자와 눌린 입력창을 사용합니다. 작은 본문은 색 대비를 높이고 버튼 테두리·선택 상태·키보드 초점을 함께 표시합니다. 외부 폰트/CDN 없이 실행합니다.

## 화면과 동작

- **업무 홈:** 자료 정리·보고서·발표·자유 요청의 시작 예문과 최근 업무. 예문은 입력창만 채웁니다.
- **새 업무:** 앱 관리 폴더 자동 생성 또는 기존 폴더 선택. 이름은 폴더 경로로 사용하지 않습니다. 실행할 업무 위치의 신뢰 확인을 받습니다.
- **업무 화면:** 자연어 입력, 첨부, 부분 응답, 질문 선택, 실행 승인, 중지, 업무 제목 변경과 고정. 화면 이동 중 초안은 메모리에 유지합니다.
- **자료 / 이번 결과:** 로컬 자료 목록, 안전한 텍스트·이미지·정적 HTML 미리보기, 최근 요청 전후 파일 변화 관찰, 후속 요청 첨부.
- **설정:** 실행 연결 재확인, 실제 초기화에서 받은 모델·스킬·MCP 정보, 지원하는 연결의 임시 모델 변경, 기존 학습·기억·사용 현황 도우미.
- **좁은 화면:** 자료와 결과를 별도 패널로 열고, 좁은 상단 탐색과 스크롤 가능한 업무 홈을 제공합니다.

모르는 CLI 개념을 기본 화면에서 먼저 학습하도록 요구하지 않습니다. 승인에서 일반적인 파일 읽기/쓰기/편집은 대상과 영향·변경 전후를 설명합니다. 임의 명령 및 외부 도구의 의미를 추측해서 안전하다고 표시하지 않으며 도구 설명과 실행 원문을 함께 보여 줍니다.

## 구현 경계

웹 UI → 인증된 loopback Python 서비스 → 기존 Claude CLI의 stream-json/control 프로토콜 구조를 유지합니다. 실행기는 Windows Edge의 앱 창을 사용합니다. 이번에 Electron/MSIX 설치형 런타임으로 이전하지는 않았습니다.

주요 변경 파일은 `local_app/web/index.html`, `app.css`, `app.js`, `companion.js`, `local_app/server.py`, `history.py`, `bridge.py`, 새 `artifacts.py`입니다. 버전은 0.10이며 런처의 실행 중 버전 확인과 진단 해시·미리보기 ZIP 파일 목록도 맞췄습니다.

부분 응답은 설치된 CLI가 `--include-partial-messages`를 지원할 때만 활성화합니다. message ID와 content block index로 최종 응답과 합칩니다. [공식 headless 문서](https://code.claude.com/docs/en/headless), [스트리밍 문서](https://code.claude.com/docs/en/agent-sdk/streaming-output), [공식 SDK control 구현](https://github.com/anthropics/claude-agent-sdk-python/blob/main/src/claude_agent_sdk/_internal/query.py)을 참고했습니다. 연결별 모델 변경은 초기화된 대기 연결에서 응답 확인 후 반영하며 사용자의 영구 모델 설정을 수정하지 않습니다.

새 공간은 기본 `%LOCALAPPDATA%/CompanyAgent/local-ui/workspaces` 하위입니다. 사용자 지정 상태 폴더가 있으면 해당 폴더를 따르고, 화면에 실제 위치를 표시합니다. 대화 목록은 고정 여부와 최근 갱신순으로 최대 500개를 보관합니다. 기존 기록 원본과 개인 설정을 자동 삭제하거나 이동하지 않습니다.

- 브라우저 UI: 기존 폴더 연결, 새 관리 공간 생성, 자연어 입력, 질문/승인, 파일 변화 표시, Markdown 표 미리보기, 결과 재첨부, 홈 왕복 초안 유지, 이름 변경·고정, 연결별 모델 적용·원복, 부분 응답 중복 제거, 중지 후 승인 카드 제거, 도움말 연결을 확인했습니다.

## 현재 한계

- 사내 HCP 인증, DRM/Office 실제 자료 처리, 직원 PC 설치 정책은 이번 가상 UI 시험으로 검증되지 않았습니다.
- 모든 터미널 기능을 GUI로 재구현한 것은 아닙니다. 로그인/설치/일부 고급 명령은 기존 Claude 환경이 필요합니다. 모델 선택도 실제 연결이 지원하고 회사 제공자가 허용하는 이름만 사용할 수 있습니다.
- 결과 목록은 요청 전후 파일 크기·수정 시각 비교이며 생성 주체/요청과의 인과 관계를 확정하지 않습니다. 문서 확장자, 폴더 깊이 1단계, 파일/디렉터리/시간 한도가 있고 외부 첨부 위치의 결과·삭제 파일은 자동 수집하지 않습니다.
- 대화 초안은 앱 재시작 후 복구되지 않습니다. 대화 본문은 로컬 기록 정책을 따릅니다. Markdown은 표·목록·제목·코드·강조 중심의 제한된 렌더러입니다.
- 기존 Windows 일반 권한 토큰이 없는 WS-33 환경 및 창 X 버튼 종료 수명주기의 기존 제약은 그대로입니다. 앱의 **설정 → 앱 종료**를 사용하면 소유한 실행을 정리합니다.

## 실행

저장소 루트 또는 새 미리보기 ZIP을 푼 폴더의 `Company-Workspace.vbs`를 더블클릭합니다. 다른 Workspace 버전이 실행 중이면 먼저 해당 앱을 종료합니다. ZIP은 별도 미리보기 산출물이며 GitHub 게시나 기존 사용자 설치 갱신은 수행하지 않았습니다.
