# AX Workspace 0.23.22 검증 기록

게시 준비일: 2026-10-12 (한국 시간).

0.23.21 로컬 수정본의 스킬 자동완성·단일 원본 연결·하위 폴더 명령·중지 안내 변경을 새 버전으로 묶습니다. 사용자 상태와 개인 스킬은 배포하지 않습니다. [상세 스킬 검증](VALIDATION_SINGLE_SOURCE_SKILLS_0.23.21.md)과 [사용 가이드](WORKSPACE_USER_GUIDE.html)를 참고하세요.

## 기능 검증

- 0.23.22 최종 재검증: 스킬·입력·서버·Windows 시작·브랜드 패키지·배포 이력·소스 ZIP·최신 실행기 관련 318개 중 313개 통과, 환경 조건 5개 생략. 로그: `build/qa-release-20261012.log`.
- 스킬·입력 통합 회귀 175개 중 172개 통과, 환경 조건 3개 생략. 실제 Windows 정션 테스트는 통과했으며 생략은 심볼릭 링크 생성 권한 2개와 선택적 구형 하네스 소스 부재 1개입니다.
- 기존 환경 상속·래퍼·프로필·세션 이어가기·Effort·승인 모드 68개 통과.
- 답변 중지·이어가기·분류·도움말·입력 관련 57개 통과. 위 검사들과 범위가 일부 겹칩니다.
- 실제 CLI 2.1.296, 격리된 설정과 로컬 가짜 API를 사용해 같은 프로세스에서 새 스킬 생성 및 원본 수정 후 `/스킬명`에 변경된 본문이 포함됨을 확인했습니다. 외부 모델 요청 0회, 실제 개인 스킬 실행 0회입니다.
- 기존 개인 원본과 설정을 보존하고 업무 전용 폴더 연결로 같은 실제 파일을 읽는 것을 확인했습니다. 이 연결은 해당 PC에만 적용했으며 사용자 경로나 스킬은 릴리즈에 포함하지 않습니다.

## 배포 계약

앱 서버, Windows 시작·버전 전환·진단, VBS 묶음 및 상태 확인 스크립트의 현재 버전을 0.23.22로 맞춥니다. 과거 버전 검증 문서와 변경 이력은 당시 버전으로 보존합니다. 소스 확인 목록은 Git 인덱스의 실제 파일 바이트에서 생성하며 새 릴리즈 이력을 포함합니다.

EXE·VBS 본문 파일 일치, 사내 반입용 소스 ZIP의 버전·소스 목록, 소개 HTML 포함 여부를 검사합니다. 공개 게시 후에는 main·태그의 커밋 일치와 다운로드 SHA256, Code → Download ZIP의 소스 목록도 별도로 확인합니다. 공개 파일의 최종 해시는 Release의 `SHA256SUMS.txt`를 기준으로 합니다.

운영 사내 GitLab 재게시, 실제 업무 스킬의 업무 결과, 사내 보안 제품과의 조합은 이번 로컬·공개 배포 검증 범위가 아닙니다. 앱은 기존 CLI 연결을 사용하며 터미널 화면 자체의 모든 메뉴를 대체하지 않습니다.
