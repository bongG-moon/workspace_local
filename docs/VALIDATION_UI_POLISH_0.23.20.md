# 0.23.20 입력 메뉴·알림·간격 검증

검증일: 2026-10-06. 버전은 0.23.20을 유지합니다. 앞서 반영한 버튼 반응성, 작업 중 승인 전환, PowerShell 정리 개선을 포함합니다.

## 변경 내용

- 모델·Effort·승인 버튼의 글자 화살표를 SVG로 바꾸어 글꼴 기준선과 무관하게 중앙 정렬합니다. 열린 메뉴의 아이콘만 회전하며, 움직임 줄이기 설정을 따릅니다.
- 선택창은 누른 버튼 위 8px 간격으로 열립니다. 화면과 중앙 대화 영역의 경계 안에서 위치·너비를 조정하고, 위쪽 공간보다 아래쪽 공간이 넓을 때만 아래로 전환합니다.
- 창 크기, 스크롤, 비동기 목록 높이 변경은 열린 동안만 관찰합니다. 같은 프레임의 위치 계산을 합치고 닫으면 관찰자·이벤트·예약 프레임을 해제합니다. 상시 타이머는 추가하지 않았습니다.
- 실행 중 입력창 하단의 구분선 여백을 11px에서 6px, 상태 문구 위 간격을 9px에서 3px로 줄였습니다. 두 안내 문구의 줄높이를 1.5로 맞추고 좁은 화면의 세로 배치 간격도 줄였습니다. 글꼴 크기, 버튼 크기와 전송·중지·승인 동작은 유지합니다.
- 네이티브 알림의 작은 한글에서 보이던 색 번짐을 줄이도록 `ClearTypeGridFit` 대신 회색조 `AntiAliasGridFit`를 사용합니다. 기존 내장 글꼴·크기·색상·DPI 처리·클릭 동작은 유지합니다.

## 확인하지 못한 범위

실제 최소화 상태의 완료·응답 대기 알림 요청에는 호스트가 응답했지만, 현재 PC에서 `notificationAccepted=false`, `notificationReason=suppressed`를 반환했습니다. 따라서 실제 우측 하단 배너 표시가 성공했다고 처리하지 않습니다. Windows 설정은 변경하지 않았으며, 물리적 다중 모니터 간 이동과 운영 PC의 GPU·배율 조합도 별도 확인이 필요합니다.

로컬 증거는 `build/qa-caret-notification-0.23.20/VALIDATION.md`, `build/qa-anchored-controls-0.23.20/VALIDATION.md`, `build/qa-compact-followup-0.23.20/VALIDATION.md`, `build/qa-notification-typography-final/`, `build/qa-publish-ui-0.23.20/packaged-final-validation.json`에 있습니다. `build`의 격리 시험 자료는 소스 배포에 포함하지 않습니다.

## 수정본 실행 방법

EXE ZIP 또는 VBS ZIP을 새 폴더에 풀고, 기존 앱을 트레이에서 **완전 종료한 뒤** 실행하세요. 같은 0.23.20이므로 버전 비교 기반 자동 업데이트 알림은 나오지 않으며, 기존 프로세스가 남아 있으면 그 창을 재사용합니다.

최신 배포 파일의 해시는 [Release의 SHA256SUMS.txt](https://github.com/bongG-moon/workspace_local/releases/download/v0.23.20/SHA256SUMS.txt)로 확인하세요. 이전 검증 문서의 해시는 해당 시점의 기록이며 현재 배포 파일과 다를 수 있습니다. 사내 배포 도구도 같은 소스와 변경 안내를 사용하며, 사내 GitLab 게시 자체는 사내 PC에서 별도로 진행합니다.
