# AX Workspace 0.23.35 — 사용량 표시와 스토어 설치 연계 개선

버전은 0.23.35를 유지하며 2026-10-27까지의 변경을 포함한 설치 파일과 소스 ZIP으로 갱신했습니다.

- **LLM 사용량 표시:** 왼쪽 하단 설정 메뉴 위에서 사용률과 남은 예산을 확인합니다. 화면 이름은 ‘LLM 토큰 사용량’이며 실제 수치는 서비스가 제공하는 팀 사용 금액/예산입니다. 80%·95%에 안내를 구분하고 조회 오류가 업무 실행을 막지 않도록 분리했습니다. 운영 주소 설정은 `docs/LLM_USAGE.md`를 참고하세요. 로컬 예시는 명시적인 데모 모드에서만 표시합니다.
- **스토어 AI 설치 요청:** 공통 또는 업무 설치 범위와 ‘요청을 처리할 업무 위치’를 고르면 선택한 기존 업무로 이동합니다. 실행 중인 일이 없으면 일반 대기열 처리로 시작하고, 작업 중이면 끝난 뒤 이어서 실행합니다. 중지·전송 확인이 필요한 대기열은 그대로 유지합니다. 초안·첨부·폴더 권한·승인 모드를 보존합니다.
- **스토어 파일 첨부:** 파일 선택과 끌어 놓기를 위한 공통 업로드 연결부를 추가했습니다. 선택한 파일만 전달하고 파일 크기·형식·경로를 확인합니다.
- **업무 목록 클릭 개선:** 제목은 업무 열기에 사용하고 순서 이동은 옆 손잡이로 구분했습니다. 클릭 도중 목록이 갱신돼 입력이 누락되는 경우도 보완했습니다.
- **선택 상자 정렬:** 스킬·플러그인 팝업의 저장 범위 글자가 상자 중앙에 오도록 수정했습니다.
- **요청 시간과 상태 표시 유지:** 요청별 소요 시간, 업무를 이동해도 유지되는 실행 시간, 진행 중 초록 점·완료 후 미확인 보라 점·오류 빨간 점을 포함합니다. 확인하지 않은 결과와 연결 설정은 앱 재실행 후에도 유지합니다.

P&T AI Square 확장 0.1.0과 플랫폼 API도 함께 갱신했습니다. 내 도구 전체 목록, KEY 기반 직접 등록, 파일 끌어 놓기, 공통/업무 설치 요청과 화면 전환 개선은 새 확장 Distribution에서 설치 파일을 다시 만들어 배포해야 적용됩니다.

## 다운로드

- Windows 설치: `AX-Workspace-0.23.35-Setup.exe`
- 사내 반입·GitLab 배포용 소스: `workspace-local-0.23.35-source.zip`
- 자동 업데이트용 EXE·VBS ZIP, 호환 파일명과 `SHA256SUMS.txt`도 함께 갱신합니다.

사내 운영 환경은 새 소스 ZIP을 기존 사내 배포 도구로 게시한 뒤 사내 업데이트 채널로 적용합니다. GitHub 게시만으로 사내 GitLab 서버가 변경되지는 않습니다.

기본 앱·확장 회귀 검사, 격리 MongoDB 기반 등록 API, 실제 Edge의 라이트/다크 화면·클릭·드롭다운·파일 첨부·설치 요청·화면 전환을 검증했습니다. 사내 LLM 사용량 서버, 개인 KEY, 실제 업무의 설치 명령 실행은 이 검증 범위에 포함하지 않았습니다.
