# AX Workspace 0.23.35 — 요청 시간과 업무 상태 표시 개선

- **요청별 소요 시간:** 완료한 답변 아래에 실행부터 종료까지 걸린 시간을 표시합니다. 중지·오류로 끝난 요청도 구분하며, 업무를 이동하거나 앱을 다시 열어도 저장된 시간이 유지됩니다. 기록이 없는 예전 요청의 시간은 추정하지 않습니다.
- **실행 중 경과 시간 유지:** 다른 업무로 이동했다 돌아와도 원래 요청을 시작한 시각부터 표시합니다. 실행 전 대기열·준비 시간과 완료 후 파일 확인 시간은 소요 시간에서 제외하고, 실행 중 승인·답변 대기는 포함합니다.
- **업무 상태 구분:** 진행 중은 초록색 점, 완료했지만 아직 확인하지 않은 결과는 보라색 점과 굵은 제목으로 표시합니다. 오류는 기존 빨간 점으로 구분하며 라이트·다크 모드의 배경에 맞춰 색상을 조정했습니다.
- **실제로 본 결과만 확인:** 해당 업무의 최종 결과가 활성 화면에 보였을 때 미확인 표시를 해제합니다. 다른 업무·과거 대화·설정·스킬 화면을 보고 있을 때는 유지합니다. 접힌 업무 폴더, 최근 업무와 전체 업무에도 새 결과를 알립니다.
- **미확인 상태 보존:** 앱 재실행이나 이어 할 일의 다음 요청 실행 후에도 이전 미확인 결과가 남습니다. 여러 업무가 동시에 완료되거나 확인 응답이 늦게 도착해도 더 새 결과의 표시를 지우지 않도록 했습니다. 기존 과거 업무를 일괄 미확인으로 만들지 않습니다.
- **기존 기능과 반응성 유지:** 초안·첨부, 이어 할 일, 동시 업무, 업데이트 복구와 확장 연결 정보를 유지합니다. 별도 주기 조회나 토큰마다 실행하는 처리를 추가하지 않으며, 변경이 없으면 업무 목록을 다시 그리지 않습니다.

기본 앱 버전을 **0.23.35**로 올렸습니다. 이전 0.23.34 갱신본의 요청 시간 표시와 이번 업무 상태 표시를 함께 포함합니다.

## 다운로드

- Windows 설치: `AX-Workspace-0.23.35-Setup.exe`
- 사내 반입·GitLab 배포용 소스: `workspace-local-0.23.35-source.zip`
- 기존 자동 업데이트용 EXE·VBS ZIP, 호환 파일명과 `SHA256SUMS.txt`도 함께 제공합니다.

사내 운영 환경은 새 소스 ZIP을 기존 사내 배포 도구로 게시한 뒤 사내 업데이트 채널을 통해 적용합니다. GitHub 릴리즈 게시만으로 사내 GitLab 서버가 변경되지는 않습니다.

관련 회귀 검사 224개와 실제 앱 UI·격리 HTTP 서버 기반 브라우저 시나리오 12개를 검증했습니다. 포커스 해제 조건은 브라우저에서 모사했으며, 실제 사내 Claude·VDI 환경이나 Windows 최소화까지 검증한 결과는 아닙니다. 기존 P&T AI Square 확장은 유지되며 이 릴리즈에서 별도로 갱신하지 않습니다.
