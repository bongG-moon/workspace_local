# AX Workspace 0.23.30 검증

2026-10-22. 소스 버전과 실행기·진단·번들 이름·내장 릴리즈 노트를 0.23.30으로 맞췄습니다. 기능 수정 검증과 공개 릴리즈용 설치 EXE·업데이트 ZIP 빌드 검증을 완료했습니다. 사내 GitLab 게시와 회사 PC 실행은 로컬 검증에 포함하지 않습니다.

## 포함한 변경

- 오늘 저녁의 응답성, 승인 폴더 유지, Auto 기본값, 실행 빌드 확인, 모드 숫자 배치 개선은 [기존 검증](WORKSPACE_RESPONSIVENESS_AND_DEFAULTS_REVIEW.md)에 기록되어 있습니다.
- 추가 자료·결과 탭의 동일 너비와 좁은 채팅 영역의 상태줄 배치를 포함합니다.
- 사용자가 실제로 받는 설명은 [0.23.30 변경 내용](RELEASE_NOTES_0.23.30.md)과 내장 릴리즈 기록에 동일하게 반영했습니다.

## 실행 결과

- 버전 변경 관련 실행기·Python 진단·앱 진단·빌드 식별·배포 이력·업데이트 경로 10개 테스트 모듈, 총 124개 검사를 실행했습니다. 버전 변경으로 달라진 진단 해시와 이력 30개 보관 상한에 맞지 않던 오래된 테스트 가정을 수정했습니다. 해당 2개 모듈 31개를 재실행해 통과했습니다. 합계 123개 통과, 실제 로그인 사용자 토큰의 명시적 opt-in 검사 1개는 제외했습니다.
- 릴리즈 기록 검사는 새 버전의 검토된 Markdown과 앱에 포함하는 변경 내용이 일치하는지도 확인합니다. 오래된 모든 버전을 내장 기록에 영구 보관한다고 가정하지 않습니다.
- Edge에서 자료·결과 숫자 0/1/9/10/99/200/999, 패널 최소 260px·기본·최대 너비를 확인했습니다. 두 탭 너비와 아이콘·제목·숫자 위치가 유지되고 내부 겹침이 없었습니다.
- 같은 창 너비에서 실제 포인터로 우측 패널을 드래그해 상태줄이 두 줄로 바뀌는 것을 확인했습니다. 중앙 최소 420px, 창 너비 700px, 넓은 화면을 함께 확인했습니다.
- 밝은·어두운 화면, 큐가 있어 버튼이 숨겨진 상태, 일반 대화·간편 모드에서 숨김과 빈 줄 처리가 유지됐고 작성 중 초안도 그대로였습니다. 브라우저 오류는 없었습니다.

## 추가 성능 점검

[성능·구조 점검 보고서](PERFORMANCE_REVIEW_0.23.30.md)에 최초 원인 분석과 후속 구현 상태를 구분했습니다. 사용자 승인에 따라 스킬 계산·버전 관리와 응답성 개선을 반영했습니다. 큰 응답 이벤트의 메모리 상한은 변경하지 않았습니다. 사내 PC의 원인 확정이나 실제 Claude 실행 검증으로 해석하지 않습니다.

## 후속 구현 검증

- 한글 50만 자의 합성 대화에서 활동 30건을 연속 처리했습니다. 같은 실행의 동기 저장 기준은 30회·45,081,600바이트·300.84ms, 병합 후는 1회·1,504,763바이트·최종 flush 포함 14.24ms였습니다. 이는 연속 활동 묶음의 측정이며 앱 전체 성능 배율을 의미하지 않습니다.
- 저장을 latch로 보류한 동안 다른 업무의 삭제·순서 변경·지금 반영이 먼저 완료되는지, 중복 지금 반영이 한 번만 중지 요청을 보내는지, 작성 중 줄바꿈·첨부가 유지되는지 검사했습니다. 최종 답변·중지·오류의 동기 저장, 오래된 저장과의 경쟁, 삭제한 대화 미복원, 종료 시 작업자 종료와 일시 저장 오류의 재시도도 확인했습니다.
- 백엔드 기록·활동·종료·대기 요청·일반 대화 관련 고유 검사 184개가 통과했습니다. 기존 일반 대화 테스트의 업무 승인 복원 기대값 1개를 이미 적용된 명시적 폴더 승인 유지 기능에 맞췄으며, 해당 모듈과 새 저장 검사를 다시 실행했습니다. 동기 저장이 실패해도 재시도 표시가 남는 추가 경계 검사까지 포함합니다. 저장 잠금 순서와 최신 스냅샷 보호에 대한 독립 코드 검토도 수행했습니다.
- 프런트엔드 관련 209개 회귀 검사 통과. 실제 Edge에서 1000/1280/1600px 창 너비로 답변 출력 중 삭제·지금 반영·드래그·키보드·클릭 위치 변화와 초안 보존을 확인했습니다. 페이지 오류와 중복 요청은 없었습니다.
- 업무 500개에서 같은 실행의 전체 목록 갱신 중앙값은 기존 숨겨진 팝업 생성 포함 124.68ms, 수정 후 84.44ms였습니다. 닫힌 팝업 내부 요소 8,500개는 0개로 줄었습니다. 텍스트 이벤트 500개 동안 스킬 문맥 재계산은 0회였고, 관련 정보 변경과 업무 폴더 자동 조회는 유지됐습니다.
- 이전 이미지 응답 2개를 보류해도 새 이미지 2개가 시작됐습니다. 이는 화면의 fetch 취소와 슬롯 해제 검증으로, 관리자 프록시 뒤의 이미 실행 중인 디코딩까지 강제 종료한다는 뜻은 아닙니다.
- 실제 WebView2 관리자 프록시에 이전 진행 조회를 남긴 동일 조건에서 새 조회 지연이 수정 전 **2,798.3ms → 수정 후 8.3ms**였습니다. 테스트 서버의 이전 응답은 3초간 지연시켰으며 회사 네트워크 측정이 아닙니다. 일반 변경 요청은 6.6~10.6ms, 실행 중인 POST 요청은 보존됐습니다. 6개 시나리오 모두 HTTP 200, 네이티브 실패 0건입니다.
- 네이티브 프로세스·알림·창 전환 회귀 79개: 78 통과, Windows 런타임 opt-in 1개 제외. 중지·재개·창 수명·기록 캐시·보관 기록 68개는 모두 통과했습니다.
- 버전 원본 변경, 생성 결과의 재실행 안정성, 오래된 상수·해시·현재 배포 이력의 불일치 차단, 6개 빌드 진입점의 사전 검사 및 번들/온라인 설치기 검증을 수행했습니다. 관련 고유 검사 43개 중 42 통과, 실제 Windows 토큰 opt-in 1개 제외입니다. 후속 새 Python 모듈을 포함한 번들 검사도 통과했습니다.

네이티브 비교 자료: `build/native-poll-fix/baseline/verification.json`, `build/native-poll-fix/verification-1/verification.json`. 기능 검증 단계에서는 별도 숨김 호스트를 사용했습니다. 이후 릴리즈용 빌드 결과는 아래에 기록했습니다.

기타 비교 자료: `build/progress-history-performance.json`, `build/frontend-performance-improvements/frontend-audit.json`, `build/frontend-performance-improvements/lifecycle-checks.json`, `build/frontend-performance-queue-matrix.log`. 운영 앱에 상시 계측 코드를 추가하지 않았습니다.

## 릴리즈 빌드 검증

- 릴리즈 다운로드 구성·소스 ZIP·배포 설명·버전 동기화 50개 검사 중 49개 통과, Windows 토큰 opt-in 1개 제외입니다.
- 0.23.30 standalone EXE의 실제 내장 파일 175개를 `--verify-only`로 추출·검증했습니다. 긴 빌드 임시 경로는 Windows 경로 길이 제한(EXE-63)에 걸려, 별도의 짧은 검증 경로를 지정해 통과했습니다. 사용자 실행 경로나 설정은 변경하지 않았습니다.
- 새 EXE ZIP과 VBS ZIP의 원본 175개가 모두 일치했습니다. 배포 번들은 소스 168개와 고정된 빌드 자산 7개로 구성되며, 실행 상태·자격 증명·Python 인터프리터를 포함하지 않습니다.
- NSIS 3.12로 사용자별 설치 EXE를 생성했습니다. 설치파일 SHA-256은 `1f569e78285d9b776cd8df44b50715d7528c3c2260bed9c14606b3be8ca8c7b9`입니다. 설치파일 내부 standalone SHA-256은 `b28d7b1711acfcdef14f9ece58b740fcd8c0e4d25d2973d6d47dba1a0e215524`입니다.
- 실제 배포 ZIP을 별도 폴더에 풀고 격리된 데모 상태에서 실행했습니다. 0.23.30 버전·인증 경계·화면/한글 폰트/도움말·업무 생성·파일 조회·정상 종료와 런타임 정리가 통과했습니다. 실제 Claude 요청이나 기존 설치 제거·재설치는 수행하지 않았습니다.
- 소스 ZIP은 릴리즈 커밋의 Git archive로 만들고, 인덱스 기준 파일 목록·SHA-256과 일치하는지 게시 전 검사합니다. 검증 자료는 `build/workspace-standalone-0.23.30-build.json`, `build/workspace-release-0.23.30.json`, `build/workspace-installer-0.23.30.json`, `build/qa-workspace-0.23.30-bundle.json`입니다.
