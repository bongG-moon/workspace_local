# AX Workspace 브랜드 적용 검증

2026-10-09. 버전은 0.23.21을 유지합니다. 이 문서는 공개 배포를 위해 확인한 구현·배포 파일의 검증 기록입니다. 공개 다운로드의 최종 파일은 Release의 `SHA256SUMS.txt`를 기준으로 확인합니다.

## 적용 내용

- 사이드바: **AX Workspace / 내 업무와 AI가 만나는 공간**. 밝은 화면·어두운 화면·접힌 아이콘 레일에서 기존 배치를 유지합니다.
- 창 제목·알림·트레이·새 최신 실행기 바로가기와 배포 도구의 표시 이름을 맞췄습니다.
- 기본 배포 파일은 `AX-Workspace-0.23.21.exe`, EXE/VBS ZIP이며 VBS 실행기는 `AX-Workspace.vbs`입니다.
- 기존 업무·설정·캐시·업데이트 출처 식별자와 내부 `Company-Workspace` 폴더를 유지합니다. 기존 `Company-Workspace.vbs`도 같은 내용의 호환 실행기로 남깁니다.
- 구형 업데이트 프로그램을 위해 이전 이름의 EXE/VBS ZIP도 생성합니다. EXE ZIP 내부의 파일 이름만 구형 규약에 맞추고 실행 파일 바이트는 같습니다. 새 업데이트 프로그램은 두 이름을 수용합니다.
- GitLab 게시 도구는 두 이름의 ZIP을 게시하고 채널에는 기존 3개 항목 형식을 유지합니다. 실제 사내 GitLab에는 게시하지 않았습니다.
- `AX_WORKSPACE_STORY.html`에 개발 배경·업무 흐름·설계 원칙·이름의 의미를 작성했습니다. 가이드와 서로 연결하고 번들에 포함했습니다. 앱의 소개 경로는 고정 파일만 허용하며 기존 가이드 보안 정책을 적용합니다.
- CLI와 AI를 처음 접하는 사람도 자신의 업무부터 편하게 시작할 수 있도록 만든 취지를 도입부·개발 배경·설계 원칙·맺음말에 반영했습니다.
- 이전 로컬 채팅 스크롤·말풍선 개선을 포함합니다.

## 검증 결과

검사 묶음은 서로 겹치므로 전체 고유 테스트 수로 합산하지 않습니다.

- 업데이트·게시·실행기 중심 검사: 175개 통과 (`build/qa-ax-packaging.log`).
- 추가 게시 워크플로·설치 검사: 155개 실행, 154개 통과·1개 환경 조건 생략 (`build/qa-ax-publisher-workflow.log`).
- 최종 통합 검사: 315개 실행, 313개 통과·2개 환경 조건 생략 (`build/qa-ax-integration-final.log`). 채팅·레이아웃·알림·창 소유권·업데이트·실행기·가이드·시작 진단을 포함합니다.
- 진단·현재 변경 안내·브랜드 호환성: 38개 실행, 37개 통과·1개 생략 (`build/qa-ax-final.log`).
- 최종 소개 문구·변경 안내 반영 후 가이드 경로·게시 변경 안내·브랜드 호환 검사: 28개 통과 (`build/qa-ax-publish-final.log`).
- 실제 직전 커밋의 GitHub/GitLab 파서·체크섬·VBS 구성·EXE 추출 함수로 호환 파일 규약을 확인했습니다 (`build/qa-ax-legacy-contract.log`).
- Windows WebView2 독립 데모 창에서 새 제목과 소개 문구, 밝은/어두운 화면, 접힌 사이드바를 직접 확인했습니다. 실제 Claude 호출이나 개인 업무 데이터 변경은 하지 않았으며 검증 창을 종료했습니다.
- 브라우저에서 소개 HTML의 상단·본문·하단 배치를 확인했습니다. 모바일 기기와 인쇄 출력은 직접 검증하지 않았습니다.
- 가이드→소개→가이드 HTTP 이동, 임의 파일·경로 접근 차단 테스트가 통과했습니다.
- 단일 EXE 내장 파일 검증과 EXE/VBS 147개 파일 일치 검사를 통과했습니다. 번들은 소스 140개와 고정 빌드 자산 7개이며 런타임 상태·인증 정보·Python을 포함하지 않습니다.

초기 통합 명령에서 존재하지 않는 진단 테스트 모듈 이름을 지정한 오류는 올바른 모듈로 고쳐 최종 통합 검사를 완료했습니다. 패키지 검사에서 새 소개 HTML 허용 목록과 시작 진단의 정규화된 소스 해시를 보완했고, 해당 최종 소스로 EXE·ZIP을 다시 빌드했습니다. 진단 반복 검사에서는 이전 임시 보고서가 다음 하위 검사에 섞이지 않도록 테스트용 결과를 정리합니다.
