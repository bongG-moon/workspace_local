# AX Workspace 0.23.24 업무 폴더와 드래그 개선

2026-10-14 동일 버전 수정본입니다.

## 사용 방법

- 업무 이름 바꾸기에서 이름을 입력한 뒤 Enter로 저장합니다. 한글 조합 중 Enter는 글자 입력만 확정합니다.
- 왼쪽 업무 목록의 새 폴더로 관련 업무를 묶고, 폴더 이름을 눌러 접거나 펼칩니다.
- 업무 왼쪽의 점 모양 손잡이를 끌어 폴더 제목, 펼친 폴더의 업무 또는 빈 공간에 놓으면 이동합니다. 같은 폴더에서는 순서를 바꿉니다.
- 폴더에서 꺼내려면 일반 목록의 업무나 목록 맨 아래 빈 공간으로 끕니다. 일반 목록에 별도 구분 제목은 표시하지 않습니다.
- 업무 이름은 클릭하여 열기 전용입니다. 손잡이를 6 CSS 픽셀 이상 움직이면 드래그를 시작하며, 드래그 직후에는 업무를 잘못 열지 않습니다. 이름을 누르는 동안 손이 흔들려도 순서 변경으로 바뀌지 않습니다. (2026-10-27 개선)
- 이름과 손잡이의 포커스, 드래그 중 강조는 업무 행 전체를 감쌉니다. 고정·삭제 버튼의 개별 키보드 포커스는 유지합니다.
- 업무 행의 폴더 이동 아이콘과 직접 지정 팝업은 제거했습니다. 폴더 머리글의 폴더 아이콘은 유지합니다.
- 폴더 메뉴에서 삭제를 확인하면 폴더만 사라지고 안의 업무는 일반 목록으로 돌아옵니다. 비어 있지 않은 폴더도 삭제할 수 있습니다.

## 데이터와 자원 사용

폴더는 앱 목록을 정리하는 가상 분류입니다. 실제 작업 디렉터리, Claude 세션, 대화, 첨부, 예약을 옮기거나 삭제하지 않습니다. 보관한 업무도 폴더 삭제 후 복원할 수 있습니다.

앱 상태 폴더의 `session-groups.json`에 이름·접힘 상태·소속 ID만 저장합니다. 최대 100개 폴더, 이름 80자, 파일 2 MiB로 크기를 제한합니다. 수정 번호를 확인하고 임시 파일을 원자적으로 교체하여 동시 변경과 저장 실패를 처리합니다. 손상된 분류 파일은 자동으로 덮어쓰지 않습니다.

추가 폴링, 파일 감시, 백그라운드 프로세스는 만들지 않았습니다. 폴더를 조회하거나 정리할 때 열지 않은 대화 본문을 메모리로 불러오지 않습니다. 기존 개인 Claude 설정을 변경하지 않습니다.

## 검증 범위

최종 회귀 검사 251개 중 250개가 통과했고, Windows 심볼릭 링크 생성 권한이 필요한 1개는 제외했습니다.

- 백엔드: 생성·이름 변경·접기·이동·삭제·재시작, 보관 업무 복원, 충돌·손상·저장 실패, 대화와 실제 파일 보존.
- 화면 처리: Enter 저장과 한글 조합, 클릭과 드래그 구분, 취소·Escape, 폴더 하위 영역과 일반 목록 이동, 고정·순서 변경과 초안 보존.
- 실제 Windows 데모 창: 이름 클릭, 이름과 손잡이 드래그, 폴더 안의 업무·빈 영역으로 이동, 접기, 이동 아이콘 제거, 라이트·다크 모드 전체 행 포커스.
- 배포: EXE 내장 소스와 VBS ZIP의 동일 파일 비교, 자격 증명·실제 업무 데이터 제외, 실행 파일 없는 소스 ZIP의 SHA256 목록 검증.

실제 Claude 모델 호출과 사내 운영 PC 환경은 이번 UI 검증 범위에 포함하지 않았습니다. 버전이 같으므로 기존 앱을 완전히 종료한 뒤 최신 Release 파일을 다시 받아 실행하세요.
