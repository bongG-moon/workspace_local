# Workspace 0.11.4 공개 검증 기록

검증일: 2026-09-28. 이 문서는 사용자 경로·실제 업무·실행 토큰을 포함하지 않는 공개용 요약이다.

## 별도 저장소 검증

`workspace_local`은 기존 Company Agent 저장소에서 Workspace 실행 파일·문서·관련 테스트만 분리했다. 기존 Company Agent 전체 소스나 Git 이력, 개인 설치 상태는 포함하지 않는다.

| 검사 | 결과 | 범위 |
| --- | --- | --- |
| 전체 Workspace 회귀 | 255개 중 231개 통과, 24개 건너뜀 | Windows 정상 로그인 계정, 외부 Company Agent core 미지정 |
| 외부 core 통합 관련 3모듈 | 47개 모두 통과 | 별도로 지정한 검토 대상 Company Agent 소스와 임시 설치 등록·상태 사용 |
| 잘못된 외부 core 경로 | 명시적 구성 오류 확인 | 잘못 지정된 경로를 조용히 건너뛰지 않음 |
| 프런트 JavaScript 구문 | 3개 파일 통과 | app.js, companion.js, capabilities.js |
| 공개 파일 점검 | 실제 사용자 경로·주요 인증 토큰 형식 검출 없음 | 실행 상태·개인 설정·로컬 검토 스크린샷 제외 |

전체 실행에서 건너뛴 24개는 외부 core가 필요한 21개, 심볼릭 링크 생성 권한에 따른 2개, 명시적 선택이 필요한 사용자 토큰 진단 1개다. 외부 core를 지정한 47개 재실행은 전체 실행과 일부 겹치므로 두 수치를 더해 고유 테스트 수로 계산하지 않는다.

```powershell
python -X utf8 -m unittest discover -s tests -p "test*workspace*.py" -v
```

외부 core 지정 방법과 빌드 명령은 [README](../README.md)에 설명한다. 외부 소스는 `COMPANY_AGENT_SOURCE`가 가리키는 플러그인 루트에서 읽으며, 테스트는 개인 Claude 프로필 대신 임시 등록과 상태를 사용한다.

## 0.11.4 UI 보완 검증

공개 저장소 분리 전, UI 변경에 직접 관련된 자동 테스트는 122개 중 119개 통과, 환경 조건으로 3개를 건너뛰었다. 위의 전체 회귀 실행과 다른 범위의 기록이다.

가상 CLI·가상 업무를 사용하는 격리된 브라우저에서 다음을 확인했다.

- 기본 확인창을 앱 디자인의 대화상자로 통일하고 취소를 기본 초점으로 설정.
- Esc 취소 후 원래 설정 창과 호출 버튼 초점 유지.
- 예문 적용 취소 시 작성 중인 요청과 도우미 화면 유지.
- 팝업에서 발생한 오류가 해당 팝업 안에 표시됨.
- 긴 파일명이 자료 영역 안에서 줄바꿈됨.
- 자료·결과 탭 중 선택한 탭 하나만 강조됨.
- 390×844 창에서도 최근 4개 밖의 업무를 전체 업무 검색으로 열 수 있음.
- 오래된 업무 선택 응답이 최신 선택을 덮거나 목록을 닫지 않음.
- 종료 승인을 누른 뒤 실제 서버 종료를 확인하고 완료를 표시함.

## Windows 및 패키지

실제 Windows API로 PMv2 DPI 초기화, 시각 스타일, COM 파일·폴더 선택 옵션, 유니코드 경로 반환과 정리를 검증했다. 경고창 보조 코드가 누락·실패해도 원래 경고를 유지하고, 재실행 시 첫 실행과 같은 Edge 경로를 찾는 것을 확인했다.

실행용 ZIP은 42개 허용 파일만 포함한다. 패키지 검사기는 각 파일의 현재 소스 일치, 시작 진단 해시 4개 일치, 상태·인증 정보 미포함을 검사한다. 별도 저장소의 빌더로도 다시 생성해 검사했다.

## 확인하지 않은 범위

가상 CLI 테스트는 실제 회사 인증·모델 응답·문서 품질 검증을 대신하지 않는다. 회사 HCP, DRM·Office 자료, 모든 직원 PC의 보안 정책과 모니터 구성에 대한 전수 검증은 수행하지 않았다. 네이티브 선택·경고창의 최종 외관을 모든 배율에서 직접 눈으로 확인한 것도 아니다.

이 기록은 검증 범위를 설명한다. 실제 회사 업무 완료 여부는 생성 파일과 요청한 기준을 직접 대조해야 한다.
