## 기존 0.23.36 변경 내용

- **조회 실패를 명확하게 표시:** 이전 사용 금액·잔액·사용률과 막대를 숨기고 `사용량을 조회하지 못했어요.`를 표시합니다. 자동 재시도 중에도 이전 잔액을 보여주지 않으며 정상 조회 후 새 수치만 표시합니다.
- **일시 오류 자동 복구:** 502/503/504, 연결 오류와 시간 초과에 같은 연결 방식으로 최대 2회 재시도합니다. 이후 실패 시에는 1분 뒤 재조회하도록 화면과 서버의 갱신 간격을 맞췄습니다. 서버가 지정한 대기 시간도 반영합니다. 업무 요청이나 설치 명령은 재실행하지 않습니다.
- **오류 원인 확인:** 주소·인증·네트워크·서버 초기화·팀 조회·사용량 조회 단계를 구분해 표시합니다. KEY와 서버 응답 원문은 표시하거나 기록하지 않습니다.
- **초기화 시각 표시:** API의 `reset_at` 값을 24시간제 한국 시간으로 표시합니다. 명시된 시간대는 그대로 따르며 시간대가 없는 값은 운영 기준에 맞춰 UTC로 해석하고 그 기준을 화면에 안내합니다. UTC 자정은 `09:00 KST`로 표시합니다. 운영 서버 원문과의 대조는 별도로 필요합니다.
- **사내 배포 주소 설정:** 사내 배포 프로그램의 `LLM 사용량 MCP 주소 (선택)`에서 주소를 설정하면 설치 EXE와 업데이트 ZIP에 동일하게 포함됩니다. 개인 KEY는 기존 Claude 환경·사용자 설정에서 자동으로 읽으며 배포 파일에 포함하지 않습니다. 변경한 주소와 다른 이전 빌드가 게시되지 않도록 검사합니다.
- **정식 앱과 연결 테스트 분리:** 정식 앱은 기존 기본 연결 방식을 유지합니다. 주소 편집·직접 연결 비교는 별도 테스트 빌드에서만 제공하며 시스템 프록시 설정을 바꾸거나 자동 우회하지 않습니다. TEST1/TEST2가 다시 연결된 사실만으로 최초 503의 원인을 단정하지 않습니다.

## 다운로드와 적용

- Windows 설치: `AX-Workspace-0.23.36-Setup.exe`
- 사내 반입·GitLab 배포용 소스: `workspace-local-0.23.36-source.zip`
- 자동 업데이트용 EXE·VBS ZIP, 호환 파일명과 `SHA256SUMS.txt`도 제공합니다.

사내 담당자는 새 소스 ZIP을 풀고 `Publish-Workspace.py`에서 사용량 MCP 주소를 입력한 뒤 사내 GitLab에 빌드·게시하세요. 공개 GitHub 파일에는 사내 주소나 개인 KEY를 넣지 않았습니다. GitHub 게시만으로 기존 사내 서버의 배포 파일이 바뀌지는 않습니다.
