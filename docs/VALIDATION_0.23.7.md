# 0.23.7 — 사용자 중지 오류 표시 개선

## 변경 내용

직접 중지한 작업에 실패 경고와 오류 알림이 생기던 표시 문제를 수정했다. 현재 연결에서 명시적 중지 중 들어오는 알려진 EDE 중단 응답만 일반 실패에서 제외한다. 질문 상태를 정리하고 실제 CLI 종료 확인 뒤 중지 상태를 표시한다. 후속 요청은 같은 대화에서 이어간다.

인증 실패, 실제 연결 종료 실패, 중지하지 않은 작업의 오류, 다른 세션이나 미확인 중단 형식은 숨기지 않는다. 기존 오류 배너 전체를 삭제하지 않고, 거짓 성공·완료 이벤트를 만들지 않는다. 추가 AI 호출·자동 재전송·대기시간은 없다. [분류 조건과 수정 전후 비교](VALIDATION_STOP_CLASSIFICATION_2026-10-03.md).

현재 버전 표기와 시작 진단 고정 해시(`ws33-42`)도 함께 갱신했다. 기존 패키지 검사기의 목록에서 빠져 있던 상세 진행 기록 파일 3개를 추가해, 원래부터 포함되던 실제 배포 목록과 검사 목록을 일치시켰다.

## 검증

- 수정 단계 관련 회귀: **189개 중 187개 통과, 2개 조건부 생략**. 사용자 중지용 신규 13개에는 서버의 실패/완료 알림 부재와 같은 세션의 후속 요청 1회 전송을 포함한다.
- 버전 갱신 후 배포 관련 검사: **243개 중 최종 240개 통과, 3개 조건부 생략**. 제한 계정에서 시작 검사 3개가 `WS-31`로 차단됐고, 동일 테스트를 실제 로그인 사용자 환경에서 다시 실행해 3개 모두 통과했다. 보안 가드를 수정하거나 건너뛰지 않았다.
- 단일 EXE 생성과 실제 내장 ZIP의 추출 검증 통과. Python을 포함·설치·다운로드하지 않는 기존 동작 유지.
- EXE와 VBS ZIP의 공통 앱 파일 **127개 전부 동일**. 원본 파일 120개와 고정 빌드 자산 7개의 일치 및 개인 상태·인증 정보 미포함 확인.
- 배포 ZIP을 별도 폴더에 풀어 실제 로그인 사용자 환경에서 데모 서버 시작/종료, 버전, 인증 없는 API 차단, HTML/한글 글꼴/안내서, 격리 업무·파일 목록, 종료 후 runtime 정리를 확인했다. 제한 계정에서는 정상적으로 시작을 거부했고 사용자 환경에서 재검증했다.
- 검사 묶음 사이의 중복 테스트는 서로 다른 기능 수로 합산하지 않는다.

## 범위와 한계

이번 배포 검증에서 실제 AI 질문이나 사용자 파일을 전송하지 않았다. 새 EXE의 실제 계정 화면에서 중지·재개를 다시 시험한 것은 아니며, 해당 경로는 합성 응답을 사용하는 서버 통합 테스트로 확인했다. 사내 HCP/DRM, 전체 업데이트·IME 시험의 미확인 사항은 이번 수정으로 통과 처리하지 않는다.

기존 설치본·개인 설정·사용자 업무 자료는 변경하지 않았다. [사용법](LOCAL_WORKSPACE.md) · [배포 페이지](https://github.com/bongG-moon/workspace_local/releases/tag/v0.23.7).
