# AX Workspace 0.23.43 — 실행 안정성과 이미지 붙여넣기 개선

## 2026-11-03 이미지 붙여넣기 추가

- **캡처 이미지 바로 첨부:** 일반 대화와 업무의 입력창에서 `Ctrl+V`를 누르면 클립보드의 PNG, JPG, WebP 이미지가 첨부됩니다. 파일로 먼저 저장할 필요가 없습니다.
- **초안과 첨부 보호:** 기존 텍스트 붙여넣기와 첨부 한도를 유지합니다. 이미지를 저장하는 동안 중복 전송을 막고, 다른 대화로 이동하면 원래 대화의 초안에 보관합니다. 클립보드를 상시 확인하거나 자동 전송하지 않습니다.
- **사용 안내:** 자료 추가 버튼의 설명과 사용 설명서에 이미지 붙여넣기 방법을 추가했습니다.

같은 **0.23.43 재빌드**이므로 기존 0.23.43에서는 새 버전 알림이 나오지 않을 수 있습니다. 새 설치 파일을 다운로드하고 앱을 완전히 종료한 뒤 설치하세요. 사내 배포 담당자는 갱신된 소스 ZIP을 사용해 주세요. 이미 같은 버전을 게시한 사내 서버는 기존 배포 정책에 따라 다음 버전으로 빌드해야 할 수 있습니다.

## 기존 0.23.43 개선

- **WS-40 실행 오류:** 회사 보안 프로그램의 진단 출력이 PowerShell 응답에 섞일 때 정상적인 Windows 권한 확인까지 실패하던 문제를 수정했습니다. 이번 실행에서 앱이 보낸 확인 결과만 읽으며, 기존 사용자와 실행 권한 검증은 유지합니다.
- **Claude 버전 표시:** 버전 조회 결과에 다른 진단 문구가 섞여 표시되는 문제를 수정했습니다. 확인되지 않거나 서로 다른 버전이 섞인 응답으로 버전 전용 기능을 임의 활성화하지 않습니다.
- **업데이트 준비와 오류 안내:** 업데이트 준비 응답도 다른 출력과 구분해서 읽습니다. 확인된 시작 오류 코드를 보존해 권한 확인 실패가 일반 WS-40으로만 표시되지 않도록 개선했습니다.
- **오류 출력 메모리:** 줄바꿈 없는 긴 오류 출력을 한꺼번에 읽으며 메모리가 커질 수 있던 부분을 수정했습니다. 작은 단위로 읽고 제한된 진단만 보관하며, 대화와 답변 내용의 처리 방식은 유지합니다.

연결, 중지, 재연결, 종료를 반복하는 격리 시험에서 앱이 만든 프로세스가 모두 정리되는 것도 확인했습니다. 빠른 재개를 위한 대기 연결과 기존 유휴 연결 정리 정책은 유지합니다. 장기간 실사용이나 모든 사내 보안 프로그램 조합의 무결함을 보장하는 시험은 아닙니다.

설치 파일은 `AX-Workspace-0.23.43-Setup.exe`, 사내 반입용 소스는 `workspace-local-0.23.43-source.zip`입니다. 기존 업데이트용 EXE/VBS ZIP과 호환 파일명도 제공합니다. 기존 업무, 대화, 초안과 확장 연결은 유지하며, P&T AI Square 확장과 플랫폼은 기존 배포본을 사용합니다.

사내 배포 담당자는 이 소스 ZIP으로 0.23.43을 빌드하고 기존 GitLab 프로젝트의 버전 파일과 최신 채널을 갱신해 주세요. GitHub 게시만으로 사내 서버의 배포 파일이 바뀌지는 않습니다.

WS-40 발생 PC에서도 사내 배포 도구의 **`AX-Workspace-Install.exe`**는 예전에 받은 파일을 다시 실행해 최신 Setup을 내려받을 수 있습니다. 같은 서버와 프로젝트를 사용하고 수정본의 최신 채널까지 정상 게시되어 있어야 합니다. 예전에 저장한 버전별 Setup이나 일반 `AX-Workspace-Setup.exe`는 최신 파일을 다시 받아야 합니다. 앱이 시작 전에 실패하는 경우 앱 내부 자동 업데이트만으로 복구된다고 보장할 수 없습니다.

출력 혼입과 잘못된 응답 거절, 실제 Windows 권한 확인, 업데이트 전환, 연결 정리 및 오류 출력 메모리 한도를 검증했습니다. 실제 문제가 발생한 LTSC 2019와 해당 보안 프로그램 조합에서는 최종 실행 확인이 필요합니다.
