# AX Workspace 0.23.46 — 사번 등록과 보관 업무 초안 저장 개선

## 사번은 처음 한 번만 입력

- 설치 현황 집계가 설정된 사내 배포본에서 사번을 처음 한 번 등록합니다. 기능이 처음 포함된 업데이트는 새 앱을 처음 실행할 때 등록 안내를 표시합니다.
- 사번이 저장되어 있으면 이후 업데이트에서 사번이나 등록 확인창을 표시하지 않고 기존 업데이트를 진행합니다. 사번이 없을 때만 기존 업데이트창 안에서 입력받습니다.
- 앞뒤 공백을 제외한 1~8자를 저장하며 설정에서 변경할 수 있습니다. 인증키는 사용자가 입력하지 않습니다.
- 사번을 저장하는 동안 업데이트창을 닫으면 해당 업데이트 요청을 취소합니다. 창을 다시 열어도 이전 요청이 자동으로 실행되지 않습니다.

등록 안내 문구:

> 설치 또는 업데이트가 완료되면 결과를 한 번 전송합니다.
>
> 이 집계 기능은 평소 앱 사용 중 사용 정보를 수집하지 않습니다.

설치 또는 앱 내부 업데이트의 정상 실행이 확인된 뒤 버전별로 한 번만 전송을 시도합니다. 서버에 연결하지 못해도 앱 사용과 업데이트를 계속할 수 있습니다. 일반 사용 중 집계 통신이나 주기적인 감시를 추가하지 않았습니다.

## 업무를 보관한 뒤 반복되던 안내 수정

목록에서 지운 업무의 초안이 자동 저장 대기에 남으면, 다른 업무나 일반 대화를 사용할 때도 보관 업무 안내가 반복되는 문제를 수정했습니다. 보관된 업무의 초안 저장을 마칠 수 있게 하고, 보관 업무를 다시 선택한 상태로 저장하지 않습니다.

초안과 첨부 정보, 보관 상태는 유지됩니다. 이 수정으로 보관된 업무를 복원하거나 실행하지 않습니다. 삭제 중인 일반 대화와 첨부 파일의 기존 보호도 유지합니다.

## 사내 배포 담당자 안내

기존 집계 POST 시험이 정상인 웹은 그대로 사용합니다. 기본 주소를 유지한다면 `scripts/prepare-workspace-registration.py`에서 웹 서버와 같은 인증키만 숨김 입력한 뒤 생성한 설정을 사내 빌드의 `-RegistrationConfig`에 지정합니다. 이후에는 설정 파일을 재사용할 수 있습니다.

공개 설치 파일에는 실제 인증키를 포함하지 않으며 집계 설정도 기본으로 꺼져 있습니다. 사내 키가 포함된 설치 파일과 ZIP은 사내 배포에만 사용합니다. MongoDB 접속 정보는 앱에 넣지 않습니다.
