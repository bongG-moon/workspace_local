# 0.23.21 입력 보존·업무 관리 추가 검증

검증일: 2026-10-08. 0.23.21 동일 버전 수정본입니다. 10월 7일 기록은 [기존 검증](VALIDATION_0.23.21.md)에 보존하며, 이번 변경의 검증 범위는 아래와 같습니다. 최종 파일의 해시는 [Release의 SHA256SUMS.txt](https://github.com/bongG-moon/workspace_local/releases/download/v0.23.21/SHA256SUMS.txt)를 기준으로 확인합니다.

## 변경 내용

- 보내지 않은 입력·첨부와 Ctrl+S로 보관한 입력을 로컬 SQLite에 저장합니다. 변경한 항목만 저장하고, 정상 종료·버전 전환 전에 미저장 입력을 확인합니다. 충돌이나 저장 실패 시 기존 값을 보존하며 복원만으로 요청을 보내지 않습니다.
- 연결 한도에 도달해 새 연결이 필요할 때 안전한 유휴 연결을 회수합니다. 실행·승인·질문·제어 응답·종료 대기·이어 할 일이 있는 연결은 보호합니다. 기존 세션과 선택값을 보존하고 종료가 확인된 경우에만 자리를 재사용합니다.
- 설정에서 앱이 보관한 첨부 복사본의 용량을 보고 미사용 복사본을 정리할 수 있습니다. 원본 파일, 전송한 자료, 초안·이어 할 일·예약에서 참조하는 자료와 출처가 불명확한 이전 자료는 지우지 않습니다. 클릭 한 번의 처리량을 제한합니다.
- 설정에서 숨긴 업무를 검색·복원할 수 있습니다. 활성 업무 한도와 숨긴 업무 한도를 분리하며, 초기 화면은 이력 색인만 읽고 선택한 대화 본문을 필요할 때 불러옵니다. 복원만으로 Claude나 대기 요청을 실행하지 않습니다.
- Windows에서 파일 교체·업데이트 폴더 이동이 일시적으로 거절되면 정해진 오류에 한해 최대 합계 85ms 간격으로 재시도합니다. 기존 설치·원본 파일은 보존하며 지속되는 실패는 그대로 보고합니다.
- 실행 권한 안내를 실제 Windows 권한 상속 동작에 맞췄습니다. 다크 모드 저장과 관리자 권한은 별개이며, 이전 권한 선택 파일을 읽어 실행 권한을 고정하지 않습니다. 이번 확인에서 권한 정책이나 개인 설정은 변경하지 않았습니다.

## 자동·격리 검증

아래 검사 집합에는 중복이 있으므로 숫자를 합산하지 않습니다.

| 범위 | 결과 |
| --- | --- |
| 초안·보관·첨부·연결·종료·전환·예약·시작 진단 통합 | 546개 중 543개 통과, 선택 실행 2개 생략, Windows 폴더 이동 오류 1개 발견 |
| 위 폴더 이동 오류 수정 후 업데이트·실행기 재검사 | 60개 모두 통과 |
| 첨부 전송 승인 시점·회귀 검사 | 104개 모두 통과 |
| 실행 권한·직접 실행·재실행·관리 실행기 | 79개 모두 통과 |
| 시작 화면 및 정적 자산 건강 검사 | 52개 모두 통과 |
| 격리 HTTP 확인 | 추가 자산 5개, 초안 저장·읽기, 보관 목록, 첨부 용량 조회 통과 |
| 게시 직전 안내·소스 ZIP·설정·시작 화면 회귀 | 79개 중 78개 통과, 호스트 조건 1개 생략 |

최신 가이드를 포함해 EXE와 VBS ZIP을 다시 빌드했습니다. 공통 파일 145개(소스 138개·검증된 생성 자산 7개)가 바이트 단위로 일치하고 EXE의 내장 파일 검증도 통과했습니다. 개인 상태나 인증 파일은 패키지에 포함하지 않습니다.

선택 실행 생략 항목은 실제 Windows 알림과 일반 사용자 토큰의 대화형 진단입니다. 이번 추가 작업에서는 연결된 컴퓨터 사용 화면을 확보하지 못해 직접 클릭·화면 검증을 수행하지 않았습니다. 기존 10월 7일 화면 검증이 이번 추가 화면까지 검증한 뜻은 아닙니다. 실제 개인 Claude 요청과 사내 운영 환경은 사용하지 않았습니다.

## 부하 확인

격리된 구성 요소 벤치마크에서 500개 대화의 시작 시 본문 파일 읽기는 500회에서 0회로 줄었습니다. 중앙값은 1,531.91ms에서 27.36ms, 측정된 Python 최대 할당량은 약 16.8MB에서 0.75MB로 감소했습니다. 앱 전체 메모리나 운영 PC 응답 속도를 측정한 수치는 아닙니다.

초안 500개가 저장된 상태에서 항목 하나를 40회 바꾼 저장 시간 중앙값은 7.70ms, 95백분위는 13.83ms였습니다. 초안 변경 시 지연 저장 타이머만 사용하며 새 주기적 폴링·상주 작업자는 추가하지 않았습니다. 유휴 회수와 저장 공간 검사는 필요한 시점에만 수행합니다.

## 다시 설치하거나 실행할 때

- 같은 0.23.21 수정본이므로 자동 버전 비교 알림은 나오지 않습니다. 최신 ZIP을 다시 받아 별도 폴더에 풀고 기존 앱을 트레이에서 **완전 종료**한 다음 실행합니다.
- 앱 설정·대화 보존을 위해 사용자 상태 폴더를 삭제할 필요가 없습니다. 테마 설정이 유지되는 것만으로 관리자 권한이 저장되어 있다고 판단하지 않습니다.
- EXE·VBS 패키지는 동일한 소스와 생성 자산을 사용하며 Python을 포함·설치·다운로드하지 않습니다.
- GitHub 게시와 사내 GitLab 게시는 별개입니다. 사내에는 갱신된 소스 ZIP을 반입해 기존 배포 도구로 다시 게시합니다.

로컬 근거: `build/qa-durable-improvements-summary.json`, `build/qa-durable-final-tests.json`, `build/qa-durable-performance.json`, `build/qa-durable-http-smoke.json`, `build/admin-audit-20261008.json`. 이 파일들은 개인 배포 경로나 임시 실행 정보를 포함할 수 있어 공개 소스에 넣지 않습니다.
