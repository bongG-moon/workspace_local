# AX Workspace 0.23.48 — 업무 전환과 도움말 창 반응 개선

## 다른 업무로 이동할 때

업무를 전환하면 이전 화면에 새 기록을 표시하려고 기다리던 요청을 정리합니다. 업무 기록이 길거나 여러 업무를 연달아 열 때 이미 떠난 업무의 대화 전체를 반복해서 읽는 일을 줄였습니다. 다른 화면을 보는 동안에도 실행 중인 업무는 계속 진행되고, 다시 열면 그동안 쌓인 기록을 확인할 수 있습니다.

## 도움말과 단축키를 열 때

사용 도움말과 단축키 창이 열릴 때 글자가 더 빨리 선명해집니다. 단축키를 검색하지 않고 창을 다시 열면 전체 목록을 그대로 보여줍니다. 검색한 뒤 닫았다가 다시 열면 검색어가 비워지고 전체 단축키가 표시됩니다.

## 업무 화면에서 클릭할 때

- **새 업무 → 기존 폴더 사용하기**를 누를 때 창이 뜨는 동안 선택지가 움직이거나, 글자를 누른 채 마우스가 조금 움직여 클릭을 놓치는 경우를 줄였습니다.
- 다른 업무의 상태가 갱신되는 순간에도 업무 목록에서 누르던 항목, 파일 변경을 확인하던 버튼, 예약을 관리하던 버튼을 계속 사용할 수 있게 했습니다.

## Claude 모델을 사용할 수 없을 때

로그인에 문제가 있는 경우와 선택한 모델에 접근할 권한이 없는 경우를 구분해서 안내합니다. 모델 오류가 뜨면 **모델 선택**에서 사용할 수 있는 모델을 고르세요. 기본 모델을 바꾸려면 **Claude 설정 파일 열기**로 현재 연결의 `settings.json`을 메모장에서 수정하고 저장한 뒤 **Claude Code 재시작**을 누르세요.

채팅과 예약 요청을 입력할 때 보이던 맞춤법 검사 밑줄도 껐습니다.
