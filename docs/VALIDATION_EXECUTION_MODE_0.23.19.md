# 실행 권한 선택 보완 검증 — 로컬 0.23.19

2026-10-06. 공개 GitHub Release와 기존 `dist/workspace-release-0.23.19`는 변경하지 않았습니다. 이번 실행 파일은 별도 `dist/workspace-execution-preview-0.23.19`에 있습니다.

## 구현

- 설정에서 일반·관리자를 선택합니다. 관리자는 추가 확인 후 Windows의 정상 권한 요청을 사용합니다. 실제 계정·세션·토큰 검증을 통과해야 앱과 Claude가 같은 권한으로 실행됩니다.
- 작업·승인·질문을 마칠 때까지 기다리고 초안·첨부를 보관해 재시작합니다. 성공한 실행만 앱 자체 선택 파일에 저장하며 Claude 개인 설정과 Windows 정책·기존 파일 ACL은 변경하지 않습니다.
- 일반으로 돌아올 때는 관리자 상태의 전환 담당 프로세스가 기존 앱을 정리한 뒤 새 실행기에서 권한을 낮춥니다. 같은 버전의 기존 앱 교체와 더 높은 버전 우선 규칙을 포함합니다.
- 관리자 연결은 Windows TCP 소유 PID, 같은 사용자·세션, 관리자 그룹·상승 상태·무결성 수준을 확인합니다. 일반 프로세스는 연결 토큰만으로 실행·종료 요청을 수행할 수 없습니다.
- WebView2는 샌드박스를 유지합니다. 전용 창이 인증된 같은 출처 요청만 중계합니다. 본문 길이가 없는 POST와 파일 첨부 대체 처리를 포함하며 동시 4개·응답 32MiB로 제한합니다. 큰 업로드는 독점적인 삭제용 임시 스트림으로 처리합니다.

- 마지막 중계·진단·권한·화면 변경 관련 91개 검사 통과.
- 실제 Windows TCP 연결에서 클라이언트 PID와 현재 프로세스의 사용자·권한 조회를 확인했습니다. 관리자 토큰 판정의 다른 사용자·다른 세션·일반 권한 거절도 검증했습니다.
- 가상 CLI와 시계를 사용해 요청 중복 방지, 관리자 선택 취소·실패 시 기존 작업 유지, 전환 전 대기, 초안 보관, 관리자→일반 전환 순서를 검증했습니다.
- computer-use로 실제 전용 앱의 설정 영역을 확인했습니다. OS는 일반 권한으로 유지한 별도 체험 화면에서 관리자용 중계를 활성화해 GET 조회와 POST 가상 요청 전송이 질문 대기까지 도달함을 확인했습니다. 실제 AI 호출은 하지 않았습니다.
- 최종 EXE를 별도 상태·캐시에서 실행해 일반 권한·정책 프로토콜 1·선택 저장·실행기 종료 코드 0·앱 정상 종료·runtime 정리를 확인했습니다.
- 최종 EXE 내장 검증 통과. EXE·VBS 공통 파일 133개 일치, 원본 126개와 고정 빌드 자산 7개 확인. Python을 포함·설치·다운로드하지 않습니다.
