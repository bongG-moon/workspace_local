# 입력창에서 모델 · Effort · 승인 모드 바꾸기

Workspace 0.12.4는 입력창 아래에 현재 모델, Effort(사고 수준), 승인 모드를 항상 표시합니다. 각각을 누르면 바로 위에 작은 선택 목록이 열립니다. 전체 설정 창을 열거나 적용 버튼을 다시 누르지 않고 후보를 선택하면 됩니다.

- **모델:** 현재 Claude 연결이 제공한 모델 중에서 선택합니다. 회사 모델 이름은 같은 목록 아래에서 직접 입력할 수 있습니다.
- **Effort:** 현재 CLI와 모델이 지원하는 수준을 선택합니다. Claude가 확인해 준 실제 적용 수준을 표시하며, 요청만 확인된 경우에는 실제 적용값으로 단정하지 않습니다. 모델과 회사 정책에 따라 수준이 제한될 수 있습니다.
- **승인:** 현재 연결이 지원하는 승인 모드만 표시합니다. 모드의 설명을 보고 선택할 수 있으며 모든 승인을 우회하는 모드는 추가하지 않습니다.
- **기존 설정 사용:** 해당 업무 연결에서의 변경을 원래 설정으로 되돌립니다. 개인 Claude 설정 파일을 변경하지 않습니다. Effort의 **기존 설정으로 다시 연결**은 현재 연결을 닫고 다음 요청에서 원래 모델·Effort·승인 모드를 함께 상속합니다. 이 영향은 선택 목록에 표시합니다.

처음 선택 목록을 열면 필요한 Claude 연결을 초기화합니다. AI 질문은 보내지 않지만 기존 시작 후크와 MCP 초기화는 실행될 수 있습니다. 홈에서는 업무 선택 안내를, 신뢰 확인이 필요한 업무에서는 기존 폴더 확인 흐름을 제공합니다. 확인 후에도 작성 중인 요청을 자동 전송하지 않습니다.

변경을 확인하는 동안 전송과 중복 변경을 막고, 응답이 확인되면 표시를 갱신합니다. 실패하면 기존 상태를 유지하고 이유를 입력창 근처에 표시합니다. 다른 업무로 이동한 뒤 늦게 도착한 응답은 그 업무의 표시를 바꾸지 않습니다. 진행 중인 요청은 마치거나 중지한 뒤 변경합니다.

CLI가 Effort나 다른 변경 기능을 제공하지 않으면 기존 설정을 유지하고 해당 사유를 표시합니다. 확인되지 않은 모델·모드·수준을 임의로 추가하지 않습니다. 기존 설정 창의 상세 기능도 유지합니다.
