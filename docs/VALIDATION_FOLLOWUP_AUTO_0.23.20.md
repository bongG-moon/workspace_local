# 0.23.20 이어 할 일 자동 실행 보완

검증일: 2026-10-07. 0.23.20 동일 버전 수정본의 검증 기록입니다. 아래 EXE 해시는 이 기능을 단독 검증한 당시 기록이며, 자료·결과 갱신까지 포함한 최종 배포 해시는 Release의 SHA256SUMS.txt와 [통합 수정본 검증](VALIDATION_FILE_REFRESH_0.23.20.md)을 기준으로 확인하세요.

## 수정 내용

- 이전 중지·오류·재시작 뒤 실제 대기 요청이나 활성 예약이 없어도 업무별 보류 표시가 남아, 새 요청의 후속 작업까지 멈추던 경로를 수정했습니다.
- 정상 상태에서 사용자가 새 후속 요청을 등록할 때만 비어 있는 대기열의 오래된 보류 표시를 해제합니다. 정상 완료 후 기존 서버 실행 루프가 등록 순서대로 실행합니다.
- 오류·중지·연결 종료로 보류된 기존 항목과 전송 확인이 필요한 항목은 자동 재전송하지 않습니다. 활성 예약, 사용자 일시 정지, 설정 변경·복원 확인도 유지합니다. 중지 응답과 늦은 완료 이벤트가 겹쳐도 임의로 재개하지 않습니다.
- 결과물의 일반적인 ‘결과 미확인’ 표시는 정상 완료 후 실행을 막지 않습니다. 실제 종료 확인 절차의 오류, 승인·질문 대기는 계속 기다립니다.
- 대기 목록과 등록 안내에서 자동 실행 대기·응답 대기·일시 정지·중지 확인 중을 구분합니다. 이미 보류된 항목이 있으면 ‘이어 실행’이 필요하다는 안내를 표시합니다.
- 새 실행 스레드·폴링·프로세스는 추가하지 않습니다. 기존 0.5초 서버 루프와 등록 시 대기열 확인을 사용합니다.
