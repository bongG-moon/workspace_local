# Company Workspace 0.12.6 — 입력창 정리

검증일: 2026-09-29.

## 변경 내용

- 자료 추가·경로 추가 옆에 모델·Effort·승인 모드를 배치했습니다. 보내기는 오른쪽에 유지합니다.
- `/`와 `@` 버튼을 작은 안내 문구로 바꿨습니다. 중복된 보내기 단축키 안내와 입력창 placeholder의 반복 문구도 줄였습니다.
- 키보드 자동완성, 선택 목록, 첨부, 모델·Effort·승인 변경 로직은 유지합니다. 없어진 버튼의 이벤트와 전용 삽입 함수만 제거했습니다.
- 실행 설정의 상태·오류 안내는 하단 도구 아래에 필요할 때 표시합니다. 좁은 창에서는 실행 설정 묶음을 다음 줄로 정렬합니다.

## 검증

관련 기존 자동완성·연결·인라인 컨트롤 검사 78개가 모두 통과했습니다. 삭제한 바로가기 버튼을 기대하던 테스트 1개는 제거했습니다. 버전 및 실행기·진단 해시 계약 검사 4개도 통과했습니다. 전체 회귀검사를 다시 실행한 기록은 아니며 이번 변경에 영향을 받는 범위를 검사했습니다.

브라우저에서 다음을 확인했습니다.

- `/my` 입력 → 추천 표시 → Tab으로 `/my-fixture` 선택.
- `@확인` 입력 → `확인용.md` 추천 → Tab으로 파일 참조와 첨부 생성.
- 옮긴 모델 버튼으로 입력창 위 선택 목록 열기.
- 1280px 및 900px 창에서 자료 추가·모델·Effort·승인·보내기가 같은 줄에 표시.
- 390px 창에서 실행 설정 묶음 줄바꿈, 가로 화면 넘침 없음.
- 최종 EXE에서도 실제 `claude-sonnet-5-5`와 Effort `medium`이 같은 도구 줄에 표시.

초기화한 최종 EXE 화면의 입력 상자 높이는 146.4px였습니다. 실제 입력창 화면 (로컬 검증 기록: `build/qa-standalone-0.12.6-composer/screen.png`; 공개 저장소에는 포함하지 않음)을 저장했습니다.
