Company Workspace 0.21.6 - Python 실행 진단

1. ZIP 전체를 쓰기 가능한 새 폴더에 압축 해제하세요.
2. Check-Python.cmd를 평소처럼 더블클릭하세요. 약 1분 정도 걸릴 수 있습니다.
3. 완료 후 같은 폴더에 생긴 Workspace-Python-Diagnostic-날짜-번호.json 파일 하나를 담당자에게 보내 주세요.
   결과 경로는 마지막 화면에도 표시됩니다. reportRun 폴더는 검사 중간 기록입니다.

이 도구는 현재 PowerShell 환경과 Company Workspace의 일반 권한 실행 환경에서
설치된 Python의 버전과 기본 모듈, 프로세스 시작 조건을 비교합니다.
Python을 설치하거나 다운로드하지 않고, PC 보안 설정과 기존 Claude 인증·개인 설정을 바꾸지 않습니다.
앱 서버나 Claude, AI 업무는 실행하지 않습니다.
파일에 사용자 SID, 인증 정보, 환경 변수, PowerShell 프로필, 원본 출력·오류 내용은 기록하지 않습니다.
실제로 검사한 Python 실행 경로에는 Windows 사용자 폴더 이름이 포함될 수 있습니다.

결과는 이번 진단 실행의 관찰값입니다. 이전 앱 실행 실패 원인이 확정되었다는 뜻은 아닙니다.
이미 일반 권한이면 같은 환경임을 기록하며, 별도 권한 전환 검사를 했다고 표시하지 않습니다.
지원되지 않거나 차단된 검사는 null 또는 실패 상태로 남깁니다.
출력을 연결하지 않은 검사는 고정 Python 검사의 종료 코드만 확인합니다. 앱 전체의 실행 성공을 뜻하지 않습니다.
Default DACL의 직접 허용 ACE 유무는 참고 정보이며, 전체 유효 접근 권한 판정은 아닙니다.

평소 Python이 동작하는 PowerShell에서 직접 비교하려면 다음처럼 실행할 수도 있습니다.
  & "압축 해제한 폴더\Check-Python.ps1"
기존 Python 실행 파일을 지정하려면:
  & "압축 해제한 폴더\Check-Python.ps1" -PythonCommand "기존 python.exe의 전체 경로"

manifest.json은 함께 배포한 파일의 변경·누락을 확인합니다. 인증서 서명을 대신하지는 않습니다.
반드시 전달받은 원본 ZIP을 사용해 주세요. 실행이 완료되지 않으면 화면의 상태를 담당자에게 알려 주세요.
