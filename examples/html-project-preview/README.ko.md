# HTML 웹 미리보기 예시

AX Workspace 0.23.45 이상의 **화면 / 웹 / 코드** 차이를 확인하는 예시입니다. 실제 업무 자료가 아닌 가상 생산 데이터를 사용합니다.

## 열어 보기

1. 예시 ZIP을 받았다면 **전체 압축을 풀어** 주세요. HTML 파일 하나만 옮기지 말고 `production-web-demo` 폴더도 함께 두세요.
2. AX Workspace에서 압축을 푼 `html-project-preview` 폴더를 업무 폴더로 선택하세요. 업무 요청을 입력하거나 보낼 필요는 없습니다.
3. 오른쪽 자료 목록에서 **생산보고서-다크.html**을 엽니다.
4. **화면**에서는 정적 미리보기가 표시됩니다. 연결 상태는 대기이며 범위 버튼은 작동하지 않습니다.
5. **웹**을 누르면 공정 그림과 디자인이 연결됩니다. 아래 범위 버튼을 눌러 수치와 그래프가 바뀌는지 확인하세요. 공간이 좁으면 **넓게 보기**를 사용합니다.

| 버튼 | 선택한 데이터 | 최대 생산량 | 해당 작업 |
| --- | ---: | ---: | --- |
| 전체 105건 | 105건 | 2,400개 | LOT-101, 조립 |
| 처음 100건 | 100건 | 1,480개 | LOT-078, 검사 |
| 검사 공정 | 35건 | 1,480개 | LOT-078, 검사 |

버튼은 상단 예시 영역의 요약과 상위 3개 작업 그래프만 바꿉니다. 그 아래 기존 보고서의 고정 수치는 그대로입니다. **코드**에서는 현재 HTML 원문을 확인할 수 있습니다.

## 파일을 함께 보관하세요

```text
html-project-preview/
  README.ko.md
  생산보고서-다크.html
  production-web-demo/
    demo.css
    demo.js
    process.svg
    data.json
```

`data.json`은 가상 `생산검토.csv` 105건에서 만든 고정 사본입니다. 예시에 필요한 데이터는 모두 포함되어 있으므로 CSV를 따로 준비할 필요는 없습니다. 실시간으로 CSV를 다시 읽거나 업무를 자동 분석하는 예시는 아닙니다.

이 예시는 인터넷 서비스에 연결하거나 원본 파일을 수정하지 않습니다. 플러그인이나 추가 프로그램도 설치하지 않습니다. HTML을 브라우저에서 직접 열면 환경에 따라 모듈과 데이터 읽기가 제한될 수 있으므로, 동작 비교는 AX Workspace의 **웹** 탭에서 진행하세요.
